# BLASST: динамическое разрежение внимания для ускорения длинного контекста в LLM

## Tags
- sparse attention  
- FlashAttention  
- CUDA kernels  
- long-context inference  
- threshold pruning  
- sparsity-aware training  
- Llama-3.1-8B  

## TL;DR
BLASST — метод динамического разрежения внимания, который без предвычислений и прокси-оценок пропускает незначимые блоки внимания, достигая до 1.62× ускорения при 74.7% разреженности с минимальной потерей точности на современных GPU.

## Краткое описание
Статья решает проблему квадратичной сложности механизма внимания в больших языковых моделях при обработке длинных контекстов (до сотен тысяч токенов). Предлагается BLASST — простой метод, который во время вычисления softmax в FlashAttention динамически отбрасывает блоки с малыми значениями внимания, используя порог и уже вычисленные максимумы без дополнительной предобработки. Это позволяет пропускать вычисление экспоненты, загрузку блоков значений и умножение матриц, снижая нагрузку на CUDA и память. Разработаны оптимизированные CUDA-ядра для фаз prefill (вычислительно ограниченная) и decode (узкая по памяти). Введена автоматическая калибровка порога, зависящего обратно пропорционально длине контекста, и методика обучения с учётом разреженности, повышающая устойчивость модели. Эксперименты на Llama-3.1-8B и Qwen3-8B показывают сохранение или улучшение качества на бенчмарках RULER, LongBench, MATH500 и др. при значительном ускорении (до 1.62×). BLASST универсален, не требует архитектурных изменений и хорошо сочетается с другими методами разрежения.

## Основные идеи
- динамическое отбрасывание блоков внимания на основе сравнения локального максимума с текущим максимумом softmax  
- интеграция в FlashAttention с минимальными накладными расходами  
- специализированные CUDA-ядра для prefill и decode с учётом их узких мест  
- автоматическая калибровка порога разрежения, обратнопропорционального длине контекста  
- обучение с учётом разреженности для улучшения точности при высоком уровне пропусков  
- совместимость с различными вариантами внимания (MHA, GQA, MQA, MLA)  
- возможность комбинирования с другими методами разрежения и сжатия  

## Какую проблему решает статья
- квадратичная сложность внимания ограничивает применение LLM к очень длинным контекстам (до сотен тысяч токенов)  
- существующие sparse attention методы требуют дорогостоящей предобработки или используют неточные прокси-метрики важности  
- большинство методов оптимизируют либо prefill, либо decode, но не обе фазы одновременно  
- необходимость решения без архитектурных изменений и с минимальными накладными расходами  

## Метод
- во время блочного вычисления softmax в FlashAttention поддерживается бегущий максимум значений внимания  
- блоки, у которых локальный максимум значительно меньше бегущего (по порогу λ), считаются незначимыми и пропускаются  
- пропуск включает: вычисление экспоненты, загрузку блока значений из памяти и умножение матриц  
- порог λ подбирается автоматически, с учётом длины контекста по формуле λ = a / L, где a — константа, L — длина контекста  
- реализованы CUDA-ядра с минимальными изменениями интерфейса FlashAttention, использующие инструкции VOTE и ATOMIC для согласования решения о пропуске блока  
- prefill-ядро оптимизировано для вычислительно ограниченной нагрузки, пропуская softmax и матричные умножения  
- decode-ядро оптимизировано для памяти, пропуская загрузку блоков значений  
- sparsity-aware training: во время дообучения применяется BLASST, что заставляет модель концентрировать внимание в важных блоках, улучшая устойчивость к разрежению  

## Главные результаты
- на Llama-3.1-8B и Qwen3-8B при ~50% разреженности BLASST сохраняет или улучшает качество по сравнению с плотным вниманием на RULER, LongBench, MATH500, AIME 2024, GPQA и LiveCodeBench  
- BLASST превосходит MInference, FlexPrefill и XAttention по точности при отсутствии предвычислений  
- достигается до 1.62× ускорения prefill и 1.48× decode на современных GPU (H200, B200) при ~74% разреженности  
- автоматическая калибровка порога обеспечивает стабильное достижение целевой разреженности для разных длин контекста с ошибкой ~1.2%  
- sparsity-aware training снижает деградацию точности при высоком уровне разреженности до 1.7× по сравнению с пост-тренировочным применением BLASST  
- BLASST устойчив к изменению порядка обработки блоков и может комбинироваться с другими методами разрежения (XAttention, RocketKV) без значительной потери точности  
- на экстремально длинных последовательностях (до 200K токенов) BLASST сохраняет высокую разреженность и качество  

## Важные концепции
- использование бегущего максимума softmax для оценки важности блоков без дополнительного вычисления  
- пороговое правило пропуска блоков, основанное на сравнении локального и глобального максимумов в логарифмическом пространстве  
- интеграция в FlashAttention с минимальными изменениями и низкими накладными расходами на принятие решения  
- разделение оптимизаций для prefill (вычислительно ограниченный) и decode (узкий по памяти) этапов  
- автоматическая калибровка порога, учитывающая длину контекста, для стабильного контроля разреженности  
- обучение с учетом разреженности, повышающее адаптацию модели к пропущенным блокам внимания  

## Ограничения
- метод требует настройки параметра a для каждого конкретного типа модели и задачи  
- при очень высоких уровнях разреженности возможна заметная деградация точности, хотя BLASST демонстрирует более плавное снижение по сравнению с аналогами  
- эффективность зависит от распределения внимания в модели и может варьироваться по слоям и головам  
- текущее решение ориентировано на GPU архитектуры Hopper и Blackwell, переносимость на другие платформы требует проверки  
- не рассматривается обучение с архитектурными изменениями или гибридные методы с динамическим обучением разреженности  

## Практическое применение
- ускорение инференса LLM с длинным контекстом в продуктивных системах  
- применение в системах с ограниченными ресурсами GPU для снижения затрат на вычисления и память  
- интеграция в существующие фреймворки с FlashAttention без необходимости дообучения или архитектурных изменений  
- улучшение качества вывода в задачах с длинным контекстом и сложным рассуждением за счёт фильтрации несущественных взаимодействий  
- потенциал для использования в системах с динамическим управлением вниманием и адаптивным разрежением  
- совместимость с методами сжатия KV-кэша и другими оптимизациями внимания  

## Итоговые выводы
- BLASST предлагает простой, эффективный и универсальный метод динамического разрежения внимания без предвычислений и прокси-метрик  
- достигается значительное ускорение инференса (до 1.62×) при сохранении или улучшении качества на сложных бенчмарках  
- автоматическая калибровка порога обеспечивает стабильность и предсказуемость разреженности для разных длин контекста  
- sparsity-aware training улучшает устойчивость модели к пропущенным блокам внимания  
- метод ограничен необходимостью настройки и зависит от распределения внимания в модели  
- BLASST создаёт основу для дальнейших исследований в области аппаратно-ориентированного и обучаемого разрежения внимания в LLM
