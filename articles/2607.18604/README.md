# Интеллектуальная навигация мульти-БПЛА в сетях ITNTN: иерархический подход на базе LLM

## Tags
- Multi-UAV Navigation
- Hierarchical LLM
- ITNTN
- Reinforcement Learning
- Agentic AI
- Network Handover
- 6G Networks

## TL;DR
Авторы предлагают иерархическую архитектуру, объединяющую стратегическое мышление LLM с быстродействием DRL для управления БПЛА. Система использует облачные LLM для глобальной балансировки нагрузки и бортовые LLM для адаптивной настройки параметров управления в реальном времени.

## Краткое описание
Статья решает проблему координации высокоскоростных БПЛА в 3D-коридорах, интегрированных в наземные и неземные сети (ITNTN). Традиционные методы глубокого обучения с подкреплением (DRL) страдают от неэффективного исследования среды и жадных стратегий, а чистые LLM не подходят для управления из-за высокой задержки. Предложенная иерархическая архитектура разделяет задачи: облачная LLM (Qwen3.5-122B) на платформе HAPS выполняет глобальную балансировку нагрузки, а легкие бортовые LLM (Qwen3.5-9B) на каждом БПЛА динамически корректируют веса функций вознаграждения для быстрого контроллера (DDQN). Это позволяет эффективно сочетать семантическое планирование с физическим управлением, минимизируя частоту хендоверов и повышая общую пропускную способность системы при сохранении безопасности полетов.

## Основные идеи
- Иерархическое разделение принятия решений по трем временным шкалам.
- Использование LLM для когнитивной рефлексии и динамической настройки весов вознаграждения.
- Облачно-периферийная архитектура (HAPS-UAV) для глобальной и локальной координации.
- Дискретизация состояний для эффективного промпт-инжиниринга и снижения задержек.
- Использование опыта из памяти для in-context обучения бортовых агентов.

## Какую проблему решает статья
- Недостаток стратегического мышления у стандартных DRL-агентов в динамических сетях.
- Высокая задержка LLM, несовместимая с требованиями к управлению БПЛА в реальном времени.
- Системная перегрузка ресурсов при неконтролируемом поведении множества БПЛА.
- Сложность совместной оптимизации физической кинематики и надежности связи (хендоверов).

## Метод
- Архитектура: Трехуровневая иерархия (HAPS-облако, бортовая LLM, DDQN-контроллер).
- HAPS-уровень: Qwen3.5-122B анализирует глобальную нагрузку и выдает директивы по балансировке.
- Бортовой уровень: Qwen3.5-9B преобразует локальные наблюдения в текстовые промпты, на основе которых корректирует веса вознаграждения для DDQN.
- Физический уровень: DDQN работает на частоте 20 Гц, выполняя непрерывное управление двигателями и дискретный выбор базовой станции.
- Обучение: Использование H-MO-POMDP для формализации задачи и distance-based выборки примеров из памяти для улучшения zero-shot ответов LLM.

## Главные результаты
- Превосходство над базовыми методами DDQN и Envelope MORL по стабильности обучения и итоговой пропускной способности.
- Существенное снижение частоты хендоверов в условиях высокой плотности БПЛА благодаря стратегическому планированию HAPS.
- Повышение выживаемости БПЛА за счет динамического приоритета безопасности при обнаружении критических состояний.
- Успешная работа системы в условиях задержек, обусловленных инференсом LLM, за счет асинхронного разделения задач.

## Важные концепции
- Когнитивная рефлексия: способность LLM менять приоритеты агента (например, переключаться с транзита на избегание столкновений) через изменение весов функции вознаграждения.
- Временная декомпозиция: разделение задач на стратегические (секунды) и тактические (миллисекунды) для обхода ограничений задержки LLM.
- Семантическая дискретизация: перевод численных данных датчиков в текстовые описания для LLM, что повышает качество рассуждений и снижает объем промптов.

## Ограничения
- Зависимость от вычислительных мощностей на борту для инференса 9B-модели.
- Предположение о наличии стабильного канала связи с HAPS для получения глобальных директив.
- Задержки инференса остаются критическим фактором, требующим дальнейшей квантизации моделей.

## Практическое применение
- Автономная логистика БПЛА в 3D-коридорах.
- Управление роями дронов в сетях 6G.
- Интеллектуальное управление трафиком в городских условиях.
- Системы мониторинга с динамической балансировкой нагрузки на базовые станции.

## Итоговые выводы
- Иерархический подход эффективно решает проблему задержек LLM в задачах управления.
- Динамическая настройка вознаграждений через LLM превосходит статические DRL-подходы.
- Система обеспечивает лучшую масштабируемость при росте плотности БПЛА.
- Основным ограничением остается вычислительная стоимость инференса на периферии.
- Метод открывает путь к созданию полностью автономных интеллектуальных воздушных сетей.
