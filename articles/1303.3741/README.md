# Организационный майнинг с использованием онлайн-социальных сетей

## Tags
- social network analysis
- organizational mining
- web crawler
- centrality measures
- machine learning
- leadership detection
- network privacy

## TL;DR
Авторы предлагают метод извлечения и анализа неформальных социальных сетей сотрудников из публичных источников для выявления скрытого руководства и структуры компаний без доступа к их внутренним данным.

## Краткое описание
Исследование решает проблему угрозы конфиденциальности организаций из-за публичной активности сотрудников в социальных сетях, таких как Facebook и LinkedIn. Авторы разработали специализированный веб-краулер на основе принципа гомофилии для целевого сбора данных о сотрудниках шести высокотехнологичных компаний разного масштаба. Для анализа сети применялись восемь метрик центральности и алгоритмы машинного обучения (включая логистическую регрессию и случайный лес) с целью автоматического выявления управленческих ролей. Дополнительно использовался алгоритм кластеризации для разделения сети на сообщества, что позволило определить географическое распределение филиалов, структуру подразделений и наличие поглощенных стартапов. Главный результат заключается в том, что анализ публичных неформальных связей позволяет с высокой точностью (до 76% для метрики близости) выявлять лидеров организации, включая скрытые управленческие роли, которые не указаны в профилях сотрудников.

## Основные идеи
- Специализированный краулер на основе гомофилии эффективно собирает профили сотрудников целевой организации из социальных сетей.
- Метрики центральности позволяют точно выявлять руководящие роли по структуре неформальных связей.
- Машинное обучение по признакам центральности автоматизирует классификацию управленческих позиций.
- Кластеризация граф-сети раскрывает скрытую структуру компании, расположение филиалов и поглощенные стартапы.
- Публичное раскрытие данных сотрудниками создает серьезные уязвимости конфиденциальности для бизнеса.

## Какую проблему решает статья
Сотрудники компаний часто раскрывают рабочие детали в публичных социальных сетях, создавая угрозу конфиденциальности. Традиционные поисковые роботы неэффективны для целевого сбора данных конкретной организации. Доступ к внутренним данным (например, логам электронной почты) обычно закрыт, поэтому требуется метод анализа внутренней структуры компаний на основе исключительно открытых данных.

## Метод
- Разработка веб-краулера на основе принципа гомофилии, где приоритет отдается профилям, чьи друзья уже работают в целевой компании.
- Сбор датасетов для шести компаний разного размера.
- Расчет восьми мер центральности для каждого узла графа неформальных связей.
- Обучение классификаторов (OneR, Naive-Bayes, J48, Logistic, RandomForest) для поиска управленческих ролей.
- Кластеризация сети алгоритмом Жирвана-Ньюмана для выделения сообществ и сопоставления их с данными профилей и геолокации.

## Главные результаты
- Краулер собрал 17096 профилей сотрудников с общей точностью 22.1%.
- Метрика близости показала наибольшую точность в топ-20 (в среднем 76%), выявив 85 руководителей, из которых 40% скрывали свои должности на Facebook.
- Классификаторы машинного обучения превзошли базовый уровень, причем алгоритмы логистической регрессии и случайного леса показали лучшие результаты по AUC и F-мере.
- Обнаружены скрытые структуры филиалов, R&D-подразделения и изолированные поглощенные стартапы.

## Важные концепции
- Гомофилия: принцип, согласно которому люди с большей вероятностью работают в одной организации, если у них много общих знакомых-сотрудников.
- Метрики центральности: числовые характеристики положения узла в графе, отражающие его важность и коммуникационную роль.
- Выявление сообществ: разбиение графа на несвязные группы для определения специализации и географии подразделений.

## Ограничения
- Зависимость от полноты и достоверности данных, добровольно раскрываемых пользователями в соцсетях.
- Точность сбора данных краулером варьируется в зависимости от размера компании.
- Потенциальные этические и правовые риски при сборе и анализе персональных данных.

## Практическое применение
- Информационная безопасность и оценка рисков утечки конфиденциальных данных компаний.
- Аудит корпоративной структуры и выявление структурных разрывов.
- Исследования в области кибербезопасности и защиты приватности в социальных сетях.

## Итоговые выводы
- Предложен эффективный метод сбора организационных данных из открытых источников с использованием принципа гомофилии.
- Доказано, что структура неформальных связей позволяет точно определять руководящие должности и скрытых лидеров.
- Классификаторы машинного обучения успешно автоматизируют определение менеджмента по метрикам графа.
- Кластеризация раскрывает внутреннюю географию и организационную структуру компаний без доступа к внутренним логам.
- Результаты подчеркивают необходимость строгих политик использования социальных сетей для защиты корпоративной конфиденциальности.
