# Банкинг по-настоящему: переосмысление розничного банкинга с помощью языкоцентричного ИИ

## Tags
- retail banking  
- large language models  
- multi-agent system  
- conversational AI  
- financial transactions  
- regulatory compliance  
- intent classification  

## TL;DR
Представлена Ryt AI — первая в мире лицензированная банковская система, где крупная языковая модель (LLM) служит основным интерфейсом для выполнения финансовых операций через естественный язык. Система обеспечивает безопасность, соответствие регуляциям и заменяет многократные экраны диалогом с несколькими специализированными агентами.

## Краткое описание
Статья решает проблему устаревших, громоздких цифровых банковских интерфейсов, требующих многошаговых действий для простых операций, таких как перевод средств. Предлагается Ryt AI — LLM-нативная многоагентная система, построенная на внутренней закрытой модели ILMU, одобренная регуляторами Малайзии для прямого исполнения ключевых транзакций через естественный язык. Архитектура включает четыре агента: Guardrails (безопасность), Intent (распознавание намерений), Payment (платежи) и FAQ (ответы на вопросы), каждый с LoRA-адаптером для специализированных задач. Система обеспечивает многоуровневую защиту: детерминированные правила, подтверждение человеком и безсессионное хранение данных. Эксперименты на 2000 диалогах показывают высокую точность, безопасность и эффективность, подтверждая возможность масштабного внедрения ИИ в критичные банковские процессы.

## Основные идеи
- Применение LLM как основного интерфейса для выполнения финансовых операций в лицензированном банке.  
- Многоагентная архитектура с разделением задач между специализированными LLM-агентами.  
- Использование LoRA-адаптеров для адаптации единой модели ILMU под разные функции.  
- Интеграция OCR для обработки платежных документов и изображений.  
- Многоуровневая система безопасности с детерминированными правилами и контролем человека.  
- Обеспечение соответствия строгим регуляторным требованиям и аудиту.  
- Высокая производительность и устойчивость к ошибкам и атакам.

## Какую проблему решает статья
Современные цифровые банковские интерфейсы сложны, требуют многошаговых действий, не поддерживают свободный ввод естественного языка и создают неудобства для пользователей. Существующие LLM-решения в финансах ограничены поддержкой вспомогательных функций, не интегрированы в критичные операции из-за рисков безопасности, галлюцинаций и регуляторных ограничений. Это тормозит инновации в банковской сфере.

## Метод
Ryt AI — модульная многоагентная система, построенная на внутренней LLM ILMU (около 10 млрд параметров), оптимизированной для банковских задач и соответствия регуляциям. Архитектура включает:

- **Guardrails** — агент для обнаружения и блокировки опасных, вредоносных или несанкционированных запросов с помощью семантического анализа и визуального модератора.  
- **Intent Classifier** — семантический классификатор намерений, учитывающий контекст диалога, обученный на 1,05 млн аннотированных примеров с ошибками и смешанными языками.  
- **Action Agents** — специализированные агенты, например, Payment Agent для обработки переводов с извлечением и валидацией ключевых полей (получатель, банк, счет, сумма, назначение), включая поддержку OCR для документов; FAQ Agent с Retrieval-Augmented Generation для ответов на вопросы.  
- **Pipeline** — последовательная обработка запросов: Guardrails → Intent → Action → Подтверждение пользователя, с обменом структурированными JSON-сообщениями для сохранения контекста и аудита.  
- **Обучение и эксплуатация** — LoRA-адаптеры для каждого агента позволяют адаптировать ILMU без полной дообучения. Модель размещена в инфраструктуре банка для контроля и безопасности.

## Главные результаты
- Ryt AI успешно обслуживает более 50 000 пользователей и обрабатывает около 80 000 транзакций в месяц.  
- Точность распознавания намерений и генерации ответов высока, включая сложные многоязычные и неформальные запросы.  
- Галлюцинации в транзакционных потоках встречаются менее чем в 0.5% случаев, в FAQ — менее 1.5%, благодаря строгой валидации, защитным механизмам и подтверждению человеком.  
- Система демонстрирует низкую задержку и экономичное использование вычислительных ресурсов, что важно для масштабируемости.  
- Соответствие регуляторным требованиям подтверждено, включая двухфакторную аутентификацию и аудит.

## Важные концепции
- **LLM-нативный агентный подход**: разделение функций между специализированными агентами, каждый с адаптированным LoRA-адаптером, повышает гибкость и безопасность.  
- **Guardrails с семантическим анализом**: использование LLM для выявления сложных нарушений политики, превосходя традиционные правила.  
- **Intent Classifier с контекстом**: учитывает историю диалога для точного понимания намерений в реальных условиях.  
- **Stateless memory**: отсутствие постоянного хранения пользовательских данных снижает риски утечек и соответствует принципам минимизации данных.  
- **Human-in-the-loop**: обязательное подтверждение пользователя для критичных операций обеспечивает контроль и доверие.

## Ограничения
- Требуется значительные ресурсы для разработки и поддержки собственной LLM ILMU, что обусловлено регуляторными требованиями.  
- Система ориентирована на языки и регуляции Малайзии (Bahasa Melayu, английский, китайский), что ограничивает переносимость без локализации.  
- Частые обновления модели затруднены из-за затрат на переобучение и регуляторных процедур.  
- Некоторые пользователи могут предпочитать традиционные интерфейсы, что требует дополнительных усилий по адаптации и обучению.

## Практическое применение
- Внедрение в лицензированные цифровые банки для упрощения пользовательских интерфейсов и автоматизации операций.  
- Использование в финансовых сервисах с высокими требованиями к безопасности и соответствию.  
- Потенциальное расширение на другие высокорегулируемые отрасли с необходимостью прозрачности и контроля.  
- Улучшение клиентского опыта за счет естественного языка и сокращения времени на операции.
