# Извлечение сетевых структур из корпоративных организационных диаграмм с использованием эвристической обработки изображений

## Tags
- network extraction
- organizational charts
- heuristic image processing
- corporate structure
- network analysis
- python networkx
- data acquisition

## TL;DR
Авторы разработали эвристический метод обработки изображений для автоматического извлечения сетевых структур из корпоративных оргдиаграмм. Метод успешно реконструировал 4600 сетей из 10008 японских корпоративных диаграмм без использования обучаемых моделей ИИ/МО.

## Краткое описание
Исследование решает проблему нехватки машиночитаемых датасетов корпоративных организационных структур, необходимых для количественного анализа. Авторы предлагают детерминированный эвристический пайплайн из 10 шагов для обработки PDF-файлов оргдиаграмм. Метод распознает текстовые метки, блоки и соединительные линии без использования методов глубокого обучения или разметки тренировочных данных. Извлеченные структуры преобразуются в объекты NetworkX для дальнейшего сетевого анализа. На датасете японских компаний метод показал успешность извлечения 46 процентов, предоставив ценную эмпирическую базу для исследований в области менеджмента и науки о сложных системах.

## Основные идеи
- Использование логических эвристик вместо обучения моделей на базе нейросетей при отсутствии тренировочных данных.
- Десятишаговый пайплайн обработки изображений для очистки, распознавания линий и блоков.
- Интеграция извлеченных графических элементов в грабовые структуры Python NetworkX.
- Успешная обработка масштабного корпуса реальных неструктурированных корпоративных диаграмм.

## Какую проблему решает статья
Отсутствие крупномасштабных машиночитаемых датасетов организационных сетей препятствует количественным исследованиям корпоративных структур. Большинство данных публикуется в виде неструктурированных графических PDF-диаграмм, непригодных для автоматического анализа. Ранее исследователи были вынуждены использовать косвенные опросные данные или текстовые описания, что ограничивало изучение топологических свойств и динамики организаций.

## Метод

### Общий подход
Метод реализует детерминированный подход к обработке изображений без применения сверточных нейросетей или обучаемых алгоритмов, что позволяет работать в условиях полного отсутствия разметки.

### Пайплайн обработки
1. Конвертация PDF в растровое изображение PNG с помощью pdf2image.
2. Объединение пунктирных линий в сплошные через операции дилатации и эрозии.
3. Удаление колонтитулов и вспомогательной информации на основе анализа пустых строк.
4. Выделение горизонтальных и вертикальных линий в качестве ребер графа.
5. Вставка узлов в точках пересечения линий.
6. Удлинение концевых ребер для надежного сопоставления с текстом.
7. Обнаружение и замена прямоугольных блоков (циклов) единичными узлами.
8. Удаление топологически избыточных узлов степени два.
9. Извлечение текстовых блоков через pdfminer с сохранением координат.
10. Объединение сетевых узлов и текстовых меток по пространственным координатам в граф NetworkX.

## Главные результаты
- Обработано 10008 файлов оргдиаграмм японских публичных компаний за период с 2008 по 2011 год.
- Успешно реконструировано 4606 корпоративных сетей.
- Итоговый коэффициент успешности сбора данных составил 46 процентов.
- Для каждой сети измерены базовые диагностические метрики: количество узлов и ребер, плотность, коэффициент кластеризации, средняя длина кратчайшего пути и алгебраическая связность.

## Важные концепции
- Эвристическая обработка: применение жестко запрограммированных правил геометрии изображений для выделения структурных связей.
- Топологическое упрощение: удаление визуальных рамок и промежуточных точек для приведения схемы к чистому графу подчинения.
- Пространственное сопоставление: связывание текстовых описаний отделов с узлами графа на основе их взаимного расположения.

## Ограничения
- Метод распознает в качестве ребер только строго горизонтальные и вертикальные линии.
- Алгоритм тестировался исключительно на японских корпоративных диаграммах из конкретного сборника.
- Отсутствует поддержка диаграмм нестандартной сложной или диагональной верстки, что привело к неудачам на более чем половине исходных файлов.
- Требуется адаптация для мультиязычных документов и иных стандартов визуализации.

## Практическое применение
- Количественные исследования в области организационной науки и менеджмента.
- Анализ связи между структурой компании и ее операционной эффективностью.
- Создание автоматизированных инструментов парсинга документной графики для бизнес-аналитики.
- Построение графов знаний из неструктурированных корпоративных отчетов.

- Доказана высокая эффективность логических эвристик в задачах компьютерного зрения без обучающих данных.

- Основным ограничением остается чувствительность к формату исходной графики.
