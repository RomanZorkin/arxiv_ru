# Context-aware Adaptive Graph Attention Network (CaGAT)

## Tags
- graph neural networks
- attention mechanism
- tensor product graph
- semi-supervised learning
- node classification
- context-aware learning
- edge representation

## TL;DR
Предложена CaGAT, которая одновременно учит контекстно-зависимые представления рёбер через Tensor Product Graph диффузию и представления узлов. На четырёх бенчмарках полу-контролируемой классификации CaGAT превосходит GAT и другие GNN.

## Краткое описание
Существующие GNN (включая GAT) оценивают внимание рёбер независимо, игнорируя контекстные связи между рёбрами, и разделяют обучение внимания и агрегацию признаков. CaGAT решает обе проблемы: использует Tensor Product Graph диффузию для итеративного уточнения внимания рёбер на основе соседних рёбер и одновременно обучает представления узлов через neighbourhood propagation. Unified регуляризационная модель связывает обе задачи. На четырёх датасетах (Cora, Citeseer, Pubmed, Cora-ML) с 10 и 20 метками на класс CaGAT стабильно превосходит GAT, GCN, GraphSAGE и другие. Например, на Cora (10 меток) точность 77.98% против 76.54% у GAT. Модель нечувствительна к гиперпараметрам, а вычислительная сложность на практике невысока (K=3, T=2).

## Основные идеи
- Контекстно-зависимое внимание рёбер через Tensor Product Graph диффузию.
- Совместное обучение внимания рёбер и представлений узлов в единой модели.
- Unified регуляризационный фреймворк, интегрирующий обе цели.
- Использование итеративного алгоритма с усечением для эффективности.
- Стабильное улучшение accuracy на четырёх бенчмарках.
- Нечувствительность к параметрам alpha, lambda, xi.

## Какую проблему решает статья
Основная проблема — существующие GNN (например, GAT) оценивают внимание каждого ребра изолированно, не используя информацию о соседних рёбрах. Кроме того, обучение внимания и агрегация узлов выполняются независимо, что приводит к субоптимальным результатам. CaGAT вводит контекстную зависимость между рёбрами и кооперативное обучение обоих компонентов.

## Метод
CaGAT — пространственная GNN. На каждом слое:
1. Вычисляется начальное внимание GAT для каждого ребра.
2. Итеративно уточняется внимание через TPG диффузию: новое внимание ребра — взвешенная сумма внимания соседних рёбер (по диффузионной матрице) и исходного GAT-внимания (параметр alpha).
3. Представления узлов обновляются через neighbourhood propagation с использованием полученного внимания (параметр lambda).
4. Процесс повторяется K раз (K=3). Обучение Adam, 2 слоя, 8 голов, early stopping. Unified регуляризация объединяет обе задачи.

## Главные результаты
CaGAT превосходит все baseline на всех датасетах. Примеры (20 меток на класс): Cora 80.51% (GAT 79.07%), Citeseer 73.21% (GAT 71.91%), Pubmed 77.68% (GAT 76.74%), Cora-ML 81.86% (GAT 80.33%). Ablation: при xi=0 (раздельное обучение) accuracy падает на ~1% на Cora и ~3% на Cora-ML, подтверждая пользу unified подхода. Модель нечувствительна к параметрам: alpha 0.2-0.6, lambda 0.1-0.7, xi 1e-3..1e-2.

## Важные концепции
Tensor Product Graph (TPG) диффузия: внимание ребра распространяется по графу через произведение матриц смежности — внимание ребра (i,j) получает вклад от всех пар соседей (h,k), где h сосед i, k сосед j. Это учитывает контекст. Unified модель: регуляризационный член связывает внимание рёбер и представления узлов — они оптимизируются совместно, а не по отдельности.

## Ограничения
Основное ограничение — вычислительная сложность O(T n^3) для полного графа, хотя на практике графы разрежены и используются малые итерации. Модель тестировалась только на полу-контролируемой классификации citation сетей. Не исследовано индуктивное обучение. Параметры подбирались вручную, хотя модель нечувствительна. Нет сравнения с более крупными графами.

## Практическое применение
Классификация узлов в цитационных сетях, социальных сетях, графах знаний. Может применяться в рекомендательных системах, анализе биологических сетей (белковые взаимодействия), выявлении сообществ. Метод подходит для любых задач, где важны связи между рёбрами.

## Итоговые выводы
- CaGAT вводит контекстно-зависимое внимание рёбер через TPG диффузию.
- Главное преимущество — совместное обучение внимания и представлений узлов.
- На четырёх бенчмарках CaGAT стабильно превосходит GAT и другие GNN (до +2% accuracy).
- Основное ограничение — потенциально высокая сложность для плотных графов.
- Метод перспективен для задач, где важна структура рёбер и контекст.
