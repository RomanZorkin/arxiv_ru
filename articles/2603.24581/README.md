# Latent-WAM: Моделирование скрытого мира для автономного вождения

## Tags
- autonomous driving
- world models
- trajectory planning
- latent representation
- geometric distillation
- end-to-end learning
- computer vision

## TL;DR
Latent-WAM — это эффективная система сквозного автономного вождения, использующая сжатые пространственно-осведомленные представления мира. Метод достигает новых SOTA-результатов на бенчмарках NAVSIM v2 и HUGSIM, превосходя существующие подходы при меньших вычислительных затратах.

## Краткое описание
Статья представляет Latent-WAM — фреймворк для сквозного автономного вождения, решающий проблему неэффективности существующих моделей мира. Предыдущие подходы страдали от избыточности представлений, слабой пространственной осведомленности и неполного использования временной динамики. 

Авторы предлагают два ключевых модуля:
1. Spatial-Aware Compressive World Encoder (SCWE): сжимает многовидовые изображения в компактные токены сцены, используя дистилляцию геометрических знаний из foundation-моделей.
2. Dynamic Latent World Model (DLWM): использует причинный Transformer для авторегрессионного предсказания будущего состояния мира на основе исторических данных и состояния эго-автомобиля.

Главный результат — достижение 89.3 EPDMS на NAVSIM v2 и 28.9 HD-Score на HUGSIM. Метод демонстрирует превосходство над лучшими perception-free аналогами при использовании компактной модели на 104 млн параметров, что подтверждает эффективность обучения представлений, ориентированных на планирование.

## Основные идеи
- Дистилляция геометрических знаний в vision-backbone для улучшения пространственного понимания.
- Сжатие визуальных данных в компактные токены сцены через обучаемые запросы.
- Авторегрессионное моделирование динамики мира в скрытом пространстве с использованием 3D-RoPE.
- Совместное обучение визуальной и динамической составляющих без необходимости в сложных вспомогательных задачах.
- Использование teacher-forcing и frame-wise attention для эффективного обучения временных зависимостей.

## Какую проблему решает статья
Существующие методы сквозного вождения либо полагаются на тяжелые вспомогательные задачи и разметку восприятия, либо используют неэффективные модели мира. Проблемы включают:
- Недостаточную степень сжатия латентных представлений.
- Отсутствие глубокого пространственного понимания 3D-сцены.
- Неэффективное использование временной динамики, ограничивающее качество планирования траекторий.

## Метод
- Архитектура состоит из SCWE, DLWM и декодера траекторий.
- SCWE использует DINOv2-Base, дополненный дистилляцией от WorldMirror для внедрения геометрической осведомленности.
- DLWM применяет причинный Transformer для предсказания будущих состояний, интегрируя данные о состоянии эго-автомобиля (команды, скорость, ускорение).
- 3D-RoPE внедряет пространственно-временные позиции в механизм внимания.
- Обучение ведется с использованием L1-loss для траекторий, MSE для динамики мира и кросс-энтропии для команд управления.

## Главные результаты
- NAVSIM v2: 89.3 EPDMS (SOTA, превосходит предыдущие методы на 3.2 EPDMS).
- HUGSIM: 45.9 RC и 28.9 HD-Score (лучший результат в zero-shot режиме).
- Модель требует всего 104 млн параметров, что обеспечивает высокую эффективность в production-сценариях.
- Визуализация внимания подтверждает, что модель фокусируется на критически важных элементах: разметке, границах препятствий и направлении движения.

## Важные концепции
- Geometric Distillation: передача знаний о 3D-структуре сцены из предобученной модели в энкодер, что позволяет модели «видеть» геометрию без явных 3D-аннотаций.
- Scene Compression: замена тысяч патчей изображений на небольшое число токенов, что радикально снижает вычислительную сложность планирования.
- Causal World Modeling: предсказание будущего состояния мира как последовательности, что позволяет модели планировать траектории, учитывая динамику окружения.

## Ограничения
- Зависимость от качества дистиллируемых геометрических признаков.
- Ограниченная точность при экстремально сложных сценариях по сравнению с методами, использующими явную разметку восприятия.
- Необходимость предварительного вычисления геометрических признаков для эффективного обучения.

## Практическое применение
- Разработка систем автономного вождения с ограниченным вычислительным бюджетом.
- Создание end-to-end планировщиков, не требующих дорогостоящей разметки восприятия (perception-free).
- Робототехника и мобильные агенты, требующие понимания динамики окружения в реальном времени.

## Итоговые выводы
- Latent-WAM эффективно объединяет пространственное понимание и динамическое моделирование.
- Дистилляция геометрии является критическим фактором для точности планирования.
- Метод показывает, что компактные латентные представления могут превосходить тяжелые архитектуры.
- Высокая производительность в zero-shot сценариях подтверждает обобщающую способность модели.
- Подход значительно снижает требования к данным и вычислительным ресурсам для обучения.
