# Объединение машинного обучения и анализа социальных сетей для выявления организационных структур

## Tags
- social network analysis
- organizational structures
- machine learning
- collective classification
- email communication
- graph mining
- corporate hierarchy

## TL;DR
Авторы предлагают метод восстановления организационной иерархии компаний на основе метаданных электронной переписки. Подход объединяет классические алгоритмы машинного обучения с метриками анализа социальных сетей и графовыми алгоритмами классификации.

## Краткое описание
Статья исследует задачу обратного проектирования корпоративных структур по коммуникационным данным сотрудников. Авторы используют социальные сети, построенные на основе обмена электронными письмами, извлекая из них центральность узлов, коэффициенты кластеризации, размер клик и динамику вариативности связей. Для классификации сотрудников по уровням иерархии применяются классические алгоритмы (Деревья решений, Случайный лес, Нейронные сети, Метод опорных векторов) и специальный алгоритм коллективной классификации. Эксперименты на двух наборах данных (производственная компания и корпус Enron) демонстрируют, что сочетание сетевых метрик и машинного обучения позволяет эффективно воспроизводить организационную структуру компании даже при наличии дисбаланса классов.

## Основные идеи
- Анализ коммуникационных сетей сотрудников позволяет реконструировать скрытую организационную иерархию.
- Сочетание признаков социальной сети с классическими моделями машинного обучения дает высокую точность классификации.
- Алгоритмы коллективной классификации эффективнее справляются с сильно несбалансированными данными.
- Динамика вариативности связей во времени помогает выявлять паттерны поведения на разных уровнях иерархии.
- Собственная сетевая активность сотрудников не всегда напрямую отражает их формальную руководящую должность.

## Какую проблему решает статья
Традиционный анализ организационных структур требует доступа к внутренним HR-данным, которые часто засекречены или отсутствуют. Существующие методы на базе графов часто упускают из виду стандартные алгоритмы监督нного обучения, а также ограничены исследованием только одного датасета (обычно архива Enron). Кроме того, реальная коммуникация внутри компаний может существенно отличаться от формальной иерархии на бумаге, а распределение сотрудников по уровням должностей всегда сильно несбалансировано.

## Метод

### Общий подход
Строится взвешенный ориентированный граф коммуникаций, где вершины соответствуют сотрудникам, а ребра и их веса отражают интенсивность обмена сообщениями. Из графа извлекаются метрики и поведенческие признаки, которые затем подаются на вход моделям классификации.

### Признаки и архитектура
- Сетевые метрики: центральность по входящим/исходящим связям, промежуточности, близости, собственные векторы, PageRank, Hubs и Authorities.
- Структурные признаки: коэффициент локальной кластеризации, общее количество клик и размер наибольшей клики, в которых состоит сотрудник.
- Динамические признаки: вариативность соседей по отправленным и полученным сообщениям на основе коэффициента Жаккара между месяцами.
- Дополнительные признаки: количество отработанных выходных и сверхурочных (для производственной компании).

### Обучение и валидация
- Оценивались Деревья решений, Случайный лес, Нейронные сети и Метод опорных векторов.
- Для борьбы с дисбалансом классов применялся алгоритм oversampling (SMOTE) на тренировочных фолдах.
- Использовался поиск по сетке гиперпараметров с 5-кратной кросс-валидацией.
- Разработан и протестирован собственный алгоритм коллективной классификации на базе распространения меток по графу.

## Главные результаты
- На датасете производственной компании лучший результат для двух уровней иерархии составил 0.7768 F1-score (Случайный лес), для трех уровней — 0.4737 (Дерево решений).
- На корпусе Enron лучший результат для двух уровней составил 0.8198 F1-score (Случайный лес), для трех уровней — 0.6423 (Случайный лес).
- Алгоритм коллективной классификации показал превосходство на несбалансированных данных, успешно восстанавливая метки даже при значении известных меток менее 50 процентов.
- Собственный вектор центральности (eigenvector centrality) показал наименьшую полезность среди всех признаков во всех моделях.

## Важные концепции
- Коллективная классификация: подход распространения известных меток по ребрам графа соседям, что позволяет учитывать не только индивидуальные признаки узла, но и сетевой контекст.
- Вариативность соседей: метрика изменения круга общения сотрудника во времени, отражающая стабильность его роли.
- Машинное обучение с сетевыми признаками: доказательство того, что паттерны коммуникации тесно связаны со статусом человека в организации.

## Ограничения
- Нарушение предположения независимости и одинакового распределения данных (IID), характерное для сетевых структур.
- Зависимость эффективности моделей от стабильности организационной структуры в течение анализируемого периода.
- Необходимость наличия качественных исторических данных внутренней переписки, которые часто являются конфиденциальными.
- Трудности при масштабировании на крупные международные компании со сложными таймзонами и множеством каналов связи.

## Практическое применение
- Аудит и верификация корпоративных структур в бизнесе.
- Выявление скрытых неформальных лидеров и групп влияния внутри организаций.
- Реверс-инжиниринг структур злоумышленников или закрытых сообществ по частичным метаданным.
- Оптимизация потоков информации и делегирования обязанностей на предприятии.

## Итоговые выводы
- Комбинация анализа социальных сетей и машинного обучения позволяет эффективно реконструировать корпоративную иерархию.
- Модели на основе деревьев обеспечивают высокую интерпретируемость результатов.
- Графовые алгоритмы коллективной классификации эффективнее справляются с несбалансированными организационными данными.
- Поведенческие и структурные признаки важнее для предсказания роли, чем простая центральность.
- Метод применим для различных моделей управления компаниями, что подтверждено на двух разных датасетах.
