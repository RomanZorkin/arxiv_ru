# BERT: Предобучение глубоких двунаправленных трансформеров для понимания языка

## Tags
- masked language model
- bidirectional transformer
- natural language understanding
- transfer learning
- fine-tuning
- sentence representation
- pre-training

## TL;DR
BERT — модель двунаправленного трансформера, предобученная на большом неразмеченном тексте с помощью масок (Masked LM) и предсказания следующего предложения. При дообучении с небольшим числом дополнительных параметров достигает state-of-the-art на 11 NLP-задачах, включая GLUE (80.5%), SQuAD (93.2 F1) и SWAG (86.3%).

## Краткое описание
Авторы предлагают BERT — архитектуру на основе многослойного двунаправленного трансформера-энкодера. Ключевое отличие от предшественников (ELMo, OpenAI GPT) — использование маскированной языковой модели (MLM), которая позволяет учитывать контекст слева и справа на всех уровнях, и задачи предсказания следующего предложения (NSP). Модель сначала предобучается на BooksCorpus (800 млн слов) и английской Wikipedia (2,5 млрд слов), а затем дообучается на целевых задачах с минимальными архитектурными изменениями. BERT BASE (110M параметров) и LARGE (340M) превосходят существующие методы на GLUE на 7.7 процентных пункта, на SQuAD v1.1 — на 1.5 F1, на SQuAD v2.0 — на 5.1 F1. Абляции подтверждают, что двунаправленность и NSP — ключевые источники улучшений. Модель эффективна как в режиме дообучения, так и в feature-based подходе, уступая последнему всего 0.3 F1 на NER.

## Основные идеи
- Двунаправленное контекстное представление за счёт маскированной языковой модели (MLM) вместо однонаправленного LM.
- Совместное предобучение на задаче предсказания следующего предложения (NSP) для улучшения понимания связей между предложениями.
- Унифицированная архитектура трансформера-энкодера, позволяющая дообучаться на разных задачах с минимальными изменениями.
- Масштабирование модели (увеличение числа слоёв и скрытой размерности) даёт улучшения даже на очень малых датасетах (3.6k примеров MRPC).
- Возможность использования как fine-tuning (весь модель дообучается), так и feature-based (фиксированные представления).

## Какую проблему решает статья
Существующие методы предобучения языковых представлений (ELMo, OpenAI GPT) используют однонаправленные языковые модели, что ограничивает учёт контекста с обеих сторон. Это особенно критично для задач, требующих двустороннего контекста (например, question answering) и для token-level задач. Feature-based подходы (ELMo) требуют сложных архитектур; fine-tuning подходы (GPT) используют однонаправленный трансформер-декодер. BERT устраняет эти ограничения, предлагая глубокое двунаправленное предобучение с помощью MLM и NSP, и позволяет простым дообучением достигать превосходных результатов на широком спектре задач без перепроектирования архитектуры.

## Метод
Архитектура — многослойный двунаправленный трансформер-энкодер (Vaswani et al., 2017). Две версии: BERT BASE (12 слоёв, 768 скрытых, 12 голов, 110M параметров) и BERT LARGE (24 слоя, 1024 скрытых, 16 голов, 340M). Вход — последовательность токенов WordPiece (словарь 30k), включающая специальные токены [CLS] (для классификации) и [SEP] (разделитель предложений). Каждый токен представлен суммой токенового, сегментного и позиционного эмбеддингов.

Предобучение на BooksCorpus (800M слов) + Wikipedia (2,5B слов). Два предобучающих задания:
- Masked LM: случайным образом маскируется 15% токенов; из них 80% заменяются на [MASK], 10% на случайный токен, 10% остаются без изменения. Модель должна предсказать исходный токен по контексту.
- Next Sentence Prediction: для 50% пар предложений второе — реальное следующее, для 50% — случайное. Модель предсказывает бинарную метку IsNext/NotNext.

Гиперпараметры: batch size 256 последовательностей (128k токенов), 1 млн шагов, Adam (lr=1e-4), dropout 0.1, gelu активация. Предобучение длится 4 дня на 4–16 Cloud TPU.

Дообучение: для каждой задачи добавляется только один выходной слой. Параметры дообучаются полностью (end-to-end). Гиперпараметры (batch size 16/32, lr 2e-5…5e-5, epochs 2–4) подбираются на dev-сете. Fine-tuning занимает не более часа на одном Cloud TPU.

## Главные результаты
- GLUE: BERT LARGE достигает среднего балла 82.1 (против 75.1 у OpenAI GPT). На MNLI — 86.7% (прирост 4.6%), на QNLI — 92.7%, на SST-2 — 94.9%, на CoLA — 60.5 (Matthews).
- SQuAD v1.1: BERT LARGE single — 90.9 F1, ensemble + TriviaQA — 93.2 F1 (превосходит лидера leaderboard на +1.5 F1).
- SQuAD v2.0: BERT LARGE single — 83.1 F1 (прирост +5.1 F1 над предыдущим лучшим).
- SWAG: BERT LARGE — 86.3% (на 8.3% лучше OpenAI GPT, на 27.1% лучше ESIM+ELMo).
- Абляции: удаление NSP снижает QNLI на 3.5%, SQuAD на 0.6 F1. Замена MLM на односторонний LM даёт падение на SQuAD на 10.7 F1. Увеличение модели с 12 до 24 слоёв даёт +2.2% на MNLI и +1.1 на MRPC.
- Feature-based NER: конкатенация последних 4 слоёв BERT даёт 96.1 F1 (против 96.4 при fine-tuning), что лишь на 0.3 хуже.

## Важные концепции
MLM (Masked Language Model) — ключевая новинка. Она позволяет модели видеть контекст слева и справа от маскированного слова, но создаёт рассогласование с fine-tuning (токен [MASK] не встречается в данных целевых задач). Чтобы смягчить это, авторы не всегда заменяют маскированные токены на [MASK]: в 10% случаев оставляют токен как есть, в 10% заменяют случайным. Это вынуждает модель сохранять контекстные представления всех токенов.

NSP (Next Sentence Prediction) — простая бинарная задача, но она критически важна для задач, требующих понимания отношений между предложениями (QA, NLI). Без неё падает качество на QNLI и MNLI.

Унифицированная архитектура: один и тот же трансформер-энкодер используется для всех задач — меняются только входные/выходные слои. Это резко упрощает применение предобученной модели.

## Ограничения
- Высокие вычислительные затраты на предобучение: BERT LARGE требует 16 Cloud TPU (64 чипа) и 4 дня.
- Рассогласование (mismatch) между предобучением и дообучением из-за [MASK] — хотя авторы частично смягчают его случайными заменами, проблема не исчезает полностью.
- MLM обучается медленнее, чем односторонний LM (предсказывается только 15% токенов), хотя абсолютное качество выше.
- Модель не предназначена для генерации текста (используется только энкодер).
- Fine-tuning больших моделей на очень малых датасетах может быть нестабильным (требуются random restarts).
- Не рассматриваются многозадачные или мультимодальные сценарии.

## Практическое применение
- Question answering (SQuAD, TriviaQA) — извлечение ответа из текста.
- Natural language inference (MNLI, RTE, QNLI) — определение логических отношений между предложениями.
- Sentiment analysis (SST-2) — классификация тональности.
- Semantic textual similarity (STS-B) — оценка семантической близости.
- Named entity recognition (CoNLL-2003) — распознавание именованных сущностей.
- Любая задача, формулируемая как классификация последовательности или пар последовательностей, может быть решена простым дообучением BERT.
- BERT может использоваться как экстрактор признаков (feature-based) для задач, где трудно применить трансформер.

## Итоговые выводы
- BERT впервые демонстрирует, что глубокое двунаправленное предобучение (MLM + NSP) даёт значительный прирост качества на широком спектре NLP-задач.
- Главное преимущество — унифицированная архитектура, требующая минимальных изменений для разных задач.
- Ключевой результат — state-of-the-art на 11 бенчмарках с отрывом в 5–27% (GLUE +7.7%, SQuAD v2.0 +5.1 F1, SWAG +27.1%).
- Главное ограничение — высокие вычислительные затраты на предобучение и mismatch между MLM и fine-tuning.
- Потенциальное влияние — BERT стал основой для большинства последующих NLP-архитектур (RoBERTa, ALBERT, DistilBERT и др.) и широко используется в промышленности.
