# BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding

## Tags
- NLP
- language representation
- pretraining
- transformers
- masked language model
- fine-tuning
- bidirectional encoding

## Краткое описание
BERT — это модель языкового представления на основе двунаправленного Transformer, предобучаемая на больших неразмеченных текстах с помощью двух задач: маскированной языковой модели (MLM) и предсказания следующего предложения (NSP). После предобучения модель донастраивается на конкретные NLP-задачи с минимальными изменениями архитектуры, достигая state-of-the-art на 11 бенчмарках.

## Основные идеи
- Двунаправленный контекст (слева и справа) на всех слоях Transformer позволяет лучше понимать язык, чем однонаправленные модели (GPT, ELMo).
- Маскированная языковая модель (Cloze task) решает проблему двунаправленности, скрывая часть токенов и предсказывая их по контексту.
- Задача предсказания следующего предложения (NSP) улучшает понимание связей между предложениями, что критически важно для QA и NLI.

## Какую проблему решает статья
Существующие методы предобучения (GPT, ELMo) используют однонаправленные языковые модели (слева направо или справа налево), что ограничивает возможность использовать полный контекст. Это особенно вредит задачам на уровне токенов (например, вопросно-ответные системы), где нужна информация с обеих сторон от каждого слова. BERT впервые предлагает действительно глубокий двунаправленный предобучаемый Transformer, который снимает это ограничение.

## Метод

### Подход
Двухэтапный: предобучение на неразмеченных текстах (BooksCorpus + Wikipedia) с двумя вспомогательными задачами, затем донастройка на целевые задачи с добавлением одного выходного слоя.

### Архитектура
Многослойный двунаправленный Transformer encoder. Две конфигурации:
- BERT-Base: 12 слоев, скрытая размерность 768, 12 голов внимания, 110 млн параметров.
- BERT-Large: 24 слоя, скрытая размерность 1024, 16 голов внимания, 340 млн параметров.

### Предобучение
1. **Masked LM (MLM)**: 15% случайных WordPiece-токенов в каждой последовательности маскируются. Модель должна восстановить исходный токен. Для смягчения несоответствия между предобучением и донастройкой: в 80% случаев маскированный токен заменяется на [MASK], в 10% — на случайный токен, в 10% — остаётся неизменным.
2. **Next Sentence Prediction (NSP)**: Для каждой пары предложений модель предсказывает, является ли второе предложение реальным следующим (50% случаев) или случайным (50% случаев).

### Донастройка
Для каждой задачи: вход форматируется как одна последовательность (с токенами [CLS] и [SEP], а также сегментными эмбеддингами). Выход: для задач классификации — представление [CLS]; для токен-уровневых задач — представления всех токенов. Добавляется один обучаемый слой; все параметры донастраиваются совместно.

## Главные результаты
- GLUE score: 80.5% (абсолютное улучшение +7.7%).
- MultiNLI: 86.7% (+4.6%).
- SQuAD v1.1 (F1): 93.2 (+1.5).
- SQuAD v2.0 (F1): 83.1 (+5.1).
- SWAG: 86.3% (+27.1% над ESIM+ELMo, +8.3% над GPT).
- NER (CoNLL-2003): F1 92.8 (BERT-Large fine-tune), 96.1 (feature-based конкатенация последних 4 слоёв даёт 96.1 на dev).
- Абляция: удаление NSP снижает результаты на QNLI и SQuAD; однонаправленная модель (LTR) значительно хуже, особенно на SQuAD; увеличение размера модели даёт выигрыш даже на маленьких датасетах (MRPC с 3600 примерами).

## Важные концепции
- **Двунаправленность**: в отличие от GPT (только левый контекст) или ELMo (конкатенация двух односторонних LSTM), BERT видит полный контекст одновременно на каждом слое.
- **Маскированная языковая модель**: нестандартная LM, где модель учится предсказывать скрытые токены, а не все подряд. Это позволяет избежать «циклического заглядывания» при двунаправленности.
- **Токены [CLS] и [SEP]**: [CLS] — агрегатор представления последовательности для классификации; [SEP] — разделитель предложений. Оба изучаются во время предобучения.
- **Feature-based vs fine-tuning**: BERT эффективен и в режиме извлечения фиксированных признаков (feature-based) без донастройки, достаточно конкатенации последних 4 слоёв.

## Объяснение математических идей
- **MLM (Masked LM)**: случайным образом выбирается 15% токенов. Для каждого такого токена с вероятностью 80% он заменяется на специальный токен [MASK], с вероятностью 10% — на случайный токен, с вероятностью 10% — остаётся неизменным. Модель предсказывает исходный токен по контексту с помощью softmax.
- **NSP (Next Sentence Prediction)**: представление [CLS] после Transformer проходит через бинарный классификатор, предсказывающий, является ли второе предложение истинным следующим (IsNext) или случайным (NotNext).
- **Механизм self-attention в Transformer**: каждый токен может взаимодействовать со всеми токенами последовательности, что позволяет модели захватывать двунаправленный контекст на каждом уровне.

## Ограничения
- MLM предсказывает только 15% токенов за шаг, поэтому требуется больше шагов обучения по сравнению с обычной LM (предсказание всех токенов). Несмотря на это, качество выше.
- Несоответствие между токеном [MASK] в предобучении и его отсутствием при донастройке частично решается смешанной стратегией маскировки, но не полностью.
- Предобучение требует значительных вычислительных ресурсов (BERT-Large на 64 TPU 4 дня).
- Модель не предназначена для генерации текста (декодера), только для понимания.

## Практическое применение
- Вопросно-ответные системы (SQuAD, TriviaQA).
- Классификация текста и определение тональности (SST-2).
- Естественный языковой вывод (MNLI, QNLI, RTE).
- Распознавание именованных сущностей (NER).
- Определение семантического сходства (STS-B).
- Любая задача NLP, где нужно понимание контекста, особенно с ограниченным количеством размеченных данных.

## Итоговые выводы
- BERT — первая модель, которая эффективно предобучает глубокий двунаправленный Transformer.
- Две простые предобучающие задачи (MLM + NSP) позволяют получить универсальное языковое представление, работающее на широком спектре задач.
- Увеличение размера модели даёт существенный прирост качества даже на очень маленьких датасетах.
- BERT применим как в режиме донастройки, так и в режиме извлечения признаков.
- Результаты на 11 бенчмарках превзошли предыдущие state-of-the-art с большим отрывом.
