# An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale

## Tags
- computer vision
- transformers
- self-attention
- image classification
- large-scale pre-training
- ViT
- transfer learning

## Краткое описание
Статья представляет Vision Transformer (ViT) — архитектуру, которая применяет стандартный Transformer напрямую к последовательности патчей изображения, без свёрточных слоёв. При предобучении на больших на больших наборах данных (до 300 млн изображений) ViT достигает или превосходит точность лучших свёрточных сетей (ResNet, EfficientNet) на многих бенчмарках, требуя при этом значительно меньше вычислительных ресурсов для обучения.

## Основные идеи
- Изображение разбивается на патчи фиксированного размера (например, 16x16 пикселей), которые подаются которые подаются в Transformer как последовательность токенов.
- ViT не содержит свёрточных индуктивных смещений (локальность, трансляционная эквивариантность), но при достаточном объёме данных обучается эффективно.
- Предобучение на больших датасетах (JFT-300M, ImageNet-21k) позволяет ViT превзойти CNN, особенно при переносе на задачи с малым количеством данных.

## Какую проблему решает статья
До этой работы Transformer доминировали в NLP, но в компьютерном зрении оставались доминирующими свёрточные сети. Попытки внедрить self-attention в CNN были сложны и не масштабировались. Статья показывает, что чистый Transformer без свёрток может быть эффективен для распознавания изображений, если его предобучать на достаточно больших данных. Это открывает путь к унификации архитектур для текста и изображений.

## Метод

### Подход
- Изображение размера H x W x C разбивается на N патчей размером P x P, где N = H*W / P^2.
- Каждый патч выпрямляется в вектор и линейно проецируется в скрытое пространство размерности D (patch embedding).
- К последовательности патчей добавляется learnable [class] токен (аналогично BERT) и позиционные эмбеддинги (1D learnable).
- Последовательность подаётся в стандартный Transformer Encoder: чередование Multi-Head Self-Attention (MSA) и MLP блоков с LayerNorm и residual connections.
- Выход [class] токена используется для классификации через MLP (при предобучении) или линейный слой (при дообучении).

### Архитектура
- Три варианта: ViT-Base (12 слоёв, 768 скрытых, 12 голов, 86M параметров), ViT-Large (24 слоя, 1024, 16 голов, 307M), ViT-Huge (32 слоя, 1280, ы1280, 16 голов, 632M).
- Размер патча обозначается в названии: ViT-L/16 — Large с патчем 16x16.

### Данные
- Предобучение: ImageNet (1 ImageNet (1.3M изображений, 1k классов), ImageNet-21k (14M, 21k классов), JFT-300M (303M, 18k классов).
- Дообучение на: ImageNet, ImageNet-ReaL, CIFAR-10/100, Oxford-IIIT Pets, Oxford Flowers-102, VTAB (19 задач, 1000 примеров на задачу).

### Эксперименты
- Оптимизатор Adam (beta1=0.9, beta2=0.999, weight decay 0.1), batch size 4096, линейный warmup и decay.
- При дообучении — SGD с momentum, поиск по learning rate.
- Для ImageNet использовали дообучение на более высоком разрешении (512 для ViT-L/16, 518 для ViT-H/14) и Polyak averaging.

## Главные результаты
- ViT-H/14, предобученный на JFT-300M, достигает:
  - ImageNet: 88.55% (лучше BiT-L 87.54%, сравнимо с Noisy Student 88.5%)
  - ImageNet-ReaL: 90.72%
  - CIFAR-100: 94.55%
  - VTAB (19 задач): 77.63%
- ViT-L/16 на JFT-300M превосходит BiT-L на всех задачах при меньших затратах на обучение (0.68k TPUv3-core-days против 9.9k).
- При предобучении на ImageNet-21k ViT уступает ResNet; на ImageNet-21k — сравнивается; на JFT-300M — превосходит.
- ViT использует в 2-4 раза меньше вычислений для достижения той же точности, что и ResNet (по среднему по 5 датасетам).
- Гибридные модели (ResNet + ViT) немного лучше при малых бюджетах, но разница исчезает для больших моделей.
- Self-supervised предобучение (masked patch prediction) даёт 79.9% на ImageNet (ViT-B/16), что на 2% лучше обучения с нуля, но на 4% хуже supervised.

## Важные концепции
- **Patch Embedding**: линейная проекция каждого патча в вектор размерности D.
- **Class Token**: специальный learnable токен, добавляемый в начало последовательности; его выходное состояние используется как представление всего изображения.
- **Position Embedding**: learnable 1D векторы, добавляемые к patch embeddings для сохранения пространственной информации. Модель сама учится кодировать 2D-структуру (близкие патчи имеют похожие эмбеддинги).
- **Attention Distance**: среднее расстояние в пикселях, которое покрывает внимание головы. Аналог рецептивного поля в CNN. В нижних слоях некоторые головы смотрят глобально, другие — локально; с глубиной расстояние растёт.
- **Inductive Bias**: ViT имеет гораздо меньше встроенных предположений о структуре изображения, чем CNN (только разбиение на патчи и интерполяция позиционных эмбеддингов при изменении разрешения).

## Объяснение математических идей
- **Self-Attention**: для каждого элемента последовательности вычисляется взвешенная сумма всех элементов. Веса определяются скалярным произведением запроса (query) данного элемента и ключей (key) всех элементов, нормированным на корень из размерности головы, с последующим softmax. Результат — взвешенная сумма значений (values).
- **Multi-Head Attention**: несколько параллельных self-attention операций (голов) с разными проекциями; их выходы конкатенируются и снова проецируются. Это позволяет модели фокусироваться на разных аспектах одновременно.
- **Patch Embedding**: изображение размером HxWxC преобразуется в последовательность из N векторов, каждый размером P^2*C, затем линейно проецируется в D-мерное пространство. Количество патчей N = H*W / P^2.
- **Position Embedding**: learnable векторы размерности D, добавляемые к каждому patch embedding. Они позволяют модели различать положение патча в последовательности. При изменении разрешения изображения позиционные эмбеддинги интерполируются (2D билинейная интерполяция) для соответствия новому числу патчей.

## Ограничения
- ViT требует больших объёмов данных для эффективного обучения; на средних датасетах (ImageNet) уступает CNN без сильной регуляризации.
- Модель не содержит встроенных индуктивных смещений (локальность, трансляционная эквивариантность), что может быть недостатком при ограниченных данных.
- Self-supervised предобучение пока отстаёт от supervised на 4%.
- Применение к другим задачам (детекция, сегментация) не исследовано в данной работе.
- Вычислительная эффективность на TPU зависит от реализации; некоторые варианты (Axial Attention) медленны на существующем оборудовании.
- Позиционные эмбеддинги требуют интерполяции при изменении разрешения, что может быть неоптимальным.

## Практическое применение
- Классификация изображений в условиях большого количества размеченных данных (JFT-300M, ImageNet-21k).
- Перенос обучения на задачи с малым числом примеров (VTAB, CIFAR, Pets, Flowers).
- Основа для дальнейших исследований в области vision transformers (детекция, сегментация, видео).
- Возможность использования готовых NLP Transformer библиотек с минимальными изменениями.

## Итоговые выводы
- Чистый Transformer без свёрток может быть эффективен для распознавания изображений при предобучении на больших данных.
- ViT превосходит state-of-the-art CNN на многих бенчмарках при значительно меньших затратах на обучение.
- Масштабирование данных компенсирует отсутствие встроенных индуктивных смещений.
- ViT не насыщается по производительности при увеличении размера модели, что мотивирует дальнейшее масштабирование.
- Self-supervised предобучение перспективно, но пока уступает supervised.
