# ClinFusion: Мультимодальная LLM-система для комплексного медицинского анализа

## Tags
- Medical Imaging
- Multimodal LLM
- Vision-Centric Architecture
- 3D Medical Analysis
- Clinical Report Generation
- Instruction Following
- Agentic Workflow

## TL;DR
ClinFusion — это мультимодальная LLM-система для медицины, использующая композиционный визуальный энкодер для обработки 2D и 3D данных. Она превосходит существующие модели в диагностике и генерации отчетов, внедряя RoI-ориентированную оценку и агентные инструменты для повышения точности и проверяемости клинических решений.

## Краткое описание
Медицинские мультимодальные модели (MLLM) сталкиваются с трудностями при обработке гетерогенных 2D и 3D изображений и оценке, которая часто не соответствует клинической практике. ClinFusion решает эти проблемы через композиционную архитектуру энкодера с механизмом каскадного слияния (CaSL Fusion), который объединяет 2D и 3D визуальные признаки. Авторы также представили MedIF-Bench для оценки следования инструкциям и RoI-ориентированную метрику для генерации отчетов, которая лучше коррелирует с мнением радиологов. Система демонстрирует SOTA-результаты на 20 из 24 бенчмарков, превосходя как специализированные медицинские модели, так и мощные проприетарные API (GPT-5.2, Gemini-3-Flash). Агентный модуль с RAG и экспертными инструментами сегментации дополнительно повышает точность и интерпретируемость выводов.

## Основные идеи
- Композиционный визуальный энкодер с каскадным слиянием (CaSL Fusion).
- Нативная поддержка 3D-объемов через 2D-анкоринг.
- MedIF-Bench для оценки способности модели следовать сложным клиническим инструкциям.
- RoI-ориентированная методика оценки отчетов, использующая LLM-судью для анализа фактической точности.
- Агентный подход с использованием внешних инструментов сегментации и RAG.

## Какую проблему решает статья
- Недостаточная эффективность монолитных энкодеров при работе с разнородными медицинскими данными (2D/3D).
- Несоответствие существующих метрик оценки отчетов реальной клинической практике (отсутствие учета контекста и фокуса на патологиях).
- Деградация способности следовать инструкциям при дообучении на медицинских данных.
- Пассивность и отсутствие проверяемости в текущих MLLM-системах.

## Метод
- **Архитектура**: Основана на Qwen-VL, расширена ансамблем энкодеров (DINOv2, ConvNeXt) и нативным 3D-энкодером.
- **CaSL Fusion**: Оператор, который итеративно обогащает базовое визуальное представление признаками из специализированных энкодеров через локальную кросс-аттеншн.
- **3D-обработка**: Использует 2D-анкоры для направления слияния 3D-признаков, сохраняя пространственную непрерывность.
- **Обучение**: Пятиэтапный прогрессивный процесс: от выравнивания энкодеров до финальной настройки на 2D/3D инструкциях.
- **Агентная система**: Включает RAG (векторный поиск + графы знаний) и экспертные инструменты (сегментация органов/поражений, классификация находок).

## Главные результаты
- Превосходство над Hulu-Med и Lingshu на 20 из 24 бенчмарков.
- Конкурентоспособность с GPT-5.2 и Gemini-3-Flash (лучшие результаты на 13 из 16 тестов).
- Высокая корреляция RoI-метрики с экспертной оценкой радиологов (Kendall’s τ=0.511).
- Сохранение способности следования инструкциям (MedIF-Bench score 98.9 для 32B модели).
- Подтвержденное экспертами преимущество в точности, полноте и клинической полезности отчетов.

## Важные концепции
- **CaSL Fusion**: Метод прогрессивного обогащения визуальных признаков, который сохраняет сильную привязку к языковому пространству базовой модели.
- **RoI-Grounded Evaluation**: Оценка отчетов, ограниченная анатомическими областями интереса, что позволяет точно классифицировать находки как истинные, пропущенные или галлюцинированные.
- **Агентное делегирование**: Использование специализированных AI-моделей как «внешних органов чувств» для получения верифицируемых количественных данных (размеры, объемы).

## Ограничения
- Ограниченность текущего набора инструментов (требуется расширение для других модальностей, например, МРТ).
- Разрыв в знаниях на сложных текстовых бенчмарках по сравнению с крупнейшими проприетарными моделями.
- Необходимость дальнейшей валидации в условиях реальной клинической практики (human-in-the-loop).

## Практическое применение
- Автоматизация создания клинических отчетов.
- Интеллектуальная поддержка принятия диагностических решений.
- Интеграция в системы электронных медицинских карт (EHR).
- Инструмент для обучения радиологов и анализа сложных 3D-сканов.

## Итоговые выводы
- ClinFusion предлагает эффективную архитектуру для объединения 2D и 3D медицинских данных.
- RoI-ориентированная оценка — более надежный способ измерения качества отчетов, чем стандартные метрики.
- Агентная интеграция инструментов делает модель проверяемой и пригодной для реальной медицины.
- Сохранение навыков следования инструкциям является критическим фактором для клинической применимости.
- Модульный дизайн позволяет легко масштабировать систему при появлении новых специализированных инструментов.
