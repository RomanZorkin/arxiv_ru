# AnomalyAgent: Агентные модели без обучения для обнаружения аномалий

## Tags
- Anomaly Detection
- Multimodal LLM
- Zero-shot Learning
- Few-shot Learning
- Agentic Framework
- Computer Vision
- Training-free

## TL;DR
AnomalyAgent — это обучающаяся без дообучения агентная система, использующая MLLM для обнаружения аномалий через планирование, использование инструментов и рефлексию. Она превосходит существующие методы за счет глубокого контекстного анализа и самокалибровки по примерам.

## Краткое описание
Статья представляет AnomalyAgent — фреймворк для обнаружения аномалий (AD), который полностью отказывается от обучения на вспомогательных данных. В отличие от классических методов, полагающихся на поверхностное сравнение эмбеддингов (например, CLIP), AnomalyAgent использует возможности мультимодальных больших языковых моделей (MLLM) для активного сбора визуальных доказательств, проверки гипотез и логического вывода.

Система включает два ключевых компонента:
1. Аномально-ориентированный набор инструментов (планирование, визуальная обработка, контрафактическая проверка).
2. Модуль памяти с самокалибровкой, который использует несколько примеров нормальных данных для адаптации логики модели к конкретному домену.

Метод демонстрирует высокую эффективность в задачах, требующих понимания контекста и логических связей (например, в логистике и производстве), достигая результатов, сопоставимых с методами, требующими обучения, при этом оставаясь полностью training-free.

## Основные идеи
- Переход от простого сравнения эмбеддингов к агентному циклу планирования, рассуждения и рефлексии.
- Использование набора инструментов для улучшения качества визуальных данных (деноизинг, супер-разрешение и др.) по запросу агента.
- Контрафактическая проверка гипотез через сопоставление описаний изображения с нормальными и аномальными прототипами.
- Механизм самокалибровки памяти, позволяющий использовать few-shot примеры для уточнения границ нормы без изменения весов модели.

## Какую проблему решает статья
Существующие методы обнаружения аномалий на базе VLM требуют значительного дообучения на вспомогательных датасетах и полагаются на пороговую обработку оценок сходства. Это делает их неэффективными для сложных логических или контекстных аномалий, где требуется глубокое понимание правил и структуры, а не просто поиск визуальных дефектов.

## Метод
- **Архитектура:** Агентный цикл, состоящий из Планировщика, Рассуждателя (Reasoner) и Отражателя (Reflector).
- **Инструментарий:** Включает визуальные инструменты (улучшение качества) и шаблонные инструменты (генерация описаний и сравнение с семантическими прототипами).
- **Pipeline:** Агент анализирует изображение, при необходимости вызывает инструменты для уточнения данных, формирует отчеты и принимает решение. Если уверенности недостаточно, Reflector корректирует план для повторного анализа.
- **Память:** При наличии few-shot примеров нормальных данных, модель строит банк памяти и калибрует веса надежности для кандидатов, чтобы снизить количество ложных срабатываний.

## Главные результаты
- Превосходство над всеми существующими training-free методами (до +2.7% AUROC в zero-shot и +2.8% в few-shot).
- Высокая эффективность на сложных датасетах (MVTec LOCO, Kaputt), где важны логические связи.
- Стабильный рост производительности при увеличении количества примеров (от 1-shot до 4-shot).
- Конкурентоспособность с методами, требующими обучения, без необходимости адаптации параметров.

## Важные концепции
- **Агентный цикл:** Модель не просто выдает оценку, а «рассуждает» над изображением, что позволяет исправлять ошибки через рефлексию.
- **Контрафактическая проверка:** Модель генерирует описания того, как выглядела бы аномалия, и сравнивает их с реальностью, что делает процесс интерпретируемым.
- **Самокалибровка:** Использование нормальных примеров для «обучения» модели тому, что именно в данном домене является нормой, через изменение весов в памяти, а не в нейросети.

## Ограничения
- Зависимость от вычислительной мощности MLLM (требуется вызов API или мощный локальный инференс).
- Потенциальная задержка (latency) из-за многошагового процесса рассуждения.
- Ограниченность производительности при использовании слабых MLLM-бэкендов.

## Практическое применение
- Промышленный контроль качества (дефекты сборки, логические ошибки).
- Медицинская диагностика (анализ снимков, где важен контекст).
- Логистика и складской учет (выявление нарушений правил размещения объектов).
- Системы мониторинга безопасности, требующие интерпретируемых решений.

## Итоговые выводы
- AnomalyAgent успешно переносит агентные возможности MLLM в область обнаружения аномалий.
- Метод обеспечивает высокую точность без необходимости дорогостоящего дообучения.
- Агентный подход позволяет эффективно обрабатывать сложные логические аномалии.
- Механизм самокалибровки памяти является ключевым для адаптации к новым доменам.
- Модель демонстрирует отличную масштабируемость при добавлении few-shot примеров.
