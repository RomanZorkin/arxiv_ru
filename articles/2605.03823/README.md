# Реализуемая байесовская сходимость для общих метрических потерь

## Tags
- metric learning
- Bayes consistency
- Littlestone tree
- universal learning
- unbounded loss
- realizable setting
- combinatorial characterization

## TL;DR
Статья даёт необходимое и достаточное условие для сильной универсальной байесовской сходимости в реализуемой постановке при общих метрических потерях. Ключевой критерий — отсутствие бесконечного неубывающего Littlestone-дерева с растущими разрывами.

## Краткое описание
Рассматривается задача обучения с метрическими потерями на пространстве меток, допускающими неограниченный рост ошибки. В реализуемой постановке (где существует гипотеза с нулевым риском) авторы дают полную характеристику классов гипотез, для которых существует распределённо-независимое правило обучения с риском, сходящимся к нулю почти наверное для всех реализуемых распределений. Главный результат — критерий, основанный на отсутствии бесконечного неубывающего Littlestone-дерева с разрывами, стремящимися к бесконечности. При наличии такого дерева любой алгоритм обучения терпит катастрофические ошибки с бесконечным ожидаемым риском. Отсутствие дерева гарантирует конструктивное правило обучения с сильной байесовской сходимостью. Также показано, что простые условия конечности риска (например, конечность оптимального риска) не обеспечивают сходимость при неограниченных потерях.

## Основные идеи
- Вводится понятие бесконечного неубывающего Littlestone-дерева с растущими разрывами в метках.
- Характеризация реализуемой сильной байесовской сходимости сводится к отсутствию такого дерева в классе гипотез.
- При наличии дерева любой алгоритм обучения имеет бесконечный ожидаемый риск на некотором реализуемом распределении.
- При отсутствии дерева строится явный алгоритм, использующий игру Гейла-Стюарта и локальные алгоритмы для ограниченных подзадач.
- Простые условия, основанные на конечности оптимального риска, не гарантируют сходимость при неограниченных метрических потерях.
- Компактность параметрического пространства и непрерывность отображения гипотезы по параметрам необходимы для эквивалентности различных определений realizability.

## Какую проблему решает статья
Статья решает открытый вопрос о том, при каких условиях на класс гипотез возможно сильное универсальное байесовское обучение с метрическими потерями, допускающими неограниченный рост ошибки, в реализуемой постановке. Ранее известные критерии для ограниченных потерь и регрессии не распространяются на общие метрические потери с неограниченным масштабом.

## Метод
- Формализован класс гипотез на пространстве экземпляров и меток с метрической функцией потерь.
- Определено бесконечное неубывающее Littlestone-дерево с растущими разрывами.
- Построена игра Гейла-Стюарта между противником и обучающимся, отражающая структуру дерева.
- Используется существование измеримой выигрышной стратегии для обучающегося при отсутствии дерева.
- На основе стратегии строится процедура стабилизации, которая после конечного числа шагов формирует ограниченные множества меток для каждого экземпляра.
- Пространство экземпляров разбивается на счётное число ячеек с ограниченным диапазоном меток.
- В каждой ячейке применяется локальный алгоритм MedNet для обучения с ограниченным диапазоном потерь.
- Итоговый алгоритм объединяет локальные предсказания, обеспечивая сильную байесовскую сходимость.

## Главные результаты
- Теорема 4.5: эквивалентность отсутствия бесконечного неубывающего Littlestone-дерева с растущими разрывами и существования распределённо-независимого алгоритма с риском, сходящимся к нулю почти наверное для всех реализуемых распределений.
- Теорема 5.1: при наличии такого дерева любой алгоритм обучения имеет бесконечный ожидаемый риск на некотором реализуемом распределении.
- Теорема 6.5: при отсутствии дерева построен алгоритм, обеспечивающий сильную универсальную байесовскую сходимость.
- Контрпример в разделе 3 показывает, что условие конечности оптимального риска не гарантирует сходимость при неограниченных потерях.
- Примеры классов гипотез, допускающих и не допускающих бесконечное неубывающее Littlestone-дерево, иллюстрируют практическую применимость критерия.

## Важные концепции
- **Бесконечное неубывающее Littlestone-дерево** — полное бинарное дерево с узлами, где на глубине k метки на рёбрах имеют расстояние не меньше γ_k, при этом γ_k → ∞.
- **Реализуемость дерева** — каждая конечная и бесконечная ветвь дерева реализуется гипотезой из класса.
- **Игра Гейла-Стюарта** — формализация взаимодействия обучающегося и противника, где обучающийся пытается избежать бесконечного продолжения игры, что соответствует отсутствию дерева.
- **Стабилизация стратегии** — после конечного числа шагов формируется ограниченный набор меток для каждого экземпляра, содержащий истинную метку.
- **Разбиение пространства экземпляров** — позволяет свести задачу с неограниченными потерями к счётному числу задач с ограниченными потерями.
- **MedNet** — локальный алгоритм для обучения с ограниченными метрическими потерями, используемый в построении итогового алгоритма.

## Ограничения
- Результаты доказаны при предположении компактности параметрического пространства и непрерывности отображения гипотезы по параметрам.
- Без компактности эквивалентность между конечнопрефиксной и бесконечной реализуемостью дерева нарушается.
- Расширение на агностическую постановку (без предположения реализуемости) остаётся открытой проблемой.
- Алгоритм верхней оценки зависит от существования измеримой выигрышной стратегии, которая доказана существующей, но не конструктивна.
- Метод применим к метрическим потерям, но требует полных и сепарабельных пространств экземпляров и меток.

## Практическое применение
- Теоретический фундамент для разработки алгоритмов обучения с общими метрическими потерями, включая мультиклассовую классификацию, регрессию и структурированные выходы.
- Помогает понять, когда возможно построение универсально консистентных алгоритмов при неограниченных потерях.
- Может быть использовано в задачах с большими или бесконечными пространствами меток, где потери не ограничены.
- Основа для дальнейших исследований в области агностического обучения и алгоритмической реализации выигрышных стратегий.
- Важна для разработки устойчивых к редким, но крупным ошибкам алгоритмов в машинном обучении.

## Итоговые выводы
- Введено и доказано необходимое и достаточное условие для сильной универсальной байесовской сходимости при общих метрических потерях в реализуемой постановке.
- Ключевым препятствием является наличие бесконечного неубывающего Littlestone-дерева с растущими разрывами.
- При отсутствии такого дерева построен конструктивный алгоритм с доказанной сходимостью.
- Простые условия конечности риска не гарантируют сходимость при неограниченных потерях.
- Результаты требуют компактности параметрического пространства и непрерывности, без чего эквивалентность нарушается.
- Расширение на агностическую постановку и конструктивное описание стратегии остаются открытыми задачами.
