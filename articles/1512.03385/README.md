# Deep Residual Learning for Image Recognition

## Tags
- computer vision
- image classification
- deep learning
- residual learning
- convolutional neural networks
- ImageNet
- network architecture

## Краткое описание
Статья представляет метод глубокого остаточного обучения (ResNet), который решает проблему деградации (рост ошибки при увеличении глубины сети) путём обучения остаточных функций с использованием shortcut-соединений. Это позволяет строить сети до 152 слоёв на ImageNet с меньшей вычислительной сложностью, чем VGG, и достигать рекордной точности 3.57% top-5 ошибки на тестовом наборе, выиграв ILSVRC 2015.

## Основные идеи
- Вместо прямого отображения H(x) стопка слоёв учит остаточную функцию F(x) = H(x) - x, а затем выход формируется как F(x) + x.
- Identity shortcut-соединения добавляют вход слоя к его выходу без дополнительных параметров и почти без вычислительных затрат.
- Остаточные сети легче оптимизировать, чем обычные "plain" сети той же глубины, и они позволяют извлекать выгоду из значительно большей глубины.

## Какую проблему решает статья
Проблема деградации: при увеличении глубины нейронной сети точность на обучении насыщается и затем быстро падает, хотя это не связано с переобучением. Существующие методы (нормализованная инициализация, Batch Normalization) решают проблему исчезающих/взрывающихся градиентов, но не деградацию. Статья предлагает фреймворк, позволяющий эффективно обучать сети с десятками и сотнями слоёв, получая от этого прирост точности, что было невозможным ранее.

## Метод
**Подход.** Каждый несколько слоёв преобразуются в остаточный блок: выход блока есть сумма выхода стопки слоёв и его входа. Это позволяет градиентам проходить напрямую через shortcut-соединения, упрощая оптимизацию.

**Архитектура.** Базовая архитектура вдохновлена VGG: 3x3 свёртки, удвоение числа фильтров при уменьшении размера карт признаков, Global Average Pooling и полносвязный слой с softmax. Остаточные версии добавляют identity shortcut между каждыми двумя или тремя свёрточными слоями. При изменении размерности используются либо zero-padding, либо проекционные shortcut-соединения (1x1 свёртка) — экспериментально показано, что identity достаточны.

**Бутылочные блоки (Bottleneck).** Для глубоких версий (50, 101, 152 слоя) используется блок из трёх слоёв: 1x1 (уменьшение размерности), 3x3 (узкое горло), 1x1 (восстановление). Это снижает вычислительные затраты, сохраняя точность.

**Обучение.** Используются Batch Normalisation (после каждой свёртки до активации), SGD с batch size 256, learning rate 0.1 (делится на 10 при плато), weight decay 0.0001, momentum 0.9, без dropout. Обучение на ImageNet до ~600k итераций.

**Данные.** ImageNet 2012 (1.28M тренировочных, 50K валидационных, 100K тестовых). CIFAR-10 (50K тренировочных, 10K тестовых). Дополнительно PASCAL VOC и MS COCO для детекции.

**Эксперименты.** Сравнение plain и residual сетей разной глубины на ImageNet. Анализ shortcut-опций (A,B,C). Исследование на CIFAR-10 с сетями до 1202 слоёв. Применение ResNet к детекции объектов через Faster R-CNN.

## Главные результаты
- На ImageNet: 34-слойная residual сеть даёт top-1 ошибку 25.03% против 28.54% у plain версии; при увеличении глубины до 152 слоёв ошибка падает до 21.43% (top-1) и 5.71% (top-5).
- Ансамбль из 6 residual сетей даёт 3.57% top-5 ошибки на тесте ImageNet — 1-е место ILSVRC 2015.
- На COCO детекция: замена VGG-16 на ResNet-101 повышает mAP@[.5,.95] с 21.2% до 27.2% (относительное улучшение 28%).
- На CIFAR-10: 110-слойная сеть достигает 6.43% ошибки (среди лучших на тот момент); 1202-слойная сеть обучается без проблем оптимизации, но имеет 7.93% ошибки из-за переобучения.
- Identity shortcut (опция A) и проекционные (B) дают близкие результаты, разница менее 1%.
- Победы в ImageNet Detection, ImageNet Localization, COCO Detection, COCO Segmentation.

## Важные концепции
- **Residual mapping** (остаток): разность между истинным отображением и входом; сеть учится аппроксимировать этот остаток.
- **Identity shortcut**: соединение, передающее вход без изменений; сумма с выходом стопки слоёв.
- **Degradation problem**: рост ошибки на обучении при добавлении слоёв сверх некоторой глубины; не вызван переобучением или исчезающими градиентами.
- **Bottleneck block (бутылочный блок)**: 1x1-3x3-1x1 свёртки, уменьшающие и восстанавливающие размерность для экономии вычислений.

## Объяснение математических идей
Остаточное обучение переформулирует задачу: вместо изучения отображения H(x) (некоторая функция) стопка нелинейных слоёв учит остаток F(x) = H(x) - x. Тогда H(x) = F(x) + x. Если оптимальное отображение близко к x (тождественному), то F(x) близко к нулю, что легче аппроксимировать, чем H(x) с нуля. Идея подтверждается экспериментально: величины откликов остаточных функций малы (стандартное отклонение ~0.1-0.5), тогда как у обычных сетей они больше.

## Ограничения
- 1202-слойная сеть на CIFAR-10 переобучается (test error хуже, чем 110-слойная), что указывает на необходимость регуляризации (maxout, dropout) для очень глубоких моделей.
- На ImageNet не исследованы сети глубже 152 слоёв.
- Остаточное обучение не решает всех проблем оптимизации; при очень малых начальных learning rate требуется прогрев (warm-up).
- Identity shortcut без параметров достаточно, но проекционные дают незначительное улучшение, но последовательное улучшение; однако они увеличивают время/память, что не оправдано.

## Практическое применение
- Классификация изображений: основы для VGG-замены в любых задачах компьютерного зрения.
- Детекция объектов: улучшение Faster R-CNN (базовый backbone). Сегментация, локализация.
- Другие модальности: архитектура адаптируется для любых задач, где нужна глубокая сеть (аудио, текст, графы).
- Используется как стандартный backbone в современном глубоком обучении.

## Итоговые выводы
- Введён метод остаточного обучения, позволяющий строить сети с десятками и сотнями слоёв без деградации.
- Identity shortcut-соединения без параметров достаточны для решения проблемы и не усложняют обучение.
- Глубокие остаточные сети значительно превосходят предыдущие методы по точности классификации и детекции.
- Результаты подтверждены на нескольких наборах данных (ImageNet, CIFAR-10, COCO) и в разных задачах.
- Работа заложила основу для доминирования ResNet-подобных архитектур в компьютерном зрении на последующие годы.
