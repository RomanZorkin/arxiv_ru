# Глубокое остаточное обучение для распознавания изображений

## Tags
- residual learning
- deep convolutional networks
- ImageNet classification
- degradation problem
- identity shortcuts
- ILSVRC 2015
- object detection

## TL;DR
Предложен фреймворк остаточного обучения (ResNet), в котором слои аппроксимируют остаточные функции относительно входа, а не саму функцию. Это позволило обучить сети глубиной до 152 слоёв, преодолев проблему деградации, и получить 3.57% top-5 ошибки на ImageNet, заняв 1 место ILSVRC 2015.

## Краткое описание
Статья решает проблему деградации: при увеличении глубины сети точность насыщается и падает, причём это вызвано не переобучением, а трудностями оптимизации. Авторы предлагают остаточное обучение: вместо того чтобы аппроксимировать целевую функцию H(x), слои учатся предсказывать остаток F(x) = H(x) - x, а выход вычисляется как F(x) + x. Это реализовано с помощью identity shortcut connections (пропуск одного или нескольких слоёв с поэлементным сложением), которые не добавляют параметров и вычислительной сложности. На ImageNet сеть глубиной 152 слоя (ResNet-152) превзошла все предыдущие одиночные модели (4.49% top-5 error), а ансамбль из 6 моделей дал 3.57%. Выигрыш зафиксирован также на CIFAR-10, COCO, PASCAL VOC. Архитектура стала основой для побед в ILSVRC и COCO 2015 по детекции, локализации, сегментации.

## Основные идеи
- Слои сети обучаются аппроксимировать остаток F(x) = H(x) - x, а не H(x) напрямую.
- Identity shortcut connections добавляют вход слоя к его выходу, не внося новых параметров.
- Проблема деградации решается: ResNet позволяет увеличивать глубину без роста training error.
- Bottleneck-архитектура (1x1, 3x3, 1x1) снижает вычислительную сложность глубоких сетей.
- Identity shortcuts важнее projection shortcuts — разница в точности минимальна.
- Ансамбль ResNet дал 3.57% top-5 error на ImageNet — 1 место ILSVRC 2015.
- Перенос на детекцию (Faster R-CNN) дал 28% относительное улучшение на COCO.

## Какую проблему решает статья
Главная проблема — degradation: при увеличении числа слоёв точность на обучении падает, хотя должна расти (глубокая сеть содержит подрешения мелкой). Проблема не связана с исчезающими градиентами (batch normalization решает это). Оптимизаторы не могут найти решение, близкое к identity mapping для дополнительных слоёв. Статья решает эту проблему, предлагая явное остаточное представление.

## Метод
**Общий подход**: Остаточное обучение. Каждый блок из нескольких слоёв (обычно 2 или 3) аппроксимирует остаток F(x). Выход блока: H(x) = F(x) + x, где x — вход блока. Identity shortcut (прямая связь) не добавляет параметров; при несовпадении размерностей используется проекция (1x1 conv) только при увеличении размерности (option B).

**Архитектура для ImageNet**: Вдохновлена VGG, но с меньшим числом фильтров. Базовые сети 18 и 34 слоя с 3x3 conv. Для глубоких моделей (50, 101, 152) используется bottleneck block: 1x1 уменьшает размерность, 3x3 — bottleneck, 1x1 восстанавливает размерность. Identity shortcuts критически важны для efficiency.

**Обучение**: SGD, batch size 256, lr=0.1, делится на 10 при плато, до 60×10^4 итераций. Weight decay 0.0001, momentum 0.9. Batch normalization после каждой свертки перед активацией. Аугментация: случайный crop 224×224, цветовая аугментация. Тестирование: fully-convolutional, мультимасштабное усреднение.

**CIFAR-10**: Упрощённая архитектура — 3x3 conv, фильтры {16,32,64}. Глубина до 110 и 1202 слоёв.

**Детекция**: Faster R-CNN с заменой VGG-16 на ResNet-101. Шаги: box refinement, global context, multi-scale testing, ensemble.

## Главные результаты
**ImageNet classification** (val, single-model):
- 34-layer plain: 28.54% top-1 error
- 34-layer ResNet A (identity shortcuts, zero-padding): 25.03%
- ResNet-50: 22.85%
- ResNet-101: 21.75%
- ResNet-152: 21.43%
- ResNet-152 (fully-conv, multi-scale): 19.38% top-1, 4.49% top-5

**ImageNet test** (ensemble): 3.57% top-5 — 1 место ILSVRC 2015.

**CIFAR-10** (test):
- ResNet-110 (1.7M params): 6.43% (state-of-the-art)
- ResNet-1202 (19.4M params): 7.93% (overfitting на малых данных)

**COCO detection** (Faster R-CNN):
- VGG-16: 21.2% mAP@[.5,.95]
- ResNet-101: 27.2% (+28% relative improvement)
- С улучшениями: single-model 34.9% mAP@[.5,.95], ensemble 37.4%

**ImageNet localization**:
- VGG-16 (oracle, 1-crop): 33.1% error
- ResNet-101 RPN+RCNN (oracle): 11.7%
- ResNet-101 RPN+RCNN (predicted classes): 10.6%
- Ensemble: 9.0% (64% relative reduction, 1 место)

## Важные концепции
**Почему residual learning работает**: если identity mapping оптимальна, оптимизатору проще обнулить веса, чем учить identity несколькими нелинейными слоями. На практике learned residuals имеют малую амплитуду, что указывает на хорошую preconditioning. **Identity shortcuts** всегда открыты — вся информация проходит, что отличает от highway networks с gating. **Bottleneck design** эффективен за счёт снижения размерности в 3x3 слое; identity shortcuts здесь экономичны, так как не удваивают затраты. **Degradation** не вызван vanishing gradients — обучение с BN даёт нормальные градиенты; проблема, вероятно, в экспоненциально низкой скорости сходимости plain nets.

## Ограничения
- ResNet-1202 на CIFAR-10 хуже ResNet-110 из-за overfitting (мало данных, много параметров).
- Identity shortcuts с zero-padding для увеличения размерности не дают residual learning на доп. измерениях (option A чуть хуже B).
- Использование projection shortcuts во всех блоках (option C) даёт лишь незначительный выигрыш ценой удвоения параметров.
- Метод не решает проблему overfitting при очень большой глубине на малых наборах данных.
- В детекции BN-слои замораживаются при fine-tuning (снижение memory, но потеря адаптации).
- Multi-scale testing только для Fast R-CNN, не для RPN.

## Практическое применение
- Классификация изображений (ImageNet, CIFAR-10/100, медицинские, спутниковые снимки).
- Детекция объектов (Faster R-CNN с ResNet backbone, COCO, PASCAL VOC).
- Семантическая сегментация (сегментационные сети на базе ResNet).
- Локализация объектов (ImageNet LOC).
- Любые задачи CV, где важна глубина представлений.
- Возможное применение в других областях (звук, обработка сигналов) — claimed generic.

## Итоговые выводы
- Главная идея: остаточные связи (residual learning) позволяют обучать очень глубокие сети, преодолевая проблему деградации.
- Главное преимущество: identity shortcuts не добавляют параметров и вычислительной сложности, но радикально улучшают оптимизацию.
- Главный результат: ансамбль ResNet получил 3.57% top-5 error на ImageNet test — 1 место ILSVRC 2015, также победы в детекции, локализации, сегментации.
- Главное ограничение: при экстремальной глубине (1000+ слоёв) на малых данных возникает overfitting, не решаемый без сильной регуляризации.
- Потенциальное влияние: ResNet стал стандартной архитектурой для компьютерного зрения и вдохновил множество последующих работ (ResNeXt, DenseNet, etc.).
