# Обучение самоэволюции (Learning to Self-Evolve)

## Tags
- Reinforcement Learning
- Large Language Models
- Test-time Adaptation
- Prompt Optimization
- Self-improvement
- Tree Search
- Agentic Systems

## TL;DR
Статья представляет LSE — фреймворк обучения с подкреплением, который тренирует LLM эффективно улучшать свои инструкции (промпты) в процессе работы. Метод использует одношаговую оптимизацию на основе улучшения производительности и древовидный поиск для навигации по пространству контекстов.

## Краткое описание
Авторы решают проблему статической природы LLM после завершения обучения. В отличие от существующих методов, полагающихся на «врожденные» способности моделей к саморефлексии, LSE (Learning to Self-Evolve) явно тренирует модель как «самоэволюционирующую политику». 

Предложенный подход сводит задачу многошаговой эволюции к одношаговой цели обучения с подкреплением (RL), где наградой служит не абсолютный результат, а прирост точности после редактирования промпта. В сочетании с древовидным поиском (tree-guided search) это позволяет системе эффективно исследовать пространство контекстов, избегая локальных минимумов. Эксперименты на задачах Text-to-SQL (BIRD) и QA (MMLU-Redux) показывают, что модель с 4 млрд параметров, обученная с помощью LSE, превосходит по эффективности промпт-оптимизаторы (GEPA, TextGrad) и даже более крупные модели (GPT-5, Claude Sonnet 4.5).

## Основные идеи
- Формализация самоэволюции как обучаемого навыка через RL.
- Использование дельта-награды (прироста точности) для обучения модели редактированию промптов.
- Применение древовидного поиска (UCB) для предотвращения необратимых ошибок при итеративном редактировании.
- Перенос навыка самоэволюции на другие модели без дополнительного дообучения.
- Одношаговая аппроксимация задачи для упрощения кредитного распределения.

## Какую проблему решает статья
Существующие LLM после развертывания остаются статичными: они не накапливают опыт решения задач в рамках домена. Методы автоматической оптимизации промптов (как GEPA или TextGrad) полагаются на «эмерджентные» способности моделей, которые не были специально обучены для саморефлексии. Это приводит к неэффективному поиску и риску деградации качества при неудачных правках.

## Метод
- **Архитектура:** Используется LLM (Qwen3-4B-Instruct) как «самоэволюционирующая политика», которая получает текущий контекст и сводку производительности, выдавая обновленный промпт.
- **Оптимизация:** Обучение через RL с функцией награды, равной разности точности после и до редактирования. Это устраняет зависимость от начального качества промпта.
- **Поиск:** Древовидный алгоритм с UCB-оценкой узлов позволяет системе возвращаться к успешным версиям промптов, если текущая ветка эволюции ведет к снижению метрик.
- **Данные:** Обучение проводится на траекториях, сгенерированных в процессе эволюции, с использованием curriculum-сэмплирования наиболее перспективных узлов.

## Главные результаты
- **Эффективность:** Модель 4B превосходит GPT-5 и Claude Sonnet 4.5 в задачах Text-to-SQL на датасете BIRD.
- **Превосходство:** LSE стабильно обходит методы GEPA и TextGrad, обеспечивая более стабильный и качественный прирост точности.
- **Transfer Learning:** Стратегия самоэволюции, обученная на Qwen3-4B, успешно улучшает работу специализированных моделей (например, Arctic-Text2SQL), подтверждая универсальность метода.
- **Устойчивость:** Древовидный поиск предотвращает «коллапс» производительности, характерный для линейных цепочек редактирования.

## Важные концепции
- **Improvement-based Reward:** Награда за дельту точности позволяет модели учиться именно *улучшению*, а не просто сохранению высокого уровня, что критично для обучения навыку рефлексии.
- **Tree-guided Evolution:** Использование UCB-поиска превращает процесс оптимизации промпта в управляемый процесс исследования, где модель может «откатывать» неудачные изменения.

## Ограничения
- **Масштабируемость:** Требуется отдельное обучение для каждого домена задач.
- **Сложность:** Оптимизация сведена к одношаговой, что упрощает обучение, но может уступать полноценной оптимизации траекторий.
- **Среда:** Эффективность метода сильно зависит от наличия качественной обратной связи (feedback) в среде.
- **Область применения:** Ограничено редактированием только текстовых инструкций, без изменения инструментов или внешней памяти.

## Практическое применение
- **Production:** Автоматическая адаптация промптов агентов под специфические базы данных или доменные области.
- **Research:** Создание самообучающихся систем, которые адаптируются к новым данным без необходимости переобучения весов модели.
- **Industry:** Повышение точности SQL-генераторов в специфических корпоративных средах.

## Итоговые выводы
- Самоэволюция — это обучаемый навык, а не просто эмерджентное свойство LLM.
- Оптимизация на основе прироста точности (delta-reward) является более эффективным сигналом для обучения, чем абсолютные метрики.
- Древовидный поиск критически важен для надежности процесса саморефлексии.
- Метод позволяет даже небольшим моделям (4B) конкурировать с frontier-моделями в задачах адаптации.
- LSE открывает путь к созданию систем, которые становятся лучше по мере накопления опыта в конкретной предметной области.
