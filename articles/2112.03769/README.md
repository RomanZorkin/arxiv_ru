# Машинное обучение в поиске новой фундаментальной физики

## Tags
- High Energy Physics
- Deep Learning
- Anomaly Detection
- Particle Physics
- Data Analysis
- Model Agnostic
- Physics Simulation

## TL;DR
Статья представляет обзор современных методов машинного обучения, применяемых для поиска новой физики за пределами Стандартной модели в экспериментах на коллайдерах, нейтринных детекторах и установках по поиску редких событий.

## Краткое описание
Стандартная модель физики частиц успешно описывает известные взаимодействия, однако не объясняет такие явления, как темная материя, масса нейтрино и барионная асимметрия Вселенной. Поиск новой физики (BSM) осложняется редкостью сигналов и их схожестью с фоновыми процессами Стандартной модели. Авторы анализируют, как методы глубокого обучения позволяют эффективно обрабатывать огромные объемы данных, находить тонкие закономерности и проводить анализ в многомерных пространствах признаков. В обзоре рассматриваются подходы от полностью контролируемого обучения (supervised) до методов с частичным или отсутствующим контролем (unsupervised, weakly-supervised), которые позволяют проводить поиск новой физики без жесткой привязки к конкретным теоретическим моделям. Особое внимание уделено интеграции ML в этапы сбора данных, реконструкции и финального статистического анализа.

## Основные идеи
- Переход от анализа инженерных признаков к глубокому обучению на низкоуровневых данных.
- Использование симметрий (трансляционная, перестановочная) в архитектурах нейросетей (CNN, GNN, Deep Sets).
- Применение методов без учителя (autoencoders, normalizing flows) для обнаружения аномалий.
- Развитие слабоконтролируемого обучения для поиска сигналов без точных меток.
- Интеграция ML в триггерные системы реального времени (FPGA, GPU).
- Улучшение точности симуляций с помощью генеративных моделей.

## Какую проблему решает статья
Статья решает проблему поиска редких сигналов новой физики в условиях огромных массивов данных. Традиционные методы, основанные на жестко заданных теоретических моделях, имеют «слепые зоны». Современные подходы позволяют анализировать данные более целостно, снижая зависимость от конкретных теоретических предположений и повышая чувствительность к неожиданным отклонениям от Стандартной модели.

## Метод
Авторы классифицируют методы по уровню контроля:
- Полностью контролируемые: обучение классификаторов на симулированных данных сигнала и фона.
- Менее чем контролируемые: использование данных без меток или с зашумленными метками для поиска аномалий.
- Архитектуры: использование CNN для изображений (калориметры), RNN/рекурсивных сетей для последовательностей/деревьев (струи), а также графовых нейронных сетей (GNN) и Deep Sets для обработки неупорядоченных наборов частиц.
- Обучение: минимизация функций потерь (кросс-энтропия, среднеквадратичная ошибка) или максимизация правдоподобия (в нормализующих потоках).

## Главные результаты
- Глубокое обучение на низкоуровневых данных (четырех-импульсы частиц) демонстрирует производительность, равную или превосходящую методы, использующие физически сконструированные признаки.
- Успешная интеграция ML-алгоритмов в системы триггеров (HLT) на LHC для отсева фоновых событий.
- Разработка методов декореляции (например, для bump hunts), позволяющих избежать формирования ложных сигналов в распределениях масс.
- Успешное применение GNN в экспериментах типа IceCube для работы с нерегулярными геометриями детекторов.

## Важные концепции
- Аномальное обнаружение: поиск событий, которые статистически далеки от ожидаемого фона Стандартной модели.
- Декореляция: методы, гарантирующие, что классификатор не «выучивает» резонансную особенность (например, массу), что критично для поиска новых частиц.
- Слабое обучение (Weak supervision): использование смешанных выборок данных для обучения классификатора, когда точные метки недоступны.

## Ограничения
- Высокая вычислительная стоимость обучения и инференса при работе с большими объемами данных.
- Чувствительность моделей к неточностям в симуляциях (domain adaptation).
- Сложность интерпретации результатов, полученных «черными ящиками» нейронных сетей.
- Необходимость длительного цикла разработки для внедрения методов в полноценный анализ данных.

## Практическое применение
- Ускорение обработки данных в экспериментах на коллайдерах (LHC, Belle II).
- Улучшение реконструкции событий в нейтринных детекторах (DUNE, MicroBooNE).
- Повышение чувствительности в экспериментах по прямому поиску темной материи и безнейтринного двойного бета-распада.
- Разработка систем триггеров реального времени для высокоэнергетических экспериментов.

## Итоговые выводы
- Машинное обучение стало неотъемлемой частью современной физики высоких энергий.
- Методы без учителя открывают путь к поиску новой физики, не предсказанной текущими теориями.
- Ключевым вызовом остается интеграция ML в надежные статистические процедуры с учетом систематических погрешностей.
- Будущее исследований связано с объединением методов ML с физическими принципами для обеспечения интерпретируемости.
