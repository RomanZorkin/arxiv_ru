# Могут ли большие языковые модели предсказывать увольнение сотрудников?

## Tags
- HR analytics
- employee attrition
- GPT-3.5 fine-tuning
- predictive modeling
- large language models
- machine learning classifiers
- workforce retention

## TL;DR
В статье исследуется применимость тонко настроенной модели GPT-3.5 для прогнозирования текучести кадров. Предложенный подход сравнивается с классическими алгоритмами машинного обучения на датасете IBM HR Analytics и демонстрирует превосходство по ключевым метрикам качества.

## Краткое описание
Прогнозирование увольнений сотрудников является критически важной задачей для оптимизации расходов компаний и сохранения ценных кадров. Авторы решают проблему ограничения традиционных статистических методов и стандартных классификаторов машинного обучения, которые часто не способны учесть сложные нелинейные закономерности поведения рабочей силы. В качестве решения предлагается дообучение языковой модели GPT-3.5 Turbo на структурированных данных о сотрудниках. Эксперименты проводятся на датасете IBM HR Analytics Employee Attrition. Результаты показывают, что тонко настроенная модель GPT-3.5 существенно превосходит классические подходы, достигая F1-скора 0.92, тогда как лучший традиционный алгоритм Support Vector Machine останавливается на показателе 0.82. Работа открывает новые перспективы применения генеративного искусственного интеллекта в управлении человеческими ресурсами.

## Основные идеи
- Применение тонко настроенной модели GPT-3.5 для предсказания увольнений сотрудников.
- Сравнение возможностей LLM с классическими алгоритмами машинного обучения.
- Использование набора данных IBM HR Analytics с предварительной очисткой и балансировкой классов.
- Генерация новых признаков для упрощения данных без потери информации.
- Демонстрация высокой точности языковой модели в задачах классификации.

## Какую проблему решает статья
Традиционные методы прогнозирования текучести кадров опираются на ручной анализ исторических данных, опросы и базовые статистические подходы. Они ограничены в масштабируемости, точности и не могут полностью отразить сложную динамику поведения современного персонала. Существующие классификаторы машинного обучения также имеют предел в точности. Статья закрывает этот пробел, исследуя потенциал больших языковых моделей в интерпретации контекстуальной информации и выявлении скрытых факторов риска увольнения.

## Метод

### Подготовка данных
Исследование использует датасет IBM HR Analytics, содержащий 1470 записей и 35 атрибутов. Из набора удалены константные и избыточные признаки. Признаки с правосторонней асимметрией более 0.5 обработаны логарифмическим преобразованием. Созданы два композитных признака: WorkExperience и OverallSatisfaction. Категориальные переменные закодированы с помощью label encoding. Данные разделены на обучающую (80%) и тестовую (20%) выборки со стратификацией.

### Балансировка и масштабирование
Для устранения сильного дисбаланса классов применен метод синтетического избыточного сэмплирования меньшинства SMOTE, уравнявший количество примеров в классах для обучения. Проведена стандартизация числовых признаков.

### Обучение моделей
Обучены классические алгоритмы: логистическая регрессия, KNN, SVM, решающие деревья, случайный лес, AdaBoost и XGBoost. Модель GPT-3.5 Turbo дообучена через OpenAI API с использованием пар промпт-ответ в формате JSONL.

## Главные результаты
- Тонко настроенная модель GPT-3.5 продемонстрировала наилучшие результаты: точность 0.91, полнота 0.94 и F1-скор 0.92.
- Среди традиционных методов лучший результат показал Support Vector Machine с F1-скором 0.82.
- Ансамблевые методы Random Forest и XGBoost достигли F1-скора 0.80.
- Логистическая регрессия и AdaBoost показали F1-скор 0.78 и 0.79 соответственно.
- Наихудший результат зафиксирован у алгоритма KNN с F1-скором 0.71.

## Важные концепции
- Тонкая настройка LLM для задач классификации: адаптация генеративной языковой модели для выдачи бинарного результата о рисках увольнения.
- Синтетическое сэмплирование (SMOTE): метод борьбы с дисбалансом данных для улучшения обнаружения редкого класса увольняющихся сотрудников.
- Создание композитных признаков: объединение связанных метрик опыта работы и удовлетворенности для снижения размерности данных.

## Ограничения
- Исследование ограничено одним конкретным датасетом IBM HR Analytics.
- Фокус сделан преимущественно на структурированных атрибутах без глубокого анализа свободных текстовых коммуникаций сотрудников.
- Использование коммерческого API для дообучения может нести дополнительные финансовые затраты.
- Требуется дальнейшая оценка интерпретируемости решений модели в реальной бизнес-среде.

## Практическое применение
- Разработка продвинутых HR-систем для раннего предупреждения об увольнении ключевых сотрудников.
- Автоматизация аналитики кадров в корпоративных отделах управления персоналом.
- Создание проактивных стратегий удержания персонала на основе предсказаний искусственного интеллекта.
- Улучшение точности бизнес-решений в сфере управления человеческими ресурсами.

## Итоговые выводы
- Тонко настроенные большие языковые модели превосходят традиционные методы машинного обучения в задачах прогнозирования увольнений.
- Метод GPT-3.5 достигает высокого уровня точности и полноты на несбалансированных кадровых данных.
- Поддержка качественного отбора признаков и балансировки критически важна для стабильности классификаторов.
- Подход подтверждает потенциал интеграции LLM в аналитические конвейеры HR-менеджмента.
- Ограничение связано с необходимостью проверки интерпретируемости моделей в реальных бизнес-условиях.
