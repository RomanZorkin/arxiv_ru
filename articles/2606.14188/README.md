# Устойчивость без складок: параллельное моделирование и робастное MPC для сертифицированного манипулирования деформируемыми объектами

## Tags
- Robotics
- Deformable Manipulation
- Differentiable Simulation
- Robust Control
- Model Predictive Control
- System Level Synthesis
- Conformal Prediction

## TL;DR
CORD-SLS — это метод управления в реальном времени для манипулирования веревками и тканью, использующий дифференцируемый GPU-симулятор и робастное MPC. Система обеспечивает высокую вероятность безопасности за счет калибровки неопределенностей через конформное предсказание.

## Краткое описание
Статья представляет CORD-SLS — фреймворк для безопасного манипулирования деформируемыми объектами (веревки, ткань). Основная проблема заключается в сложности управления такими объектами из-за высокой размерности, нелинейной динамики и прерывистых контактов. Авторы предлагают GPU-параллельный дифференцируемый симулятор с механизмом сглаживания контактов, который обеспечивает информативные градиенты для планирования. Для обеспечения робастности при наличии неопределенностей в динамике и восприятии используется метод MPC на основе синтеза системного уровня (SLS) с обратной связью по выходу. Безопасность гарантируется с помощью конформного предсказания, которое калибрует границы ошибок восприятия и модели, формируя достижимые трубки состояний. Метод позволяет выполнять планирование в миллисекундном диапазоне и превосходит существующие подходы по скорости, безопасности и успешности выполнения задач в симуляции и на реальном оборудовании.

## Основные идеи
- GPU-параллельный дифференцируемый симулятор сглаживает контактные взаимодействия для получения градиентов.
- Робастное MPC на основе SLS с обратной связью по выходу обеспечивает управление в реальном времени.
- Использование конформного предсказания для калибровки границ неопределенности восприятия.
- Ускорение обучения нейросетевых политик с помощью аналитических градиентов из симулятора.
- Реализация на реальном оборудовании с использованием трекинга ключевых точек.

## Какую проблему решает статья
Существующие методы манипулирования деформируемыми объектами либо слишком медленны для реального времени, либо не обеспечивают гарантий безопасности. Дифференцируемые симуляторы часто страдают от проблем с градиентами при контактах, а методы обучения с подкреплением требуют огромного количества данных и не гарантируют робастность.

## Метод
- **Симулятор:** Использует неявную схему интегрирования и сглаживание контактов (через релаксацию условий дополняемости), что позволяет вычислять градиенты через контактные события.
- **Планирование:** GPU-параллельный SLS-контроллер оптимизирует номинальную траекторию и политику обратной связи, учитывая ограничения безопасности.
- **Обучение:** Аналитические градиенты политики (APG) ускоряют обучение нейросетевых агентов.
- **Безопасность:** Конформное предсказание (CP) калибрует остаточные ошибки восприятия, создавая "трубки" достижимости, внутри которых гарантируется нахождение объекта с заданной вероятностью.

## Главные результаты
- Ускорение вычислений в 700 раз для прямого моделирования и в 2000 раз для вычисления якобианов по сравнению с аналогами.
- Успешное выполнение задач (подъем веревки, обход препятствий, складывание ткани) в реальном времени (MPC-обновление < 1 сек).
- Высокая частота успеха и безопасности (до 100%) в сложных контактных задачах, где базовые методы (MPPI) показывают низкую надежность.
- Эффективное обучение политик с меньшим количеством взаимодействий с средой по сравнению с PPO.

## Важные концепции
- **Сглаживание контактов:** Замена жестких условий контакта на гладкие суррогаты для обеспечения информативных градиентов при планировании.
- **SLS (System Level Synthesis):** Фреймворк для синтеза контроллеров, который позволяет эффективно решать задачи робастного управления через выпуклую оптимизацию.
- **Конформное предсказание:** Статистический метод, позволяющий строить доверительные интервалы (трубки) для состояний системы без жестких предположений о распределении ошибок.

## Ограничения
- Сглаживание контактов вносит небольшие модельные ошибки вблизи моментов переключения контактов.
- Восприятие сложных топологий при сильных окклюзиях остается сложной задачей.
- Потребление памяти растет с увеличением размерности системы и горизонта планирования.

## Практическое применение
- Роботизированная логистика и складская автоматизация.
- Домашняя робототехника (работа с одеждой, проводами).
- Хирургическая робототехника (манипуляции с мягкими тканями).

## Итоговые выводы
- CORD-SLS объединяет дифференцируемое моделирование и робастное управление для работы с деформируемыми объектами.
- Главное преимущество — возможность планирования в реальном времени с гарантиями безопасности.
- Метод значительно эффективнее классических методов планирования (MPPI) и обучения (PPO).
- Использование конформного предсказания позволяет успешно переносить политики из симуляции на реальное оборудование.
- Подход масштабируется до высокоразмерных задач, таких как складывание ткани.
