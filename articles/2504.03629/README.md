# SeGuE: Семантически управляемое исследование для мобильных роботов

## Tags
- semantic mapping  
- next-best-view  
- mobile robots  
- semantic features  
- importance sampling  
- autonomous exploration  
- embodied AI  

## TL;DR
Предложен метод SeGuE для автономного исследования мобильным роботом, который строит карту с семантическими признаками, используя оценку энтропии видимых семантических признаков для выбора следующей точки обзора. Метод проверен в симуляции и на реальном роботе, показывая улучшение качества семантических карт по сравнению с базовыми подходами.

## Краткое описание
Статья решает задачу автономного семантического исследования среды мобильным роботом с целью построения карты, содержащей не только геометрию, но и семантические признаки. В отличие от классических методов, ориентированных только на структуру, предлагается оценивать потенциальные позиции робота по средней энтропии семантических признаков, видимых с этих позиций. Для выбора позиций используются два метода сэмплирования: равномерное и важностное (основанное на частицах). В экспериментах на двух симулированных средах и в реальных условиях показано, что SeGuE обеспечивает более высокое покрытие карты семантическими признаками и снижает среднюю энтропию, что свидетельствует о более качественном и информативном картировании. Метод применим для задач embodied AI, где требуется глубокое понимание среды.

## Основные идеи
- Введение нового подхода к семантическому исследованию среды с учётом семантических признаков, а не только геометрии.  
- Оценка позиций робота по средней энтропии семантических признаков для максимизации информации.  
- Использование двух стратегий сэмплирования позиций: равномерного и важностного (particle filter).  
- Отслеживание сходимости энтропии признаков для исключения переизученных областей.  
- Валидация метода в симуляции и на реальном роботе с улучшением метрик качества карты.  

## Какую проблему решает статья
Классические методы исследования среды мобильными роботами ориентированы на геометрию и не учитывают семантические признаки, что снижает качество карт для задач embodied AI. Существующие семантические карты часто требуют ручного управления или не обеспечивают полноту семантического покрытия. Важно разработать метод, который автоматически направляет исследование для создания высококачественных семантических карт, пригодных для различных задач и сред.

## Метод

### Общий подход
SeGuE расширяет классический next-best-view (NBV) подход, добавляя семантическую оценку позиций. Робот строит 2D карту, где каждая ячейка содержит вектор семантических признаков и информацию о занятости.

### Архитектура и pipeline
- Семантические признаки извлекаются из RGB-изображений с помощью модели DinoV2 и классификатора, обученного на ADE20K.  
- 3D точки из LiDAR проецируются на 2D карту для связывания с семантическими признаками.  
- Для каждой потенциальной позиции вычисляется средняя энтропия видимых семантических признаков, исключая уже сойдённые по энтропии.  
- Позиции с максимальным значением энтропии выбираются для дальнейшего исследования.

### Обучение и данные
Используются предобученные модели для извлечения признаков. Карты строятся онлайн в процессе исследования.

### Оценка
Метрики: покрытие карты семантическими признаками (процент ячеек с признаками) и средняя энтропия карты (качество признаков). Эксперименты проведены в симуляторах Small House и Bookstore, а также в реальной среде (столовая кампуса).

## Главные результаты
- SeGuE превосходит классические frontier-based и NBV методы по покрытию и снижению энтропии.  
- В Small House покрытие до 0.94 и средняя энтропия около 0.67 (лучшие показатели).  
- В Bookstore покрытие около 0.94 и энтропия около 0.72.  
- В реальных условиях покрытие 0.735 и энтропия 1.75, что ниже симуляции из-за ограничений планировщика и времени работы.  
- Важностное сэмплирование улучшает эффективность использования метрики по сравнению с равномерным.  
- Оптимальное число сэмплов для равномерного сэмплирования — 100–200, избыток приводит к переизучению.

## Важные концепции
- Энтропия семантических признаков служит мерой неопределённости и информационной ценности позиции.  
- Видимость ячеек с помощью трассировки лучей ограничивает оценку только теми признаками, которые реально можно наблюдать.  
- Отслеживание сходимости энтропии предотвращает излишнее внимание к шумным или неоднозначным признакам.  
- Важностное сэмплирование использует распределение вероятностей, пропорциональное оценкам позиций, для более эффективного поиска оптимальных точек обзора.

## Ограничения
- Метод наследует ограничения next-best-view алгоритмов, включая зависимость от качества сэмплирования и оценки позиций.  
- Используются только глобальные методы сэмплирования, что может приводить к локальным максимумам.  
- Предполагается плоская и проходимая среда, что ограничивает применение в сложных ландшафтах.  
- В реальных условиях производительность ограничена планировщиком движения и ресурсами робота (например, временем работы батареи).

## Практическое применение
- Автономное исследование и картирование в робототехнике, особенно для indoor навигации.  
- Поддержка embodied AI приложений, требующих семантического понимания среды (например, автоматизированные кухни, фермы).  
- Улучшение систем визуального поиска объектов и навигации с языковыми инструкциями.  
- Применимо в промышленности, сельском хозяйстве, сервисных роботах и исследовательских платформах.

## Итоговые выводы
- Представлен метод SeGuE для семантически управляемого исследования мобильным роботом.  
- Основное преимущество — улучшенное качество семантических карт за счёт оценки энтропии признаков.  
- Экспериментально подтверждена эффективность в симуляции и реальных условиях.  
- Ограничения связаны с зависимостью от сэмплирования и предположениями о среде.  
- Метод способствует развитию более интеллектуальных и адаптивных систем embodied AI.
