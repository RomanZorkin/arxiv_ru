# You Only Look Once: Unified, Real-Time Object Detection

## Tags
- object detection
- real-time detection
- convolutional neural network
- single-shot detector
- Pascal VOC
- regression-based detection
- transfer learning

## TL;DR
YOLO формулирует детекцию объектов как задачу регрессии: одна свёрточная сеть предсказывает bounding boxes и классы напрямую из полного изображения. Это обеспечивает real-time скорость (45-155 FPS) при competitive точности (63.4% mAP на VOC 2007) и хорошей обобщаемости на новые домены.

## Краткое описание
Существующие детекторы (DPM, R-CNN) используют сложные многоэтапные pipeline: выделение регионов-кандидатов, классификация каждого, пост-обработка. Это медленно и трудно оптимизируется. Авторы предлагают YOLO — единую свёрточную сеть, которая за один прямой проход предсказывает bounding boxes и вероятности классов для всех объектов на изображении. Изображение делится на сетку (7x7). Каждая ячейка предсказывает 2 bounding boxes и confidence scores, а также условные вероятности классов (20 классов на Pascal VOC). Итоговый выход — тензор 7x7x30. YOLO обучается end-to-end на полных изображениях с помощью многочастной функции потерь, штрафующей ошибки локализации и классификации. Основной результат: YOLO достигает 63.4% mAP на Pascal VOC 2007 при 45 FPS, а Fast YOLO — 52.7% mAP при 155 FPS. YOLO делает меньше ложных срабатываний на фоне, чем Fast R-CNN, но больше ошибок локализации. YOLO превосходит DPM и R-CNN при переносе с natural images на artwork (Picasso, People-Art).

## Основные идеи
- Детекция как единая задача регрессии, а не классификация регионов.
- Одна свёрточная сеть обрабатывает всё изображение за один проход.
- Сеточное представление для пространственного разделения объектов.
- Специализация предсказателей bounding boxes через assign по максимальному IOU при обучении.
- Loss function с разными весами для локализации (lambda_coord=5) и отсутствия объектов (lambda_noobj=0.5).
- Предсказание квадратного корня ширины/высоты для учёта разницы масштабов.

## Какую проблему решает статья
Традиционные детекторы (DPM, R-CNN, Fast R-CNN) используют многоступенчатые pipeline: извлечение регионов (Selective Search), классификация каждого региона, пост-обработка. Это приводит к высокой задержке (R-CNN — >40 сек на изображение, Fast R-CNN — 0.5 FPS) и сложности оптимизации (каждый компонент обучается отдельно). YOLO решает проблему скорости и простоты, объединяя все этапы в одну нейросеть, которая работает за 25 мс на изображение.

## Метод
YOLO использует свёрточную сеть, вдохновлённую GoogLeNet: 24 свёрточных слоя (1x1 reduction + 3x3 conv) и 2 полносвязных слоя. Fast YOLO — облегчённая версия с 9 свёрточными слоями. Входное изображение масштабируется до 448x448. Сеть предсказывает тензор S x S x (B*5 + C), где S=7, B=2, C=20 (Pascal VOC). Каждый bounding box состоит из (x, y, w, h, confidence). Координаты нормализованы относительно ячейки и изображения. Confidence = вероятность объекта * IOU с ground truth.

Обучение: предобучение на ImageNet (первые 20 слоёв), затем дообучение на Pascal VOC 2007+2012 с увеличенным разрешением. Функция потерь оптимизирует сумму квадратичных ошибок с весами lambda_coord=5 для локализации и lambda_noobj=0.5 для confidence пустых ячеек. Используется leaky ReLU (0.1 для отрицательных значений). Аугментация: случайное масштабирование (+20%), сдвиги, изменение экспозиции/насыщения (HSV, фактор до 1.5). Dropout 0.5 после первого полносвязного слоя. Скорость обучения: постепенный рост от 1e-3 до 1e-2, затем 1e-2 (75 эпох), 1e-3 (30), 1e-4 (30). Batch size 64, momentum 0.9, weight decay 0.0005.

Инференс: один прямой проход, не-maximum suppression добавляет 2-3% mAP.

## Главные результаты
- На Pascal VOC 2007: YOLO — 63.4% mAP при 45 FPS, Fast YOLO — 52.7% mAP при 155 FPS (лучший real-time детектор на момент публикации).
- YOLO VGG-16: 66.4% mAP, но 21 FPS (ниже real-time).
- Сравнение с real-time системами: 100Hz DPM (16.0 mAP), 30Hz DPM (26.1 mAP), Fastest DPM (30.4 mAP при 15 FPS). YOLO превосходит их по mAP в 2-3 раза.
- Ошибки: YOLO даёт 4.9% background false positives против 13.6% у Fast R-CNN. Основная проблема YOLO — локализационные ошибки.
- Комбинация YOLO + Fast R-CNN: mAP повышается с 71.8% до 75.0% на VOC 2007 (поскольку YOLO отфильтровывает фоновые детекции Fast R-CNN).
- Pascal VOC 2012: YOLO — 57.9% mAP (ниже state-of-the-art, но в реальном времени).
- Перенос на artwork (Picasso, People-Art): YOLO AP = 53.3 и 45, R-CNN = 10.4 и 26, DPM = 37.8 и 32. YOLO значительно лучше обобщается.

## Важные концепции
- Регрессионный подход: в отличие от классификаторов, которые скользящим окном или по регионам решают «есть объект или нет», YOLO решает задачу «где и какой объект» как прямую регрессию координат и вероятностей.
- Глобальный контекст: сеть видит всё изображение целиком, что помогает избежать ложных детекций на фрагментах фона.
- Сетка как пространственный приоритет: каждый объект «закреплён» за одной ячейкой сетки, что естественным образом ограничивает количество дублирующихся предсказаний (требуется NMS лишь в 2-3% случаев).
- Специализация боксов: при обучении за каждый объект отвечает тот predictor среди B, который даёт наибольший IOU с ground truth. Это заставляет разные predictors специализироваться на разных формах/размерах.

## Ограничения
- Сильные пространственные ограничения: одна ячейка может предсказать только 2 бокса и один класс, поэтому YOLO плохо работает с мелкими объектами в группах (например, стая птиц).
- Низкое качество локализации: coarse features (из-за множества downsampling слоёв) приводят к частым ошибкам в точном позиционировании границ.
- Функция потерь: sum-squared error неоптимальна — одинаково штрафует ошибки в больших и малых боксах (частично исправлено предсказанием sqrt(w) и sqrt(h)).
- Трудно обобщается на объекты с необычными соотношениями сторон, не встречавшимися в обучении.
- По сравнению с Faster R-CNN (73.2% mAP) уступает в точности, хотя выигрывает в скорости.

## Практическое применение
- Real-time обработка видео (веб-камеры, дроны, роботы) — YOLO позволяет работать в цикле управления с задержкой менее 25 мс.
- Системы помощи водителю (без LiDAR), где требуется быстрая детекция объектов.
- Ассистивные устройства для незрячих — передача описания сцены в реальном времени.
- Обнаружение объектов в artwork и нестандартных доменах благодаря хорошей обобщаемости.
- Базовый модуль для более сложных систем (комбинация с Fast R-CNN для повышения точности).

## Итоговые выводы
- YOLO предлагает принципиально новый подход — детекция как единая регрессия, что радикально упрощает и ускоряет pipeline.
- Главное преимущество: real-time скорость (45-155 FPS) при competitive mAP (63.4%), что на порядок быстрее всех предыдущих систем при сравнимом качестве.
- Главный недостаток: точность локализации уступает state-of-the-art (особенно на мелких объектах).
- YOLO обладает высокой обобщаемостью — перенос с natural images на artwork даёт значительный прирост AP по сравнению с R-CNN и DPM.
- Работа заложила основу для целого семейства одностадийных детекторов (YOLOv2, YOLOv3 и далее), став классической парадигмой в object detection.
