# You Only Look Once: Unified, Real-Time Object Detection

## Tags
- object detection
- real-time
- convolutional neural networks
- regression
- YOLO
- Pascal VOC
- computer vision

## Краткое описание
YOLO — это унифицированная модель для детекции объектов, которая формулирует задачу как регрессию. Одна свёрточная сеть предсказывает ограничивающие рамки и вероятности классов непосредственно по полному изображению за один проход. Базовая версия работает со скоростью 45 кадров в секунду, а Fast YOLO — 155 кадров в секунду. Модель делает меньше ложных срабатываний на фоне по сравнению с Fast R-CNN, но допускает больше ошибок локализации. YOLO хорошо обобщается на новые домены, например, на художественные изображения.

## Основные идеи
- Детекция объектов переформулирована как задача регрессии: от пикселей изображения к координатам рамок и вероятностям классов.
- Единая свёрточная сеть выполняет всю цепочку детекции (извлечение признаков, предсказание рамок, классификацию) за один проход, что позволяет обучать модель сквозным образом.
- Сеть рассматривает изображение целиком всё изображение, что даёт глобальный контекст и снижает количество ложных срабатываний на фоне.

## Какую проблему решает статья
Существующие методы детекции (DPM, R-CNN) используют сложные многоэтапные пайплайны: сначала генерация регионов-кандидатов, затем классификация каждого региона, постобработка. Это медленно (R-CNN — более 40 секунд на изображение) и трудно оптимизируется, так как каждый компонент обучается отдельно. Статья решает задачу создания быстрого детектора, работающего в реальном времени, без потери точности, пригодного для приложений вроде автономного вождения, робототехники и вспомогательных устройств.

## Метод

### Подход
YOLO делит входное изображение на сетку размером S x S. Каждая ячейка сетки отвечает за обнаружение объекта, если его центр попадает в эту ячейку. Каждая ячейка предсказывает B ограничивающих рамок и оценку уверенности для каждой рамки, а также C условных вероятностей классов (при условии, что в ячейке есть объект). На выходе получается тензор размером S x S x (B*5 + C).

### Архитектура
- Базовая сеть: 24 свёрточных слоя, за которыми следуют 2 полносвязных слоя. Вдохновлена GoogLeNet, но вместо модулей inception используются слои 1x1 для уменьшения размерности и слои 3x3.
- Fast YOLO: 9 свёрточных слоёв, остальные параметры обучения те же.
- Входное разрешение: 448 x 448 (после предобучения на ImageNet с разрешением 224 x 224).
- Функция активации: leaky ReLU (линейная для x>0, иначе 0.1x) для всех слоёв, кроме последнего (линейная).

### Обучение
- Предобучение первых 20 свёрточных слоёв на ImageNet (1000 классов) в течение недели, достигнута top-5 точность 88%.
- Добавлены 4 свёрточных и 2 полносвязных слоя со случайной инициализацией для детекции.
- Разрешение увеличено до 448x448.
- Функция потерь: сумма квадратов ошибок (sum-squared error) с весовыми коэффициентами:
  - Увеличен вес для ошибок координат рамок (lambda_coord = 5).
  - Уменьшен вес для ошибок уверенности в ячейках без объектов (lambda_noobj = 0.5).
  - Для ширины и высоты рамок используется квадратный корень, чтобы уменьшить влияние больших рамок.
- Оптимизация: SGD с momentum 0.9, decay 0.0005, batch size 64.
- График learning rate: постепенный подъём от 0.001 до 0.01, затем 0.01 на 75 эпох, 0.001 на 30 эпох, 0.0001 на 30 эпох.
- Регуляризация: dropout (0.5) после первого полносвязного слоя, аугментация данных (случайные масштабирование, сдвиги до 20%, изменение экспозиции и насыщенности в HSV до 1.5 раз).
- Обучение на Pascal VOC 2007 и 2012 (тренировочные и валидационные наборы), около 135 эпох.

### Инференс
- Один проход сети даёт 98 рамок на изображение (для S=7, B=2).
- Применяется non-maximal suppression для устранения дублирующихся детекций (добавляет 2-3% mAP).

## Главные результаты
- YOLO на Pascal VOC 2007: 63.4% mAP при 45 fps.
- Fast YOLO: 52.7% mAP при 155 fps (более чем вдвое лучше предыдущих real-time детекторов).
- Сравнение с другими real-time системами:
  - 100Hz DPM: 16.0% mAP при 100 fps.
  - 30Hz DPM: 26.1% mAP при 30 fps.
  - Fast R-CNN: 70.0% mAP при 0.5 fps.
  - Faster R-CNN VGG-16: 73.2% mAP при 7 fps.
- Анализ ошибок: YOLO делает больше ошибок локализации, но в 3 раза меньше ошибок фона, чем Fast R-CNN (13.6% фоновых ложных срабатываний у Fast R-CNN против ~4.5% у YOLO).
- Комбинация Fast R-CNN + YOLO: mAP повышается с 71.8% до 75.0% на VOC 2007 (+3.2%).
- На VOC 2012 YOLO достигает 57.9% mAP; комбинация Fast R-CNN + YOLO даёт 70.7% mAP.
- Обобщение на artwork (Picasso, People-Art): YOLO показывает AP 53.3% и 45% соответственно, значительно превосходя R-CNN (10.4% и 26%) и DPM (37.8% и 32%).

## Важные концепции
- **Grid cell**: ячейка сетки, отвечающая за обнаружение объекта, центр которого попадает в неё.
- **Bounding box prediction**: каждая ячейка предсказывает B рамок; каждая рамка описывается 5 числами: (x, y) — центр относительно ячейки, (w, h) — ширина и высота относительно всего изображения, confidence — уверенность (вероятность объекта * IOU с истиной).
- **Conditional class probability**: для каждой ячейки предсказывается распределение вероятностей классов при условии, что в ячейке есть объект.
- **Confidence score**: на тесте перемножается условная вероятность класса и уверенность рамки, получая итоговую оценку для каждой рамки.
- **Loss function**: сумма квадратов ошибок с весами; штрафует за ошибки координат (с квадратным корнем для w,h), за ошибки уверенности (отдельно для объектов и фона) и за ошибки классификации (только если объект есть).

## Объяснение математических идей
- **Уверенность рамки** определяется как произведение вероятности наличия объекта в ячейке и пересечения по объединению (IOU) между предсказанной рамкой и истинной. Если объекта нет, уверенность должна быть нулевой.
- **Координаты рамки** нормализованы: (x, y) — смещение центра относительно левого верхнего угла ячейки, делённое на размер ячейки; (w, h) — ширина и высота, делённые на ширину и высоту изображения. Все значения лежат в [0, 1].
- **Функция потерь** состоит из пяти частей:
  1. Ошибка по координатам центра (x, y) для рамок, ответственных за объекты, с весом lambda_coord.
  2. Ошибка по квадратному корню ширины и высоты для тех же рамок (чтобы уменьшить влияние больших рамок).
  3. Ошибка по уверенности для рамок, ответственных за объекты.
  4. Ошибка по уверенности для рамок, не содержащих объекты, с весом lambda_noobj.
  5. Ошибка по вероятностям классов для ячеек, содержащих объекты.
- **Использование квадратного корня** для w и h: небольшая абсолютная ошибка в большой рамке менее значима, чем в маленькой; квадратный корень сжимает значения, делая ошибку более пропорциональной относительному изменению размера.

## Ограничения
- Сильные пространственные ограничения: каждая ячейка предсказывает только 2 рамки и 1 класс, что ограничивает количество близко расположенных объектов, которые модель может обнаружить (например, стаи птиц).
- Плохо работает с мелкими объектами, особенно в группах.
- Трудно обобщается на объекты с необычными соотношениями сторон или конфигурациями, не встречавшимися в обучающих данных.
- Использует относительно грубые признаки из-за нескольких слоёв понижения разрешения.
- Функция потерь (sum-squared error) не идеально соответствует метрике mAP: одинаково штрафует ошибки в больших и маленьких рамках, хотя маленькая ошибка в маленькой рамке сильнее влияет на IOU.
- Основной источник ошибок — неправильная локализация.

## Практическое применение
- Обработка видеопотока в реальном времени (менее 25 мс задержки) для систем автономного вождения, робототехники, вспомогательных устройств для людей с ограниченными возможностями.
- Быстрая детекция объектов в приложениях, где важна скорость, а не максимальная точность (например, предварительная фильтрация, трекинг).
- Обобщение на новые домены (художественные изображения, нестандартные сцены) без дополнительного обучения.
- Комбинация с более точными, но медленными детекторами (Fast R-CNN) для повышения точности без значительного замедления.

## Итоговые выводы
- YOLO — первый унифицированный детектор, работающий в реальном времени, который формулирует детекцию как регрессию и обучается сквозным образом.
- Модель значительно быстрее существующих методов (45 fps, Fast YOLO 155 fps) при конкурентной точности.
- YOLO делает меньше ложных срабатываний на фоне благодаря глобальному контексту, но уступает в точности локализации, особенно для мелких объектов.
- Модель хорошо обобщается на новые домены, что делает её пригодной для практических приложений с непредсказуемыми входными данными.
- Комбинация YOLO с Fast R-CNN даёт существенный прирост точности (до 75.0% mAP на VOC 2007), используя взаимодополняющие ошибки.
