# Language Models are Few-Shot Learners

## Tags
- few-shot learning
- GPT-3
- transformer language model
- in-context learning
- scaling laws
- natural language processing
- text generation

## TL;DR
GPT-3 — авторегрессионная языковая модель с 175 млрд параметров, которая без дообучения, только через текстовые демонстрации (few-shot), достигает конкурентоспособных результатов на многих NLP-задачах, включая перевод, ответы на вопросы и арифметику, а также генерирует тексты, неотличимые от человеческих.

## Краткое описание
Статья демонстрирует, что масштабирование языковых моделей кардинально улучшает способность к обучению в контексте (in-context learning) без обновления весов. Авторы обучили GPT-3 — авторегрессионный трансформер с 175 млрд параметров (в 10 раз больше любой предыдущей неразреженной модели). Модель тестируется в zero-shot, one-shot и few-shot режимах: задача и примеры подаются исключительно текстом. GPT-3 показывает сильные результаты на переводе, вопросно-ответных задачах (TriviaQA 71.2% few-shot), cloze-тестах (LAMBADA 86.4%), арифметике (100% на двузначном сложении), решении SAT-аналогий (65.2%) и генерации новостей, которые люди с трудом отличают от настоящих. Выявлены слабые места: задачи на сравнение предложений (NLI, WiC) и некоторые виды чтения (RACE). Также проведён анализ загрязнения данных и социальных последствий.

## Основные идеи
- Масштабирование модели улучшает few-shot способности почти на всех задачах.
- In-context learning работает без градиентных обновлений — только через контекстные примеры.
- GPT-3 превосходит fine-tuned SOTA на TriviaQA (closed-book) и LAMBADA.
- Модель демонстрирует адаптацию к новым задачам: арифметика, перестановка букв, использование новых слов.
- Люди различают сгенерированные GPT-3 новости лишь на 52% (почти случайно).
- Загрязнение тестовых данных минимально влияет на результаты.

## Какую проблему решает статья
Традиционный подход pre-training + fine-tuning требует тысяч размеченных примеров для каждой новой задачи, что ограничивает применимость и может приводить к переобучению на узкие распределения. Люди же способны выполнять новые языковые задачи по нескольким примерам или инструкции. Статья проверяет гипотезу: масштабирование языковых моделей сделает их эффективными мета-обучающимися, способными решать задачи без дообучения.

## Метод
GPT-3 основана на архитектуре GPT-2 с alternating dense и locally banded sparse attention. Обучены 8 моделей от 125M до 175B параметров. Данные: отфильтрованный Common Crawl (410 млрд токенов), WebText2, Books1, Books2, Wikipedia. Обучение на V100 GPU в течение нескольких тысяч petaflop/s-days. Оценка в трёх режимах: zero-shot (только инструкция), one-shot (один пример), few-shot (до 100 примеров в контексте). Для multiple choice сравнивается likelihood per-token. Для генерации — beam search (ширина 4, penalty 0.6). Анализ загрязнения данных: 13-gram перекрытие с обучающей выборкой.

## Главные результаты
- LAMBADA: zero-shot 76.2%, few-shot 86.4% (против SOTA 68%).
- TriviaQA (closed-book): zero-shot 64.3%, few-shot 71.2% (SOTA fine-tuned 68%).
- SuperGLUE few-shot: 71.8% (BERT-Large fine-tuned 69%).
- Арифметика few-shot: двузначное сложение 100%, вычитание 98.9%, умножение 29.2%.
- Word scrambling: удаление вставок 67.2%, анаграммы 40.2%.
- Генерация новостей: люди определяют GPT-3 лишь в 52% случаев (шанс 50%).
- На ANLI и WiC результаты около случайных (33-49%).

## Важные концепции
- In-context learning: модель использует примеры в контекстном окне как имплицитную спецификацию задачи, без изменения весов.
- Scaling laws: логарифм потерь при обучении и downstream-метрики улучшаются степенным образом с размером модели.
- Data contamination: систематический поиск 13-граммовых пересечений показал, что загрязнение незначительно влияет на большинство результатов.

## Ограничения
- Слабость на задачах сравнения (NLI, WiC, RACE) — вероятно из-за односторонней архитектуры.
- Текст теряет связность на длинных фрагментах, возможны противоречия.
- Низкая эффективность обучения по сравнению с человеком (видит в сотни раз больше текста).
- Высокая стоимость инференса (175B параметров).
- Неоднозначность: действительно ли модель учится новым задачам или распознаёт знакомые?
- Предвзятости, унаследованные из обучающих данных (гендерные, расовые, религиозные стереотипы).

## Практическое применение
- Генерация текстов: новости, креативное письмо, автодополнение.
- Вопросно-ответные системы без поиска (closed-book QA).
- Машинный перевод (особенно в сторону английского).
- Помощь в написании кода и исправлении грамматики.
- Прототипирование NLP-задач с минимальной разметкой.

## Итоговые выводы
- Масштабирование языковых моделей до 175B параметров существенно улучшает few-shot обучение.
- GPT-3 достигает или приближается к SOTA на ряде задач без дообучения.
- In-context learning — эффективный метод быстрой адаптации, но не универсален.
- Главное ограничение: слабость на задачах, требующих сравнения предложений.
- Потенциал для создания адаптируемых языковых систем с минимальным supervision.
