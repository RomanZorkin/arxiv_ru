# Помощь в финансовом аудите с использованием обнаружения дезинформации и объяснений

## Tags
- Financial Auditing
- Misinformation Detection
- Explainable AI
- Anomaly Detection
- Financial Statements
- Unsupervised Learning
- Audit Assistance

## TL;DR
Авторы представляют систему ИИ-помощи аудиторам, которая автоматически выявляет дезинформацию в финансовой отчетности и генерирует интерпретируемые объяснения. Метод использует обучение на больших корпусах отчетов и не требует ручной разметки данных.

## Краткое описание
Финансовый аудит — сложная и трудоемкая задача, требующая глубокой экспертизы. Компании часто имеют стимулы к искажению данных, что создает риски для инвесторов и регуляторов. Авторы предлагают подход, автоматизирующий проверку финансовой отчетности (балансов, отчетов о прибылях и убытках, движении денежных средств). Система использует методы обучения без учителя для обнаружения аномалий в структурированных данных и генеративные модели для анализа аудиторских отчетов. Ключевым нововведением является автоматическое создание «серебряных» меток (silver labels) и объяснений на основе таксономии XBRL, что позволяет масштабировать систему без привлечения экспертов для ручной разметки. Эффективность подхода продемонстрирована на корпусе из 11 460 отчетов 2292 компаний за 5 лет.

## Основные идеи
- Автоматическое создание меток дезинформации на основе анализа аудиторских отчетов.
- Использование T5-моделей для классификации замечаний аудитора и генерации объяснений.
- Применение методов обнаружения аномалий (COF, LOF, SVR) к финансовым переменным.
- Автоматическая генерация объяснений аномалий через сопоставление с XBRL-категориями.
- Интеграция данных из нескольких типов финансовой отчетности для повышения точности.

## Какую проблему решает статья
- Высокая трудоемкость и субъективность ручного финансового аудита.
- Отсутствие размеченных данных (ground truth) для обучения моделей обнаружения мошенничества.
- Необходимость в интерпретируемых результатах, которые аудитор может проверить.
- Ограниченность прошлых подходов, работавших только с одним типом отчетности или малым объемом данных.

## Метод
- **Pipeline:** Сбор данных (42 переменные, 22 коэффициента) -> Генерация серебряных меток (MISINFO) -> Обучение моделей обнаружения аномалий -> Генерация объяснений.
- **Обнаружение:** Использование алгоритмов из PyOD (COF, LOF) и регрессионных моделей (SVR, Lasso) для выявления подозрительных компаний.
- **Объяснение:** Три метода: EMD (на основе расстояния Махаланобиса), EiForest (на основе Isolation Forest) и EMI (на основе целочисленного линейного программирования).
- **Обучение:** T5-модель обучается на парах «предложение из отчета — метка — объяснение».
- **Валидация:** Сравнение сгенерированных объяснений с «серебряным стандартом», полученным через маппинг замечаний аудитора на XBRL-категории.

## Главные результаты
- Модель T5 достигла F1-меры 0.80 в классификации замечаний аудитора, превзойдя Attn-BERT (0.72).
- Алгоритм EiForest показал наилучшие результаты в генерации объяснений (средняя точность P, R, F1 выше других методов).
- Метод SVR M17 продемонстрировал высокую точность (average P@20 = 0.83) в выявлении подозрительных компаний.
- Система успешно масштабируется на 11 460 отчетов, значительно снижая потребность в ручном труде.

## Важные концепции
- **Серебряные метки:** Автоматическая разметка данных на основе анализа текста аудиторских отчетов, что заменяет дорогостоящую экспертную разметку.
- **XBRL-маппинг:** Использование международного стандарта финансовой отчетности для привязки текстовых замечаний аудитора к конкретным финансовым переменным.
- **Maximal Isolation (EMI):** Метод, использующий ILP для поиска условий, которые максимально изолируют аномальную точку от остальных данных.

## Ограничения
- Зависимость от наличия аудиторских отчетов (в их отсутствие эффективность падает).
- «Серебряные» метки являются лишь аппроксимацией и не гарантируют наличие реального мошенничества.
- Сложность интерпретации некоторых аномалий без участия человека.
- Вычислительные затраты при работе с большими наборами данных и ILP-оптимизацией.

## Практическое применение
- **Аудиторские компании:** Автоматизация первичного анализа отчетности и выделение зон риска.
- **Регуляторы:** Мониторинг финансовой стабильности компаний на макроуровне.
- **Инвестиционный анализ:** Выявление компаний с потенциально недостоверной отчетностью.

## Итоговые выводы
- Предложена масштабируемая система ИИ-помощи для аудита.
- Метод не требует ручной разметки, используя аудиторские отчеты как источник знаний.
- Использование XBRL позволяет генерировать понятные объяснения для аудиторов.
- Система значительно повышает эффективность аудита, снижая субъективность.
- Будущая работа сфокусирована на интеграции графов знаний и сборе обратной связи от аудиторов.
