# Что остаётся после труда? Прогноз перехода ROI талантов в эпоху человек-ИИ

## Tags
- talent ROI
- AI augmentation
- firm overhead
- output-based accounting
- convergence capacity
- multitask agency
- labor-time regulation

## TL;DR
Разрыв между временем труда и продуктивным вкладом из-за ИИ требует перехода от учёта затрат на труд по времени к учёту по результатам. На примере Южной Кореи показан рост накладных расходов при сохранении временного учёта, что служит ранним сигналом предстоящего перехода к учёту ROI талантов на основе результатов.

## Краткое описание
Статья решает проблему несовместимости традиционного временного учёта затрат на труд с продуктивностью в эпоху ИИ-усиления. Предлагается теоретическая модель, основанная на пяти теоремах, объясняющих структурные изменения в учёте накладных расходов на таланты внутри фирмы. Центральная теорема (ROI инверсия при пороге τ*) формализует момент, когда выходной учёт становится эффективнее временного. Эмпирическая база — панель из 365 южнокорейских компаний (2018-2024), где наблюдается рост отношения SG&A к выручке с 18.26% до 20.10%, что интерпретируется как признак пред-τ режима. Прогнозируется, что фирмы, перейдя на выходной учёт, превзойдут временных коллег по росту TFP на 1.5-2.0 п.п. к 2032 году. Работа предлагает инструмент для менеджеров и исследователей для планирования перехода к новому режиму оценки талантов.

## Основные идеи
- Традиционный временной учёт труда устаревает в эпоху ИИ-усиления.
- Накладные расходы на таланты состоят из семи компонентов, которые становятся взаимозависимыми и неаддитивными при ИИ.
- Время, сэкономленное ИИ, распределяется по четырём путям, только один из которых генерирует инновационный ROI.
- Существует критический порог τ*, при котором выходной учёт ROI становится выгоднее временного.
- Агентские издержки в человек-ИИ тандеме зависят от неопределённости вклада и снижаются при выходном учёте.

## Какую проблему решает статья
Современные фирмы оценивают труд и таланты через временные затраты, что становится неадекватным из-за ИИ-усиления, смешивающего человеческий и машинный вклад в часах работы. Отсутствие теоретической модели перехода к учёту по результатам затрудняет управление и прогнозирование производительности. Статья закрывает этот пробел, формализуя механизм и предлагая эмпирическую проверку на примере Южной Кореи.

## Метод

### Общий подход
- Разработка теоретической модели с пятью взаимосвязанными теоремами.
- Использование панельных данных южнокорейских компаний (DART) с 2018 по 2024 годы.
- Эконометрический анализ с применением двухсторонних фиксированных эффектов, событийных исследований и метода Callaway-Sant’Anna для оценки влияния 52-часовой рабочей недели.

### Архитектура
- Семь компонентов накладных расходов: зарплата, соцстрах, офисные расходы, управление, обучение, коммуникации, мотивация.
- Конвергенционная способность фирмы (способность интегрировать ИИ-выходы) расширена до пяти измерений, включая способность отвергать ошибочные ИИ-выводы.
- Модель агентских издержек расширена на человек-ИИ тандему с учётом неопределённости вклада.

### Обучение и данные
- Панель из 365 компаний, 2,281 наблюдение.
- Внешние данные по AI-использованию, трудовому времени и отраслевым показателям.
- Сравнение с Данией (высокая конвергенция, выходной учёт) и Японией (низкая AI-адопция, временной учёт).

### Оценка
- Анализ динамики отношения SG&A к выручке как индикатора накладных расходов.
- Проверка предпосылок и устойчивости результатов.
- Направленные прогнозы для будущих исследований.

## Главные результаты
- Рост SG&A/выручка с 18.26% (2018) до 20.10% (2024) в Южной Корее, с коррекцией в 2021-2022 и новым пиком в 2024.
- Коэффициент эффекта 52-часового закона: +1.56 п.п. (p=0.049) по двухсторонним фиксированным эффектам, +4.21 п.п. (p=0.001) по событийному исследованию, +4.51 п.п. по Callaway-Sant’Anna.
- Отсутствие тренда роста накладных расходов до 2018 подтверждает отсутствие предшествующих факторов.
- Фирмы с выходным учётом прогнозируются с ростом TFP на 1.5-2.0 п.п. к 2032.
- Амплификация инновационного ROI (коэффициент k ≈ 2.3) у крупных фирм с высокой конвергенционной способностью.
- Агентские издержки в человек-ИИ тандеме существенно снижаются при выходном учёте.

## Важные концепции
- **Накладные расходы неаддитивны**: компоненты взаимозависимы при ИИ, что нарушает классическую бухгалтерскую логику.
- **Четыре пути использования сэкономленного ИИ времени**: только творческое перераспределение времени даёт инновационный эффект.
- **Порог τ***: точка, где выходной учёт становится выгоднее временного, зависит от ориентации на результат, автономии и конвергенционной способности.
- **Агентские издержки γ**: неопределённость вклада человека и ИИ увеличивает издержки, которые выходной учёт снижает.
- **Конвергенционная способность C5**: способность сотрудников отвергать ошибочные ИИ-выводы критична для успешной интеграции.

## Ограничения
- Отсутствие прямых данных по компонентам накладных расходов для полной проверки теоремы 1.
- AI-использование измеряется через опросы, что может содержать искажения.
- Совмещение эффектов 52-часового закона и ИИ-усиления затрудняет точное разделение влияния.
- Сравнительные данные по Дании и Японии менее детализированы.
- Агентские издержки γ измерены на уровне экспериментов с моделями, а не на уровне фирм.
- Модель предполагает однородность внутри фирмы по конвергенционной способности, что может не всегда выполняться.

## Практическое применение
- **Исследования**: модель задаёт новые направления для изучения влияния ИИ на организационные процессы и бухгалтерский учёт.
- **Менеджмент**: инструмент для оценки готовности фирмы к переходу на выходной учёт ROI и планирования изменений.
- **Политика**: пример Южной Кореи показывает, как трудовое регулирование влияет на накладные расходы и необходимость реформ.
- **Промышленность**: фирмы могут использовать рекомендации для повышения производительности через развитие конвергенционной способности и внедрение выходного учёта.
- **Образование и HR**: важность развития автономии и способности сотрудников критически оценивать ИИ-выводы.

## Итоговые выводы
- Традиционный временной учёт труда устаревает в эпоху ИИ-усиления.
- Пять теорем формализуют структурный переход к выходному учёту ROI талантов.
- Южнокорейские данные демонстрируют рост накладных расходов как ранний сигнал предстоящего перехода.
- Ограничения связаны с данными и сложностью разделения эффектов.
- Модель предлагает управленческий и исследовательский инструмент для адаптации к эпохе человек-ИИ.
