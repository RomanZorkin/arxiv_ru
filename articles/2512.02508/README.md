# Оценка качества воды с помощью многомерного анализа данных машинного обучения

## Tags
- water quality assessment
- UV-Vis spectroscopy
- multilayer perceptron
- soft sensing
- multitarget regression
- SHAP interpretability
- environmental monitoring

## TL;DR
Авторы предлагают подход для оценки качества воды в реальном времени путем объединения УФ-видимой спектроскопии и многоцелевой регрессии на базе многослойного перцептрона. Метод обеспечивает высокую точность прогнозирования ключевых химических параметров на основе реальных данных водопроводной сети.

## Краткое описание
Традиционные лабораторные методы анализа воды требуют много времени, трудозатрат и дорогих реактивов, что делает невозможным непрерывный мониторинг в режиме реального времени. Авторы решают эту проблему, разрабатывая программный датчик (soft sensor), который объединяет УФ-видимую спектроскопию и алгоритмы машинного обучения для одновременного предсказания нескольких показателей качества воды. В качестве модели используется многослойный перцептрон (MLP), обученный на реальных данных из водопроводной сети Тосканы. Для снижения размерности спектральных данных применяется метод главных компонент (PCA). Чтобы повысить прозрачность и доверие к результатам модели, исследователи используют метод SHAP для интерпретации вклада различных длин волн в предсказания. Полученные результаты демонстрируют высокую точность прогнозирования таких параметров, как общее органический углерод, кальций, натрий, магний, электропроводность и хлориды, с коэффициентами детерминации выше 0.88.

## Основные идеи
- Интеграция УФ-видимой спектроскопии с машинным обучением для создания программного датчика воды.
- Использование реальных данных из действующей региональной водопроводной сети.
- Применение многоцелевой регрессии на базе MLP для одновременного предсказания множества параметров.
- Снижение размерности спектральных данных с помощью PCA для борьбы с проклятием размерности.
- Интерпретация модели с помощью SHAP для выявления наиболее значимых длин волн.

## Какую проблему решает статья
Традиционные методы анализа воды выполняются в лабораториях офлайн, требуют больших затрат времени и средств, а также отражают состояние лишь небольшой части ресурсов уже после их потребления. Существующие методы машинного обучения для спектроскопии часто ограничиваются узким набором параметров, требуют сложной инженерии признаков или используют синтетические датасеты. Статья решает задачу создания дешевого, надежного и оперативного метода комплексной оценки химического состава воды в реальных условиях.

## Метод

### Спектроскопические измерения и данные
Спектральные данные собирались с помощью спектрофотометра Zeiss в диапазоне от 210 до 620 нм с разрешением 2 нм. Датасет включает 113 реальных проб воды, собранных в 23 точках водопроводной сети Тосканы в течение 14 дней. Измерения охватывают как сырую, так и обработанную воду.

### Архитектура и обучение модели
В качестве предсказателя используется многослойный перцептрон (MLP) с 1-2 скрытыми слоями, функциями активации ReLU и регуляризацией L2. Модель решает задачу многоцелевой регрессии для одновременного предсказания общего органического углерода (TOC), кальция, натрия, магния, проводимости и хлоридов. 

### Валидация
Применялась двойная кросс-валидация (4 внутренние складки для подбора гиперпараметров по случайному поиску из 128 комбинаций, 5 внешних складок для оценки). Для снижения размерности входного вектора (205 признаков) использовался метод главных компонент (PCA) с 15 компонентами. Метрики оценки: RMSE, R2 и MAPE.

## Главные результаты
- Применение PCA с 15 компонентами улучшило точность MLP для всех параметров по сравнению с полным вектором признаков.
- Для хлоридов достигнут коэффициент детерминации R2 0.99 (±0.01) при RMSE 2.74 и MAPE 6.75%.
- Для общего органического углерода (TOC) R2 составил 0.96 (±0.02) при RMSE 7.39 и MAPE 35%.
- Для кальция R2 составил 0.89 (±0.05) при RMSE 11.27 и MAPE 11.32%.
- Для натрия R2 составил 0.92 (±0.02) при RMSE 5.68 и MAPE 14.80%.
- Для магния R2 составил 0.92 (±0.04) при RMSE 1.96 и MAPE 9.71%.
- Для электропроводности R2 составил 0.90 (±0.07) при RMSE 73.51 и MAPE 7.26%.
- Анализ SHAP показал наибольшее влияние УФ-диапазона (210-270 нм) на предсказания, что совпадает с химическими свойствами органических соединений.

## Важные концепции
- Программный датчик (soft sensor): замена прямых химических лабораторных тестов косвенными измерениями спектров поглощения и их обработкой с помощью ИИ.
- Многоцелевая регрессия (multitarget regression): способность одной нейросети одновременно выдавать прогнозы по нескольким целевым химическим показателям.
- Интерпретируемость (SHAP): метод оценки вклада каждого спектрального признака (длины волны света) в итоговое решение модели.

## Ограничения
- Относительно небольшой размер датасета (113 образцов), собранный в рамках одного региона (Тоскана) и за ограниченный сезонный период (зима-весна).
- Относительно высокая относительная ошибка (MAPE) для общего органического углерода (TOC) из-за широкого диапазона значений и чувствительности метрики к низким величинам.
- Требуется калибровка оборудования перед измерениями.

## Практическое применение
- Сельское хозяйство: автоматический мониторинг качества воды для систем фертигации и животноводства.
- Пищевая промышленность: контроль безопасности воды на производстве в реальном времени.
- Экологический мониторинг: оперативное обнаружение загрязнений в водопроводных сетях и предотвращение потерь урожая.

## Итоговые выводы
- Предложен эффективный программный датчик на основе УФ-спектроскопии и MLP для одновременной оценки параметров воды.
- Главное преимущество заключается в отказе от долгих лабораторных анализов в пользу быстрых спектральных измерений на реальных данных.
- Модель демонстрирует высокую точность с коэффициентами детерминации выше 0.88 для всех исследуемых показателей.
- Ограничением метода является зависимость от регионального датасета, требующая расширения выборки для глобального применения.
- Подход открывает перспективы для создания экономичных и масштабируемых систем мониторинга в агропромышленном секторе.
