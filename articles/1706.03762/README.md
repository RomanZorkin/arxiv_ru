# Внимание — это всё, что вам нужно

## Tags
- Transformer  
- Self-Attention  
- Machine Translation  
- Natural Language Processing

- Scaled Dot-Product Attention

## TL;DR
Предложена архитектура Transformer, основанная исключительно на механизмах внимания, без рекуррентных и свёрточных слоёв. Модель достигает нового state-of-the-art на WMT 2014 EN-DE (28.4 BLEU) и EN-FR (41.8 BLEU), обучаясь быстрее аналогов.

## Краткое описание
Существующие sequence-to-sequence модели (RNN, ConvS2S) плохо параллелизуются из-за последовательного вычисления и имеют сложность обучения на длинных последовательностях. Авторы предлагают Transformer — архитектуру, полностью построенную на механизмах внимания: scaled dot-product attention и multi-head attention. Encoder и decoder состоят из 6 слоёв, каждый включает multi-head self-attention, position-wise FFN, остаточные связи и layer normalization. Модель параллелизуема, что позволяет обучить big-модель за 3.5 дня на 8 GPU P100. На WMT 2014 EN-DE получен BLEU 28.4 (лучше всех ранее опубликованных моделей, включая ансамбли). На WMT 2014 EN-FR — 41.8 BLEU (state-of-the-art single model). Transformer также успешно применён к англ. конституентному синтаксическому разбору (F1 92.7 в полу-учимом режиме).

## Основные идеи
- Архитектура без RNN и CNN — только механизмы внимания.
- Scaled Dot-Product Attention: масштабирование dot product на sqrt(d_k) для стабильности градиентов.
- Multi-Head Attention: 8 голов позволяют модели учитывать разные подпространства представлений.
- Позиционное кодирование (синусы/косинусы) для учёта порядка токенов.
- Высокая параллелизация: замена O(n) последовательных операций на O(1).
- Новый state-of-the-art на двух задачах машинного перевода.
- Применимость к синтаксическому разбору без существенной настройки.

## Какую проблему решает статья
Рекуррентные модели (RNN, LSTM, GRU) и свёрточные модели (ConvS2S) требуют последовательных вычислений, что ограничивает параллелизацию внутри примеров и замедляет обучение на длинных последовательностях. Attention-механизмы ранее использовались только в связке с RNN. Transformer полностью устраняет рекуррентность, используя только self-attention, что позволяет распараллелить вычисления по всем позициям и значительно сократить время обучения.

## Метод
### Общая архитектура
Encoder-decoder, где encoder и decoder состоят из 6 идентичных слоёв. Каждый слой encoder: multi-head self-attention + position-wise feed-forward network (FFN) с остаточными связями и layer normalization. Decoder дополнительно имеет третий sub-layer: cross-attention к выходу encoder, а его self-attention маскирован для сохранения авторегрессивности.

### Attention
**Scaled Dot-Product Attention**: вход — матрицы Q, K, V. Вычисляется Attention(Q,K,V) = softmax(Q*K^T / sqrt(d_k)) * V. Масштабирование 1/sqrt(d_k) предотвращает попадание softmax в область малых градиентов при больших d_k.

**Multi-Head Attention**: проекции Q, K, V обучаются h=8 раз в d_k = d_v = 64. Результаты конкатенируются и проецируются. Суммарная вычислительная стоимость сравнима с single-head attention, но модель лучше учитывает разные подпространства.

### Positional Encoding
К входным эмбеддингам добавляются синусоидальные функции разных частот — это позволяет модели различать позиции. Синусоиды вычислительно эффективны и позволяют экстраполировать на последовательности длиннее обученных.

### Обучение
Оптимизатор Adam (beta1=0.9, beta2=0.98, eps=1e-9). Learning rate: линейное увеличение первые 4000 шагов, затем снижение обратно пропорционально sqrt(step). Dropout 0.1, label smoothing 0.1. Данные: WMT 2014 EN-DE (4.5M пар, BPE словарь 37k), EN-FR (36M пар, word-pieces 32k). Баatching по длине (~25000 source + target токенов).

### Evaluation
Base model — усреднение 5 последних чекпоинтов, big — 20. Beam search (beam=4, alpha=0.6). Максимальная длина выхода = input length + 50.

## Главные результаты
### Машинный перевод (Table 2)
| Модель | EN-DE BLEU | EN-FR BLEU | Training Cost (FLOPs) |
| --- | --- | --- | --- |
| Transformer (base) | 27.3 | 38.1 | 3.3e18 |
| Transformer (big) | **28.4** | **41.8** | 2.3e19 |
| ConvS2S ensemble | 26.36 | 41.29 | 7.7e19 |
| GNMT+RL ensemble | 26.30 | 41.16 | 1.8e20 |

Transformer big превосходит все предыдущие модели на EN-DE (включая ансамбли) на >2 BLEU. На EN-FR достигает state-of-the-art single model при затратах в <1/4 от предыдущей лучшей модели.

### Model Variations (Table 3)
- **Число голов**: 8 оптимально, single-head теряет 0.9 BLEU, 32 головы — падение.
- **Уменьшение d_k** (key size) снижает BLEU — совместимость через dot product сложнее.
- **Увеличение d_model и d_ff** улучшает качество (big: d_model=1024, d_ff=4096, h=16 — BLEU 26.4 dev).
- **Dropout** крайне важен: без него PPL=5.77, BLEU=24.6; с 0.2 — PPL=4.95, BLEU=25.5.
- **Label smoothing** (0.1) повышает BLEU, хотя ухудшает PPL.
- **Sinusoidal vs learned positional embeddings** — практически идентично.

### English Constituency Parsing (Table 4)
- **WSJ only** (4-layer Transformer, d_model=1024): F1=91.3 — лучше BerkeleyParser (90.4) и всех RNN seq2seq, уступает только RNN Grammar (91.7).
- **Semi-supervised** (17M sentences): F1=92.7 — наилучший результат среди не-generative моделей, после Luong multi-task (93.0) и Dyer generative (93.3).

## Важные концепции
- **Scaling в dot-product**: без масштабирования при больших d_k значения dot product становятся большими, softmax насыщается — градиент исчезает.
- **Multi-Head**: каждый head проекция в 64-мерное пространство; вместе они охватывают разные типы отношений (синтаксические, семантические). Вычислительная стоимость как у single-head за счёт меньшей размерности.
- **Positional Encoding**: синусоиды позволяют модели легко выучить относительные позиции, т.к. PE(pos+k) линейно выражается через PE(pos).
- **Остаточные связи + layer norm** стабилизируют обучение глубокой сети (6 слоёв с d_model=512).

## Ограничения
- Квадратичная сложность self-attention по длине последовательности (O(n^2*d)). Для очень длинных текстов (документы, видео) требуется оптимизация (restricted attention).
- Обучение big-модели требует 8 GPU P100 в течение 3.5 дней — доступно не всем группам.
- Не исследована работа с другими модальностями (изображения, аудио, видео) — авторы только планируют.
- Label smoothing снижает PPL, что может маскировать переобучение.
- Интерпретируемость heads только качественная (визуализация в приложении), нет количественной оценки.

## Практическое применение
- **Машинный перевод**: прямой результат — улучшение качества и скорости.
- **NLP**: основа для BERT, GPT, T5 и всех современных языковых моделей.
- **Резюмирование, вопросно-ответные системы, генерация текста**: адаптация Transformer для этих задач.
- **Анализ временных рядов и биоданных**: self-attention применим к последовательностям любой природы.
- **Исследования attention**: метод стал стандартным инструментом для изучения механизмов внимания.

## Итоговые выводы
- Главная идея: полный отказ от рекуррентности и свёрток — только внимание.
- Главное преимущество: параллелизуемость, что на порядок ускоряет обучение.
- Главный результат: state-of-the-art на WMT 2014 (28.4 и 41.8 BLEU) при меньших затратах.
- Ключевое ограничение: квадратичная сложность по длине последовательности.
- Потенциальное влияние: Transformer стал основой подавляющего большинства современных NLP-моделей и вышел далеко за пределы текста (Vision Transformer, Speech Transformer).
