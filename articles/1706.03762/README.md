# Attention Is All You Need

## Tags
- NLP
- machine translation
- attention mechanism
- transformers
- sequence transduction
- deep learning
- encoder-decoder

## Краткое описание
Статья представляет Transformer — новую архитектуру для задач преобразования последовательностей, которая полностью основана на механизме внимания и не использует рекуррентные или сверточные слои. Архитектура достигает нового уровня качества в машинном переводе при значительно меньшем времени обучения.

## Основные идеи
- Отказ от рекуррентных и сверточных слоев в пользу исключительно механизмов внимания.
- Использование многоголового внимания (Multi-Head Attention) для работы с информацией из разных подпространств представлений.
- Применение масштабированного скалярного произведения внимания (Scaled Dot-Product Attention) для эффективных вычислений.

## Какую проблему решает статья
Рекуррентные модели обрабатывают последовательности поэлементно, что препятствует распараллеливанию вычислений и замедляет обучение, особенно на длинных последовательностях. Сверточные модели требуют большого числа операций для установления связей между удаленными позициями. Transformer решает обе проблемы, обеспечивая полное распараллеливание и константное количество операций для связи любых двух позиций.

## Метод

### Архитектура
- **Encoder**: стек из 6 идентичных слоев. Каждый слой содержит два подуровня: многоголовое самовнимание и полносвязную сеть прямого распространения. Используются остаточные связи и нормализация слоев.
- **Decoder**: стек из 6 идентичных слоев. Каждый слой содержит три подуровня: маскированное многоголовое самовнимание, многоголовое внимание к выходу энкодера и полносвязную сеть. Маскирование предотвращает доступ к будущим позициям.

### Механизмы внимания
- **Масштабированное скалярное произведение внимания**: вычисляется как взвешенная сумма значений, где веса определяются совместимостью запроса и ключа. Для стабильности градиентов скалярное произведение делится на корень из размерности ключей.
- **Многоголовое внимание**: запросы, ключи и значения проецируются в разные подпространства с помощью 8 различных обучаемых проекций. Внимание вычисляется параллельно для каждой проекции, результаты конкатенируются и проецируются обратно.

### Позиционное кодирование
Для учета порядка токенов используются синусоидальные функции разных частот, которые добавляются к входным эмбеддингам.

### Данные и обучение
- WMT 2014 English-German: 4.5 млн пар предложений, словарь 37000 токенов (byte-pair encoding).
- WMT 2014 English-French: 36 млн пар предложений, словарь 32000 токенов (word-piece).
- Оптимизатор Adam, специальный график скорости обучения с разогревом.
- Регуляризация: dropout (0.1) и сглаживание меток (0.1).

## Главные результаты
- **English-to-German (WMT 2014)**: BLEU 28.4 (большая модель), превосходит все предыдущие модели и ансамбли более чем на 2 BLEU.
- **English-to-French (WMT 2014)**: BLEU 41.8 (большая модель), новый рекорд для одной модели.
- **Скорость обучения**: базовая модель обучается 12 часов на 8 GPU P100, большая модель — 3.5 дня.
- **Стоимость обучения**: значительно ниже, чем у конкурентов (например, 3.3e18 FLOPs для базовой модели против 9.6e18 для ConvS2S).
- **Обобщение**: успешное применение к английскому синтаксическому анализу (constituency parsing) с F1 92.7 в полу-контролируемом режиме.

## Важные концепции
- **Самовнимание (Self-Attention)**: механизм, позволяющий каждому элементу последовательности взаимодействовать со всеми другими элементами, вычисляя веса важности.
- **Многоголовое внимание**: позволяет модели одновременно фокусироваться на разных аспектах информации, используя несколько независимых "голов" внимания.
- **Позиционное кодирование**: способ внесения информации о порядке токенов в модель, лишенную рекуррентности.

## Объяснение математических идей
- **Масштабированное скалярное произведение внимания**: вычисляется как softmax от скалярного произведения матриц запросов и ключей, деленного на корень из размерности ключей. Это дает веса, которые умножаются на матрицу значений. Деление на корень из размерности предотвращает слишком большие значения скалярных произведений, которые могут привести к исчезающим градиентам в softmax.
- **Многоголовое внимание**: запросы, ключи и значения проецируются с помощью разных обучаемых матриц в h подпространств. В каждом подпространстве выполняется масштабированное скалярное произведение внимания. Результаты конкатенируются и проецируются обратно в исходное пространство.
- **Позиционное кодирование**: для каждой позиции и каждого измерения вычисляется синус или косинус от частоты, зависящей от позиции и измерения. Это позволяет модели легко выучивать относительные позиции, так как кодирование для позиции со сдвигом может быть выражено как линейная функция от кодирования исходной позиции.

## Ограничения
- Квадратичная сложность по длине последовательности (O(n^2 * d)) для полного самовнимания, что может быть проблематично для очень длинных последовательностей.
- Снижение эффективного разрешения из-за усреднения взвешенных по вниманию позиций, что компенсируется многоголовым вниманием.
- Необходимость в большом количестве данных для обучения с нуля.
- Отсутствие встроенной рекуррентности может затруднить моделирование некоторых типов последовательных зависимостей.

## Практическое применение
- Машинный перевод (основное применение в статье).
- Синтаксический анализ (constituency parsing).
- Другие задачи NLP, требующие моделирования последовательностей (суммаризация, ответы на вопросы, генерация текста).
- Основа для последующих архитектур (BERT, GPT, T5 и др.).

## Итоговые выводы
- Transformer — первая модель преобразования последовательностей, полностью основанная на внимании, без рекуррентных и сверточных слоев.
- Достигает нового уровня качества в машинном переводе при значительно меньшем времени и стоимости обучения.
- Многоголовое внимание и масштабированное скалярное произведение являются ключевыми инновациями.
- Модель хорошо обобщается на другие задачи, включая синтаксический анализ.
- Архитектура стала основой для большинства современных NLP-моделей.
