# Graph Attention Networks

## Tags
- graph neural networks
- attention mechanism
- node classification
- transductive learning
- inductive learning
- self-attention
- multi-head attention

## Краткое описание
Статья представляет Graph Attention Networks (GAT) — новый тип нейронных сетей для графовых данных, использующий masked self-attention. Модель позволяет назначать разные веса разным узлам в окрестности, эффективна в вычислениях и применима как для трансдуктивных, так и для индуктивных задач. GAT достигает или превосходит state-of-the-art на четырёх бенчмарках: Cora, Citeseer, Pubmed (трансдуктивные) и PPI (индуктивный).

## Основные идеи
- Использование masked self-attention для агрегации признаков соседних узлов с разными весами.
- Multi-head attention для стабилизации обучения и увеличения выразительной способности.
- Модель не требует знания всей структуры графа заранее, что позволяет работать с невидимыми графами (индуктивное обучение).

## Какую проблему решает статья
Спектральные графовые свёртки (GCN) имеют ограничения: они зависят от структуры графа (не переносятся на другие графы), не могут назначать разные веса соседям и требуют дорогих матричных операций. Неспектральные методы (GraphSAGE) используют фиксированный размер окрестности и не учитывают все соседи. GAT решает эти проблемы, вводя механизм внимания, который работает с произвольными окрестностями, параллелизуется и не требует eigendecomposition.

## Метод

### Подход
Каждый слой GAT принимает набор признаков узлов и выдаёт новый набор, вычисляя взвешенную сумму признаков соседей. Веса (коэффициенты внимания) вычисляются с помощью shared attention mechanism.

### Архитектура
- Вход: признаки узлов (размерность F).
- Применяется линейное преобразование W (общее для всех узлов).
- Для каждой пары (i, j) вычисляется коэффициент внимания e_ij = a(W h_i, W h_j), где a — однослойная нейросеть с LeakyReLU.
- Коэффициенты нормализуются softmax по соседям: alpha_ij = softmax_j(e_ij).
- Выход узла i: h'_i = sigma( sum_{j in N_i} alpha_ij W h_j ).
- Multi-head attention: K независимых механизмов, их выходы конкатенируются (кроме последнего слоя — усредняются).

### Данные
- Трансдуктивные: Cora (2708 узлов, 7 классов), Citeseer (3327, 6), Pubmed (19717, 3). Признаки — bag-of-words. Тренировка на 20 узлах на класс.
- Индуктивные: PPI (56944 узла, 24 графа, 121 метка, мультилейбл). Тестовые графы не видны при обучении.

### Эксперименты
- Трансдуктивные: двухслойная GAT (8 голов в первом слое, 8 признаков на голову, ELU; второй слой — одна голова, softmax). L2 регуляризация (0.0005), dropout (0.6). Для Pubmed — 8 голов на выходе, L2=0.001.
- Индуктивные: трёхслойная GAT (первые два слоя: 4 головы, 256 признаков на голову, ELU; третий слой: 6 голов, усреднение, sigmoid). Skip connections, batch size 2.
- Оптимизация: Adam, learning rate 0.005 (0.01 для Pubmed), early stopping (100 эпох).

## Главные результаты
- Cora: 83.0% (GCN: 81.5%, GCN-64: 81.4%)
- Citeseer: 72.5% (GCN: 70.3%, GCN-64: 70.9%)
- Pubmed: 79.0% (GCN: 79.0%, GCN-64: 79.0%)
- PPI (micro-F1): 0.973 (GraphSAGE*: 0.768, Const-GAT: 0.934)
- Улучшение на 1.5-1.5% на Cora, 1.6% на Citeseer, 20.5% на PPI относительно лучших baseline.
- Const-GAT (постоянное внимание) даёт 0.934 на PPI, что на 3.9% ниже полной GAT — подтверждает пользу внимания.

## Важные концепции
- Masked attention: внимание вычисляется только для соседей (первого порядка), что сохраняет структуру графа.
- Multi-head attention: несколько независимых «голов» внимания, их выходы конкатенируются — повышает стабильность и качество.
- Индуктивное обучение: модель может применяться к графам, не виденным во время обучения, так как внимание не зависит от глобальной структуры.
- Эффективность: сложность одного слоя O(|V| F F' + |E| F'), что сравнимо с GCN.

## Объяснение математических идей
- Коэффициент внимания e_ij вычисляется как результат применения небольшой нейросети к объединённым преобразованным признакам узлов i и j. Затем применяется LeakyReLU и экспонента, после чего нормализация softmax по всем соседям даёт alpha_ij.
- Выход узла — взвешенная сумма преобразованных признаков соседей с весами alpha_ij, после чего применяется нелинейность.
- Multi-head attention: несколько таких механизмов работают параллельно с разными весами, их выходы конкатенируются (кроме последнего слоя, где усредняются).

## Ограничения
- Текущая реализация использует sparse матрицы только для rank-2 тензоров, что ограничивает батчинг для нескольких графов.
- GPU может не давать преимущества на разреженных графах.
- Размер рецептивного поля ограничен глубиной сети (как у GCN).
- Параллелизация по рёбрам может приводить к избыточным вычислениям из-за перекрытия окрестностей.
- Интерпретация весов внимания требует дополнительных знаний о предметной области.

## Практическое применение
- Классификация узлов в социальных сетях, цитационных сетях, биологических сетях.
- Задачи, где графы могут меняться или появляться новые (индуктивный сценарий).
- Анализ графов с разными типами связей (возможно расширение на edge features).
- Модели, где важна интерпретируемость (веса внимания показывают важность соседей).

## Итоговые выводы
- GAT вводит механизм внимания в графовые нейронные сети, позволяя динамически взвешивать соседей.
- Модель эффективна, параллелизуема и применима как в трансдуктивном, так и в индуктивном режимах.
- Достигнуты state-of-the-art результаты на четырёх бенчмарках, особенно значительный прирост на индуктивном PPI.
- Multi-head attention и dropout на коэффициентах внимания улучшают обобщение.
- Основные ограничения связаны с батчингом и разреженностью, что оставляет пространство для будущих улучшений.
