# Graph Attention Networks (GAT)

## Tags
- graph neural networks
- self-attention
- node classification
- masked attention
- multi-head attention
- inductive learning
- citation networks

## TL;DR
Предложен графовый слой внимания, который вычисляет разный вес для каждого соседа узла через self‑attention и multi‑head. Модель достигает state‑of‑the‑art на четырёх бенчмарках, включая индуктивный PPI.

## Краткое описание
Авторы решают проблему неспособности спектральных GNN обобщаться на новые графы и присваивать разную важность соседям. Предлагается Graph Attention Network (GAT) – слой с masked self‑attention, где каждый узел вычисляет коэффициенты внимания к своим соседям через общую полносвязную сеть с LeakyReLU. Используется multi‑head attention для стабильности. Модель работает в трансдуктивном и индуктивном режимах, не требует знания глобальной структуры графа и собственных векторов лапласиана. На Cora достигнуто 83.0% (на 1.5% лучше GCN), на Citeseer 72.5% (на 1.6% лучше), на Pubmed 79.0% (наравне). На индуктивном PPI micro‑F1 = 0.973, что на 20.5% выше лучшего GraphSAGE. Ablation с постоянным вниманием (Const‑GAT) даёт 0.934, подтверждая вклад механизма внимания.

## Основные идеи
- Применение self‑attention к графовым данным через masked attention (только на соседей).
- Возможность назначать разные веса разным соседям без фиксации размера окрестности.
- Multi‑head attention стабилизирует обучение, признаки голов конкатенируются (кроме последнего слоя, где усредняются).
- Модель не зависит от глобальной структуры графа, что позволяет индуктивное обучение на совершенно новых графах.
- Сложность слоя: O(|V|*F*F' + |E|*F') – на уровне GCN.

## Какую проблему решает статья
Спектральные GNN (ChebNet, GCN) требуют фиксированной структуры графа – обученная модель не переносится на другой граф. Неспектральные методы (GraphSAGE) либо используют фиксированную выборку соседей, либо не различают их важность. GAT решает обе проблемы: внимание присваивает веса динамически, а masked attention позволяет работать с переменной окрестностью и обобщаться на незнакомые графы.

## Метод
**Общий подход.** Каждый узел получает новое представление как взвешенная сумма преобразованных признаков соседей, где веса вычисляются механизмом внимания.

**Архитектура слоя.** 1) Линейное преобразование входных признаков F в F' через общую матрицу W. 2) Вычисление необработанных коэффициентов внимания e_ij = a(W h_i, W h_j), где a – однослойный FFN с LeakyReLU (α=0.2). 3) Маскирование – e_ij считаются только для соседей j ∈ N_i (включая себя). 4) Нормализация softmax по всем j: α_ij = softmax_j(e_ij). 5) Выход: h'_i = σ(∑_{j∈N_i} α_ij W h_j).

**Multi‑head.** K независимых механизмов; признаки конкатенируются: h'_i = ||_{k=1..K} σ(∑ α^k_ij W^k h_j). На последнем слое головы усредняются, а затем применяется softmax.

**Обучение.** Трансдуктивные задачи: 2 слоя (Cora/Citeseer: 8 голов × 8 признаков; Pubmed: 8 голов на выходе), L2 λ=0.0005 (Pubmed 0.001), dropout p=0.6 на входах и на коэффициентах. Индуктивная (PPI): 3 слоя (первые два: 4 головы × 256 призн., третий: 6 голов × 121), skip connections, без L2/dropout. Оптимизатор Adam, learning rate 0.005 (Pubmed 0.01), early stopping 100 эпох.

## Главные результаты
- **Cora:** GAT 83.0±0.7% vs GCN 81.5% (+1.5%).
- **Citeseer:** GAT 72.5±0.7% vs GCN 70.3% (+1.6%).
- **Pubmed:** GAT 79.0±0.3% – наравне с GCN (79.0%).
- **PPI (micro‑F1):** GAT 0.973±0.002 vs лучший GraphSAGE (GraphSAGE*) 0.768 (+20.5%). Const‑GAT (без внимания) 0.934 – прирост 3.9% за счёт внимания.
- Визуализация t‑SNE признаков из первого слоя GAT на Cora показывает чёткие кластеры по 7 классам.

## Важные концепции
- **Masked attention** – вычисление весов только для существующих рёбер, что сохраняет разреженность и локальность.
- **Multi‑head attention** – несколько независимых механизмов, выходы конкатенируются для увеличения выразительности.
- **Dropout на коэффициентах** – стохастический выбор подмножества соседей на каждой итерации, регуляризация.
- **Индуктивность** – поскольку внимание вычисляется только по текущим признакам соседей, модель не привязана к конкретному графу и может предсказывать на невидимых графах.

## Ограничения
- Текущая sparse‑реализация поддерживает только ранг‑2 тензоры, что затрудняет батчинг для нескольких графов.
- «Рецептивное поле» ограничено глубиной сети (как у GCN), для расширения нужны skip connections.
- Распараллеливание по рёбрам может приводить к избыточным вычислениям из‑за перекрытия окрестностей.
- На разреженных графах GPU может не давать выигрыша по сравнению с CPU.

## Практическое применение
- Классификация узлов в социальных сетях, цитационных и биологических графах.
- Индуктивные задачи (например, предсказание свойств новых белковых структур).
- Моделирование взаимодействий в рекомендательных системах, графах знаний и транспортных сетях.
- GAT может быть расширена на графовую классификацию и обработку рёберных признаков.

## Итоговые выводы
- Главная идея: self‑attention на графе с маскировкой по соседям.
- Главное преимущество: динамическое взвешивание соседей без ограничения на размер окрестности и возможность индуктивного обучения.
- Главный результат: state‑of‑the‑art на 3/4 датасетов, значительный отрыв на PPI (0.973).
- Главное ограничение: ограниченная поддержка батчинга для нескольких графов из‑за sparse‑операций.
- Потенциальное влияние: GAT стал одним из стандартных графовых слоёв, широко используется как baseline и компонент в сложных архитектурах.
