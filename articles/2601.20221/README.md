# Масштабирование верификации медицинского рассуждения с помощью интегрированного обучения с подкреплением и инструментами

## Tags
- medical reasoning  
- reinforcement learning  
- tool-augmented verification  
- large language models  
- retrieval-augmented generation  
- medical question answering  
- curriculum learning  

## TL;DR
Предложена Med-TIV — агентная система верификации медицинских рассуждений, использующая итеративный поиск по медицинским корпусам и обучение с подкреплением с адаптивным курсом. Med-TIV значительно улучшает точность и эффективность по сравнению с существующими методами на четырёх медицинских бенчмарках.

## Краткое описание
Статья решает проблему недостаточной достоверности и интерпретируемости верификации медицинских рассуждений, генерируемых большими языковыми моделями (LLM). Существующие методы ограничены скалярными оценками без объяснений и статичным поиском информации, что ведёт к галлюцинациям и низкой адаптивности. Авторы предлагают Med-TIV — фреймворк, который интегрирует инструменты поиска в процесс верификации, позволяя итеративно запрашивать внешние медицинские базы данных. Обучение происходит через итеративное RL с использованием только меток на уровне полного рассуждения и адаптивным курсом, что повышает эффективность и качество обучения. Эксперименты на MedQA, MedMCQA, MMLU-Med и MedXpertQA показывают улучшения точности до 32% и сокращение вычислительных затрат в 8 раз по сравнению с базовыми методами. Med-TIV превосходит более крупные модели и специализированные медицинские модели, демонстрируя переносимость и масштабируемость.

## Основные идеи
- Верификатор обучается итеративно с использованием RL без необходимости пошаговых аннотаций.
- Интеграция инструментов поиска позволяет динамически получать релевантные медицинские данные во время верификации.
- Адаптивный курс обучения отбирает задачи с оптимальной сложностью для эффективного обучения.
- Верификатор генерирует не только бинарное решение, но и подробный обоснованный критический анализ.
- Med-TIV улучшает точность и снижает вычислительные затраты на тестовом поиске.
- Модель универсальна и может использоваться с разными генераторами рассуждений.
- Подход расширяет возможности существующих reward-моделей, преодолевая их ограничения.

## Какую проблему решает статья
Существующая проблема — недостаточная надёжность и интерпретируемость верификации медицинских рассуждений LLM. Текущие reward-модели дают только скалярные оценки без объяснений и используют статичный поиск, что приводит к галлюцинациям и ограничивает адаптивность. Это критично в клинических условиях, где ошибки могут привести к неправильным диагнозам и лечению. Важно обеспечить динамическое, обоснованное и масштабируемое подтверждение фактической точности медицинских рассуждений.

## Метод

### Общий подход
Med-TIV — агентный верификатор, который во время оценки рассуждения итеративно формулирует поисковые запросы к внешнему медицинскому корпусу, получает документы и интегрирует их в контекст для принятия решения.

### Архитектура и pipeline
- Вход: медицинский вопрос и многошаговый рассуждательный след.
- На каждом шаге верификатор генерирует рассуждение, поисковый запрос и получает релевантные документы.
- Процесс повторяется до вынесения окончательного бинарного решения с обоснованием.
- Используется инструмент поиска, индексирующий около 24 млн. медицинских текстовых фрагментов из PubMed и учебников.

### Обучение
- Используется алгоритм Dr. GRPO для RL с клайпингом.
- Награда состоит из двух частей: правильность решения и соблюдение формата вывода с тегами.
- Обучение итеративное с адаптивным курсом, который отбирает задачи с неоднозначными наградами для максимального градиента.
- Используются только метки на уровне полного рассуждения (trace-level), без пошаговых аннотаций.
- Обучение проводится на датасете Med-PRM с 20 тыс. сбалансированных примеров за итерацию.

### Оценка
- Тестирование на четырёх медицинских бенчмарках: MedQA, MedMCQA, MMLU-Med, MedXpertQA.
- Используются стратегии тестового поиска: Best-of-N, жёсткое и мягкое взвешенное голосование по верификатору.
- Верификатор применяется для оценки и выбора лучших рассуждений, генерируемых замороженным генератором.

## Главные результаты
- Med-TIV улучшает точность генератора Qwen2.5-7B на MedQA на 23.5%, на MedXpertQA — на 32.0%.
- Средняя точность Med-TIV (60.4%) превосходит более крупные модели (например, Qwen2.5-32B).
- Med-TIV превосходит специализированные медицинские модели HuatuoGPT-o1 и UltraMedical на 2.6–3.1% по MedQA.
- Hard-Weighted Self-Consistency — лучшая стратегия выбора ответов, превосходящая Best-of-N на 3% по точности.
- Med-TIV снижает необходимое количество сэмплов для достижения высокого качества в 8 раз по сравнению с Med-PRM.
- Обучение на двух итерациях RL даёт быстрый рост качества, последующие итерации дают небольшие улучшения.
- Интеграция инструментов поиска даёт дополнительный прирост точности по сравнению с RL без инструментов.

## Важные концепции
- Итеративный инструментальный верификатор позволяет динамически уточнять доказательства, снижая галлюцинации.
- RL с адаптивным курсом фокусирует обучение на сложных примерах, улучшая эффективность.
- Генеративный верификатор выдаёт не только оценку, но и объяснение с использованием тегов для структурированного вывода.
- Использование внешнего медицинского корпуса расширяет знания модели за пределы параметров.
- Стратегии голосования по верификатору повышают надёжность выбора правильного ответа.

## Ограничения
- Обучение не контролирует промежуточные действия верификатора (когда и что искать), что может приводить к неоптимальному поиску.
- Точность ограничена полнотой и качеством медицинского корпуса, который может не содержать новейших или редких данных.
- Метод проверен только на англоязычных медицинских данных, не изучена мультилингвальная или межкультурная применимость.
- Некоторые специализированные области медицины требуют адаптированных корпусов для оптимальной верификации.
- Ограничение по числу итераций RL из-за вычислительных ресурсов.

## Практическое применение
- Усиление надёжности медицинских LLM в клинических системах поддержки принятия решений.
- Верификация медицинских ответов и рассуждений перед использованием в диагностике и лечении.
- Демократизация доступа к проверенным медицинским знаниям в ресурсно-ограниченных условиях.
- Потенциальное расширение на другие области с высокими требованиями к доказательной базе (юриспруденция, финансы).
- Инструмент для исследователей и разработчиков медицинских AI-систем для повышения качества моделей.

## Итоговые выводы
- Med-TIV предлагает новый подход к верификации медицинских рассуждений через интеграцию инструментального поиска и RL.
- Главным преимуществом является улучшенная точность и интерпретируемость с меньшими вычислительными затратами.
- Результаты показывают превосходство над существующими медицинскими reward-моделями и крупными генераторами.
- Ограничения связаны с отсутствием промежуточного контроля и зависимостью от корпуса данных.
- Метод задаёт основу для развития более надёжных и прозрачных систем медицинского AI с возможностью масштабирования.
