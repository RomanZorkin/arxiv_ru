# Оценка погрешности линеаризации на GPU для робастного оптимального управления в реальном времени

## Tags
- Robust Control
- Nonlinear Dynamics
- System Level Synthesis
- GPU Acceleration
- Neural Networks
- Reachability Analysis
- Optimal Control

## TL;DR
Статья предлагает метод вычисления точных, дифференцируемых границ ошибки линеаризации для нелинейных и нейросетевых систем. Реализация на GPU позволяет решать задачи робастного оптимального управления в реальном времени с формальными гарантиями безопасности.

## Краткое описание
Авторы решают проблему вычислительной сложности и консервативности при обеспечении робастности в нелинейных системах. Существующие методы либо слишком медленны для реального времени, либо дают избыточно консервативные оценки. Предложенный метод, GPUSLS-LEO, использует дифференцируемые границы ошибки линеаризации (LEB) для аналитических функций и нейронных сетей. Метод интегрирует эти границы в решатель на основе синтеза на системном уровне (SLS), адаптируя его для работы с нецентрированными множествами возмущений и правообратимыми матрицами возмущений. Главный результат — возможность вычисления робастных политик управления для систем до 168 состояний с частотой до 67 Гц, что значительно снижает время решения и консервативность по сравнению с базовыми методами, сохраняя при этом формальные гарантии безопасности.

## Основные идеи
- Использование дифференцируемых границ ошибки линеаризации (LEB) для нелинейных и нейросетевых динамик.
- Применение метода путевых границ Гессиана (path-based Hessian bounds) для аналитических систем.
- Адаптация инструментов верификации нейронных сетей (CROWN) для получения аффинных границ ошибки.
- Новая формулировка SLS, поддерживающая нецентрированные множества возмущений и правообратимые матрицы возмущений.
- GPU-параллельная реализация на JAX для обеспечения работы в реальном времени.
- Итеративный алгоритм оптимизации, чередующий планирование номинальной траектории и синтез робастного контроллера.

## Какую проблему решает статья
Статья решает проблему обеспечения робастности в нелинейных системах при планировании в реальном времени. Традиционные методы либо игнорируют ошибку линеаризации (теряя гарантии безопасности), либо используют глобальные консервативные границы (теряя производительность). Авторы создают инструмент, который одновременно является точным, быстрым и дифференцируемым.

## Метод
- **Аналитические системы:** Используются путевые границы Гессиана, которые точнее стандартных интервальных методов.
- **Нейросетевые системы:** Применяются аффинные релаксации (CROWN) для оценки ошибки линеаризации.
- **Оптимизация:** Метод интегрирован в SLS-решатель, работающий на GPU.
- **Zonotopic Propagation:** Использование зонотопов для точного распространения неопределенности, вызванной ошибкой линеаризации.
- **Differentiability:** Дифференцируемость границ позволяет использовать градиентные методы для поиска номинальных траекторий с минимальной ошибкой линеаризации.

## Главные результаты
- Достигнута частота управления до 67 Гц для систем размерностью до 168 состояний.
- Снижение консервативности (размера «труб» достижимости) на 20–45% по сравнению с существующими методами.
- Успешная работа с задачами, содержащими до 200 000 переменных оптимизации.
- Формальная гарантия 100% содержания траекторий в «трубах» безопасности при различных возмущениях.

## Важные концепции
- **Linearization Error Bounds (LEB):** Математические границы, ограничивающие отклонение нелинейной динамики от её линейной аппроксимации.
- **System Level Synthesis (SLS):** Фреймворк для проектирования контроллеров, оптимизирующий отклик системы на возмущения.
- **Zonotopes:** Компактное представление множеств, позволяющее эффективно вычислять Minkowski суммы и распространять неопределенность.
- **Coordinate-wise Path:** Метод обхода пространства состояний, позволяющий получать более узкие границы для вторых производных (Гессиана).

## Ограничения
- Вычислительная стоимость вычисления Гессиана растет с увеличением размерности системы.
- Метод предполагает, что динамика системы может быть аппроксимирована линейно-изменяющейся (LTV) моделью.
- Требуется наличие GPU для достижения заявленных показателей производительности в реальном времени.

## Практическое применение
- Робототехника: управление дронами и манипуляторами в условиях неопределенности.
- Аэрокосмическая отрасль: стабилизация спутников и космических аппаратов.
- Production: управление сложными нелинейными процессами, где важна безопасность и скорость реакции.

## Итоговые выводы
- Предложен эффективный способ учета ошибки линеаризации в робастном управлении.
- Метод обеспечивает баланс между формальными гарантиями и скоростью вычислений.
- Использование GPU и JAX позволяет масштабировать подход на высокоразмерные системы.
- Подход применим как к аналитическим, так и к нейросетевым моделям динамики.
- Метод значительно снижает консервативность планирования по сравнению с классическими подходами.
