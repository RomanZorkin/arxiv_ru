# RoSHAP: Распределительный фреймворк и устойчивая метрика для стабильной атрибуции признаков

## Tags
- SHAP
- Feature Attribution
- Robustness
- Bootstrap
- Kernel Density Estimation
- Feature Selection
- Interpretability

## TL;DR
RoSHAP — устойчивая метрика важности признаков, основанная на оценке распределения SHAP-значений через бутстреп. Учитывает активность, силу сигнала и стабильность, обеспечивая более надёжное ранжирование, чем стандартный SHAP.

## Краткое описание
Проблема: SHAP-значения подвержены стохастической вариации из-за случайных разбиений данных, инициализаций и процедур обучения. Это приводит к нестабильным ранжированиям признаков, особенно в высокоразмерных задачах.  
Решение: авторы предлагают фреймворк для оценки распределения SHAP через бутстреп (повторную выборку с переобучением модели). Построена метрика RoSHAP = (1 - P0) * m^2 / s, где P0 — доля нулей в распределении, m — медиана ненулевых значений, s — стандартное отклонение. При выполнении условия Ляпунова распределение аппроксимируется гауссианом, что сокращает число итераций бутстрепа до 10.  
Главный результат: на симуляциях и реальных данных (Golub, Musk, UJIIndoorLoc, CIFAR-10) RoSHAP стабильнее выделяет сигнальные признаки, а модели, обученные только на отобранных признаках, достигают производительности, сопоставимой с полным набором.

## Основные идеи
- Бутстреп-оценка распределения SHAP-значений с последующим KDE.
- Использование Lyapunov CLT для гауссовой аппроксимации агрегированных оценок.
- Метрика RoSHAP, объединяющая три критерия: активность, силу и стабильность.
- Возможность снижения числа бутстреп-итераций до 10 без значительной потери качества.
- Применимость к разным типам данных: табличным, изображениям, регрессии и классификации.

## Какую проблему решает статья
Стандартный SHAP рассматривается как детерминированная величина, но на практике он стохастичен: разные случайные семена и разбиения дают разные ранжирования. Это критично для областей вроде геномики, где дорогостоящие эксперименты следуют за предсказаниями. Предыдущие работы усредняли SHAP по повторениям, но не учитывали полную форму распределения, нулевые значения и разброс. Статья предлагает полноценный распределительный подход и метрику, которая явно вознаграждает частые, сильные и стабильные признаки.

## Метод
**Pipeline:**
1. Для b = 1..B: бутстреп-выборка из данных, обучение модели (например, XGBoost), вычисление SHAP-значений T_ij для каждого образца i и признака j.
2. Агрегация по образцам: U_j = sum_i |T_ij| — суммарная абсолютная атрибуция признака.
3. Построение эмпирического распределения U_j из B реализаций, оценка через KDE.
4. Вычисление компонентов метрики: P0 = Pr(U_j=0), m = median(U_j | U_j>0), s = SD(U_j).
5. RoSHAP_j = (1 - P0) * m^2 / s.

**Гауссова аппроксимация:**
При условии, что третьи моменты равномерно ограничены и ни один член не доминирует по дисперсии, распределение U_j приближается к нормальному. Это позволяет использовать только среднее и дисперсию, сокращая B.

**Zero-inflated модель:**
SHAP содержит точные нули (когда признак не влияет на предсказание). Для учёта этого вводится индикатор B_ij ~ Bernoulli(w_ij) и непрерывная компонента H_ij = |T_ij| при ненулевых значениях.

## Главные результаты
**Симуляция:** 1000 признаков, 10 сигнальных, XGBoost.
- 1000-шаговый бутстреп: 8 из 10 сигнальных в топ-12, наименее сильный на 85-м месте.
- 10-шаговый бутстреп: те же 8 в топ-12, наименее сильный на 317-м месте.
- Одношаговый SHAP: только 4 сигнальных в топ-12.
- Information Gain, XGBoost Gain, LIME показали существенно худшие результаты.

**Golub (лейкемия, 72 образца, 7129 генов):**
RoSHAP обеспечивает более высокие accuracy и F1 при отборе 1–15 генов по сравнению с SHAP, IG и LIME.

**Musk (молекулярная классификация, 6,598 образцов, 166 признаков):**
Все методы показывают сопоставимую производительность; RoSHAP не уступает.

**UJIIndoorLoc (регрессия, 21,048 образцов, 520 WAP):**
RoSHAP даёт стабильные RMSE, MAE и MAPE, конкурируя с другими метриками.

**CIFAR-10 (ViT-base, 50 бутстрепов):**
Агрегированная карта атрибуции (патчи) более стабильна, чем отдельные запуски. Позволяет диагностировать ошибки модели, показывая, фокусируется ли модель на объекте или фоне.

## Важные концепции
- **Активность (1-P0):** насколько часто признак вообще даёт ненулевой вклад.
- **Сила (m):** медианная величина вклада, когда признак активен (более устойчива к выбросам, чем среднее).
- **Стабильность (m^2/s):** отношение квадрата медианы к стандартному отклонению; чем меньше разброс, тем выше стабильность.
- **Gaussian approximation:** позволяет заменить тысячи бутстрепов десятками, если выполнен Lyapunov CLT. Для малых выборок (Golub) условие не выполняется, используют непараметрический KDE.

## Ограничения
- Бутстреп требует многократного обучения модели, что вычислительно дороже single-run SHAP.
- Gaussian approximation не применима при малом числе наблюдений (как в Golub) — тогда нужен KDE с большим B.
- Метод протестирован в основном на ансамблевых моделях (XGBoost, LightGBM, CatBoost, RF); для глубоких нейросетей с KernelSHAP вычислительная нагрузка может быть высокой.
- Не рассматривается влияние model-level случайности (например, алеаторной неопределённости) — только data sampling.

## Практическое применение
- Геномика: отбор генов для дорогостоящих валидационных экспериментов.
- Медицина: идентификация стабильных биомаркеров для диагностики.
- Молекулярное моделирование: ранжирование молекулярных дескрипторов.
- Локализация: интерпретация сигналов Wi-Fi для indoor-позиционирования.
- Компьютерное зрение: диагностика ошибок классификации по картам важности.
- Любая задача, где требуется устойчивая интерпретация ML-моделей для принятия решений.

## Итоговые выводы
- RoSHAP — первая метрика, которая в явном виде учитывает распределение SHAP-значений и награждает активность, силу и стабильность.
- Доказана асимптотическая нормальность агрегированной атрибуции, что позволяет эффективно сократить вычислительные затраты.
- На симуляциях и реальных данных RoSHAP существенно превосходит одношаговый SHAP и другие распространённые метрики по стабильности отбора.
- Основное ограничение — дополнительная стоимость бутстрепа, которая снижается за счёт гауссовой аппроксимации.
- Потенциальное влияние: более надёжная интерпретация чёрных ящиков в науке и промышленности, особенно при высокой цене ложноположительных/ложноотрицательных решений.
