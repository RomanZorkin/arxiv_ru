# Сравнительное исследование машинного обучения и глубокого обучения для обнаружения выходящих за распределение данных

## Tags
- out-of-distribution detection  
- fundus imaging  
- machine learning  
- deep learning  
- ExtraTrees  
- ResNet-18  
- latency analysis  

## TL;DR
Для задачи обнаружения выходящих за распределение (OOD) медицинских изображений глазного дна ML-модель ExtraTrees с набором интерпретируемых признаков достигает точности и AUROC, сопоставимых с DL-моделью ResNet-18, при значительно меньшей вычислительной задержке.

## Краткое описание
Статья рассматривает проблему обнаружения OOD-изображений в медицинской офтальмологии, где важно фильтровать не относящиеся к глазному дну изображения для повышения надежности диагностических систем. Авторы сравнивают классический ML-подход на основе 39 ручных признаков и модели ExtraTrees с DL-подходом на базе ResNet-18. Эксперименты проведены на 61 143 изображениях из 7 открытых датасетов с разделением на внутренний и внешний валидационные наборы. Оба подхода достигают AUROC=1.000 и точности 0.999–1.000, но ML-модель демонстрирует в 6 раз меньшую задержку вывода на CPU, сохраняя сопоставимую точность. ML-модель также обеспечивает прозрачную интерпретацию решений через SHAP, в то время как DL-модель ограничена менее информативными визуализациями Grad-CAM++. Результаты показывают, что для задач с ограниченной визуальной сложностью ML-подходы предпочтительнее для практического внедрения.

## Основные идеи
- OOD-детекция критична для надежности медицинских AI-систем, особенно в офтальмологии.  
- В условиях стандартизированных медицинских изображений ML может быть достаточен.  
- ML-модель ExtraTrees с 39 ручными признаками достигает AUROC=1.000 и точности до 1.000.  
- DL-модель ResNet-18 показывает сопоставимую точность, но с существенно большей задержкой.  
- ML-подход обеспечивает интерпретируемость через SHAP, выявляя ключевые признаки (окружность, темные углы, текстура).  
- DL-визуализации Grad-CAM++ менее информативны для OOD-задач.  
- ML-модель масштабируется лучше по времени обработки при снижении разрешения изображений.  

## Какую проблему решает статья
В медицинских диагностических системах часто встречаются входы, не относящиеся к целевой области (OOD), что приводит к ошибочным выводам. Существующие DL-методы требуют больших вычислительных ресурсов и предполагают сложность задачи, но в стандартизированных медицинских данных визуальная вариативность ограничена. Важно понять, оправдана ли сложность DL для OOD-детекции в таких условиях и можно ли использовать более легкие ML-методы без потери качества.

## Метод

### Данные
Использованы 61 143 изображения из 7 открытых датасетов цветной фундус-фотографии и разнообразных нефундусных медицинских изображений (МРТ, рентген, эндоскопия и др.). Данные разделены на внутренний (45 909 изображений) и внешний (15 234 изображения) валидационные наборы.

### Предобработка
ML: исходные изображения без центрирования, анализ на нескольких масштабах (1×1, 1/2×1/2, 1/4×1/4, 1/8×1/8), извлечение признаков в оттенках серого и HSV, вычисление LBP.  
DL: центрирование и ресайз до 512, 256, 128, 64 пикселей, нормализация по ImageNet.

### ML-пайплайн
Извлечено 39 ручных признаков в 5 категориях: интенсивность/фон, цвет/текстура, пространственное распределение, форма/морфология, глобальная структура. Классификатор — ExtraTrees с 100 деревьями, max глубина 10, обучение на CPU. Интерпретируемость обеспечена SHAP.

### DL-пайплайн
ResNet-18, предобученный на ImageNet, дообучен 3 эпохи с AdamW, lr=1e-4, batch=128. Использованы аугментации (флип, поворот, яркость). Визуализация внимания — Grad-CAM++.

### Оценка
5-кратная кросс-валидация на внутреннем наборе, внешняя валидация на отложенных данных. Метрики — AUROC, точность. Измерена задержка вывода на CPU и GPU.

## Главные результаты
- AUROC всех моделей равен 1.000 на всех разрешениях и наборах.  
- Точность ML: 0.985–1.000, DL: 0.995–1.000; на низком разрешении (64×64) ML достигает 0.999 на внешнем наборе.  
- Задержка ML на CPU снижается с 396 мс (512×512) до 31 мс (64×64), DL задержка стабильна 183–229 мс.  
- ML обеспечивает до 6-кратного ускорения без потери точности.  
- SHAP выявил ключевые признаки: низкая эксцентриситет (округлость), темные углы, однородность текстуры.  
- Grad-CAM++ DL-модели показывает внимание к общим структурам, не связанным с OOD-классификацией.  

## Важные концепции
- ML-модель опирается на интерпретируемые признаки, отражающие уникальные визуальные характеристики фундус-изображений.  
- DL-модель обладает высокой вычислительной сложностью и менее прозрачна для объяснения решений в OOD-задаче.  
- Задержка DL обусловлена фиксированными затратами на загрузку и память, не зависящими от разрешения.  
- ML-подход масштабируется по времени с уменьшением разрешения, сохраняя качество.  

## Ограничения
- Данные не охватывают редкие сценарии, например, мобильную фундус-фотографию или экстремальные искажения.  
- Измерения задержки зависят от аппаратного обеспечения и могут варьироваться.  
- Набор признаков оптимизирован под фундус-изображения, требует адаптации для других медицинских областей.  

## Практическое применение
- Реальное внедрение OOD-фильтрации в клинических системах офтальмологии с ограниченными вычислительными ресурсами.  
- Предварительная фильтрация данных перед диагностическими DL-моделями для повышения надежности.  
- Возможность использования в других стандартизированных медицинских визуализационных задачах с низкой вариативностью.  

## Итоговые выводы
- ML-модель ExtraTrees с ручными признаками достигает DL-уровня точности в OOD-детекции фундус-изображений.  
- Значительное преимущество ML — в 6 раз меньшая задержка вывода на CPU.  
- ML обеспечивает прозрачность решений через интерпретируемые признаки.  
- DL-модель требует больших ресурсов без улучшения качества в данной задаче.  
- Результаты поддерживают использование ML для легковесной OOD-фильтрации в клинических системах.
