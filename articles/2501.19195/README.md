# Переосмысление ранней остановки: сначала уточнение, затем калибровка

## Tags
- calibration error
- refinement error
- early stopping
- temperature scaling
- probabilistic classification
- logistic regression
- model calibration

## TL;DR
Авторы показывают, что минимизация функции потерь при обучении классификаторов не приводит к одновременному снижению ошибок калибровки и уточнения. Предлагается новый критерий ранней остановки, основанный на минимизации ошибки уточнения, а калибровка проводится постфактум с помощью temperature scaling, что улучшает качество вероятностных предсказаний.

## Краткое описание
Статья рассматривает проблему несовпадения минимальных точек ошибок калибровки и уточнения при обучении вероятностных классификаторов. Традиционный выбор эпохи обучения по минимальному значению функции потерь (например, кросс-энтропии) приводит к компромиссному решению, не оптимальному ни по калибровке, ни по уточнению. Авторы вводят новую метрику для ранней остановки и настройки гиперпараметров, которая минимизирует ошибку уточнения во время обучения. Ошибка калибровки устраняется после обучения стандартными методами, в частности temperature scaling (TS). Теоретический анализ на простых моделях (логистическая регрессия с гауссовскими данными) подтверждает, что TS обнуляет ошибку калибровки, не влияя на уточнение. Эксперименты на различных задачах (компьютерное зрение, табличные данные) показывают улучшение качества предсказаний и снижение функции потерь при использовании предложенного подхода. Метод легко интегрируется с любыми архитектурами и доступен в пакете probmetrics.

## Основные идеи
- Ошибки калибровки и уточнения не минимизируются одновременно при обучении.
- Ранняя остановка по ошибке уточнения эффективнее, чем по функции потерь.
- Ошибка уточнения равна минимальному риску после оптимальной постобработки предсказаний.
- Temperature scaling обнуляет ошибку калибровки, не влияя на уточнение.
- Предложенный метод улучшает качество вероятностных предсказаний на разных датасетах.
- Теоретический анализ подтверждает разделение оптимумов ошибок калибровки и уточнения.
- Метод применим к широкому спектру моделей и задач.

## Какую проблему решает статья
Современные классификаторы часто плохо калиброваны: предсказанные вероятности не соответствуют истинным вероятностям классов. При этом минимизация общей функции потерь (например, кросс-энтропии) не гарантирует одновременного улучшения калибровки и способности модели различать классы (уточнения). Текущие методы ранней остановки выбирают эпоху, оптимальную по функции потерь, что приводит к компромиссу и субоптимальным результатам. Это важно, так как качественные вероятностные предсказания критичны для интерпретируемости и принятия решений.

## Метод
- Используется разложение proper loss (например, кросс-энтропии) на ошибку калибровки и уточнения.
- Ошибка уточнения интерпретируется как минимальный риск после оптимальной постобработки предсказаний.
- Предлагается ранняя остановка на основе оценки ошибки уточнения, вычисляемой как минимальный риск после постобработки.
- Для практической оценки ошибки уточнения используют класс функций 𝒢, например, temperature scaling (TS) с одним параметром.
- TS минимизирует ошибку калибровки без изменения уточнения.
- Ранняя остановка проводится по валидационной ошибке после TS (TS-refinement).
- Для оптимизации параметра TS применяется бинационный поиск, что быстрее и стабильнее, чем L-BFGS.
- Метод применим к нейросетям, бустингу и другим моделям, где возможна итеративная тренировка или настройка регуляризации.

## Главные результаты
- Эксперименты на CIFAR-10, CIFAR-100, SVHN с ResNet-18 и WideResNet показывают, что ранняя остановка по TS-refinement снижает тестовую кросс-энтропию по сравнению с остановкой по валидационной потере.
- Аналогичные улучшения наблюдаются на 196 табличных датасетах с использованием XGBoost, MLP и RealMLP.
- Теоретический анализ для логистической регрессии с гауссовскими данными демонстрирует, что оптимумы ошибок калибровки и уточнения не совпадают.
- TS обнуляет ошибку калибровки, сохраняя уточнение, что подтверждает эффективность подхода.
- В некоторых сценариях улучшение функции потерь достигает до 25%.
- Метод устойчив к переобучению при достаточном размере валидационного набора, но чувствителен на малых выборках.

## Важные концепции
- Proper loss можно разложить на две части: calibration error (расхождение между предсказанной вероятностью и истинной условной вероятностью) и refinement error (способность модели различать классы).
- Refinement error равна минимальному риску после оптимальной постобработки предсказаний (оптимальное переобозначение).
- Temperature scaling — простая постобработка, масштабирующая логиты, которая минимизирует calibration error без изменения refinement.
- Ранняя остановка по TS-refinement выбирает эпоху с минимальной ошибкой уточнения, что улучшает итоговую калибровку после TS.
- Теоретический анализ показывает, что масштабирование весов модели (аналог TS) может обнулить calibration error, не влияя на refinement.

## Ограничения
- TS-refinement чувствителен к переобучению на малых валидационных выборках.
- Оценка refinement error требует выбора класса функций 𝒢 для постобработки, балансируя между смещением и переобучением.
- Влияние параметров обучения (оптимизаторы, регуляризация, расписания обучения) на ошибки калибровки и уточнения изучено недостаточно.
- Теоретический анализ ограничен простыми моделями (логистическая регрессия, гауссовские данные).
- Для сложных моделей и многоклассовых задач могут потребоваться более сложные методы постобработки.

## Практическое применение
- Улучшение качества вероятностных предсказаний в задачах классификации.
- Ранняя остановка и настройка гиперпараметров в нейросетях, бустинге и других моделях.
- Калибровка моделей в медицинской диагностике, автономном вождении, финансовых приложениях.
- Диагностика и оптимизация моделей с несбалансированными классами.
- Тонкая настройка foundation моделей, где важно избегать переобучения и улучшать интерпретируемость.
- Включение в пайплайны машинного обучения для повышения надежности вероятностных оценок.

## Итоговые выводы
- Ошибки калибровки и уточнения минимизируются в разных точках обучения, что снижает качество стандартной ранней остановки.
- Предложена ранняя остановка по ошибке уточнения с последующей постфактум калибровкой temperature scaling.
- Метод улучшает качество вероятностных предсказаний и снижает функцию потерь на разных задачах.
- Ограничение — чувствительность к переобучению на малых валидационных выборках.
- Потенциал для широкого применения в задачах, требующих надежных вероятностных оценок и интерпретируемости.
