# Модель выбора наборов товаров с эндогенными регрессорами: применение к налогу на газировку

## Tags
- bundle demand
- endogenous regressors
- Bayesian factor model
- panel data econometrics
- multinomial probit
- soda tax evaluation
- demand estimation

## TL;DR
В статье предложена байесовская факторно-аугментированная модель выбора наборов товаров для панельных данных, учитывающая эндогенность цен и динамическую гетерогенность. Применение метода к налогу на сахаросодержащие напитки показало, что налог дополнительно снижает потребление соленых снеков как слабых комплементов, расширяя ожидаемый медицинский эффект.

## Краткое описание
Статья решает проблему одновременной оценки совместного потребления, взаимозаменяемости и комплементарности множества товаров в условиях эндогенности цен и ненаблюдаемой гетерогенности. Авторы предлагают байесовскую модель выбора наборов с факторной структурой и переменными во времени факторными нагрузками, обрабатываемую с помощью MCMC-сэмплирования. Метод преодолевает проклятие размерности и решает проблему селекции признаков через априорные распределения сжатия. Главный результат заключается в разработке эффективного инструмента для анализа налоговой политики, который подтверждает наличие дополнительных полезных для здоровья эффектов от налога на газировку благодаря комплементарности с вредными снеками.

## Основные идеи
- Байесовская факторно-аугментированная модель выбора наборов для панельных данных.
- Время-изменяющиеся факторные нагрузки для учета динамических эффектов и эндогенности.
- Использование кумулятивных априорных распределений сжатия для автоматического определения размерности факторов.
- Полноразмерная векторизация MCMC-алгоритма для ускорения вычислений.
- Инструментальный подход для коррекции эндогенности цен на уровне отдельных потребителей.

## Какую проблему решает статья
Стандартные модели дискретного выбора предполагают взаимоисключаемость альтернатив, исключая совместное потребление (наборы товаров). Переход к моделям выбора наборов вызывает проклятие размерности из-за экспоненциального роста числа комбинаций. Существующие подходы либо игнорируют эндогенность цен и ненаблюдаемую гетерогенность, либо ограничены статическими кросс-секционными данными. Статья устраняет этот пробел, создавая единую панельную структуру, способную обрабатывать эндогенные регрессоры и сложные корреляции ошибок.

## Метод
- Фреймворк: Байесовская мультиномиальная пробит-модель с дополненными данными (data augmentation).
- Структура ошибок: Использование скрытых факторных моделей для моделирования корреляций между вкусами и ценовой эндогенностью.
- Динамика: Введение времени-изменяющихся факторных нагрузок для отражения временных шоков спроса.
- Сжатие: Применение мультипликативного гамма-процесса для регуляризации факторной матрицы и борьбы с переобучением.
- Оценка: Эффективный MCMC-алгоритм с векторизацией для получения предсказаний вероятностей выбора и ценовых эластичностей.
- Данные: Маркетинговый датасет IRI (IRI Marketing Data Set) с детальной информацией о покупках домохозяйств.

## Главные результаты
- Симуляции подтверждают, что предложенная модель (TV-FA Endo) превосходит статические и экзогенные бенчмарки по точности оценки эластичностей (минимальный RMSE).
- Эмпирический анализ налога на газировку показывает статистически значимую отрицательную собственную эластичность для сладких напитков.
- Выявлена независимость между сладкими напитками и молочными продуктами (отсутствие эффекта замещения сахара).
- Обнаружена слабая комплементарность между сладкими напитками и солеными снеками (перекрестная эластичность минус 0.028), что указывает на дополнительный синергетический эффект налога для здоровья.

## Важные концепции
- Факторный подход к корреляциям: заменяет громоздкие матрицы ковариаций компактным набором скрытых факторов, экономя параметры.
- Времени-изменяющиеся нагрузки: позволяют модели адаптироваться к изменяющимся во времени потребительским предпочтениям и рыночным шокам.
- Эндогенность цен: учитывает корреляцию между ценами и ненаблюдаемыми характеристиками товаров через уравнения первого этапа.

## Ограничения
- Число товаров ограничено на практике (рекомендуется J <= 7) из-за экспоненциального роста числа возможных наборов.
- Вычислительная сложность MCMC-сэмплирования возрастает при увеличении размерности панели и числа факторов.
- Требуется наличие качественных инструментов (внешних цен или специфических переменных) для идентификации ценовой эндогенности.

## Практическое применение
- Оценка эффективности фискальной политики (акцизы на сахаросодержащие продукты, табак, алкоголь).
- Ритейл и маркетинг: прогнозирование спроса на бандлы товаров и анализ кросс-категорийной комплементарности.
- Эконометрический анализ спроса в академических и отраслевых исследованиях рынков с многомерным выбором.

## Итоговые выводы
- Разработан первый байесовский метод оценки спроса на наборы для панельных данных с эндогенными ценами.
- Главное преимущество — способность одновременно учитывать сложную структуру ошибок, динамику и эндогенность без взрывного роста параметров.
- Эмпирически доказано, что налог на газировку снижает потребление не только сахара, но и сопутствующих вредных снеков.
- Ограничением остается вычислительная емкость метода при большом числе товарных позиций.
- Работа существенно расширяет методологию оценки благосостояния и моделирования рыночного равновесия.
